## 📖 Read (English)

On September 25, Microsoft unveiled a redesigned Copilot that it calls a "super app." The new Copilot has three tabs: **Home**, **Code**, and **Autopilot**. Home brings Chat and Cowork together and builds Word, Excel and PowerPoint right into the experience. Code, powered by the same technology as GitHub Copilot, runs in a sandboxed environment so that anyone can build an internal app and share it with teammates. Autopilot — previously known as Scout — is a cloud-hosted "digital teammate" with its own identity, memory, computer and workspace; it keeps working while you sleep, and you can @mention it in Teams or Outlook like a colleague. Microsoft says Home and Code will roll out through its Frontier early-access program in the coming weeks, while Autopilot enters private preview later this month.
