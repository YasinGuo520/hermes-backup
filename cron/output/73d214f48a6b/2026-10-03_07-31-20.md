## 4. 填空练习（语法/听力）

先自己填，再看答案 👇

1. OpenAI has ______ (launch) a new agent platform that can ______ software for you.
2. Each Dot runs inside ______ own cloud computer, so it can browse the web and take ______ your desktop.
3. It is great ______ big tasks, but it often gets stuck ______ security checks when ordering food.
4. Dots are rolling ______ first to OpenAI's most expensive ______.

**答案**：
1. launched ｜ use
2. its ｜ over
3. at ｜ on
4. out ｜ plans（也可用 tier）

**语法点**：
- **has + 过去分词**（现在完成时）→"已经发布了"，强调对现在有影响。
- **its** = 它的（无撇号！**it's** = it is，两者别混）。
- **be good at + 名词/动名词**：be great **at** big jobs；**get stuck on** 是固定搭配（卡在…上）。
- **roll out** = 推出（产品/功能的行业黑话，科技新闻里天天出现）。
