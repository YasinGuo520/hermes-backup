## 📖 English (原文)

Microsoft has released **Microsoft-Decision-1**, a model that does not write text at all. Instead of generating sentences, it reads a question together with a fixed list of options and returns a probability for each option — so software can act on the answer immediately. It was post-trained from Alibaba's Qwen3.5-9B and is now available through Microsoft Foundry and OpenRouter. Microsoft reports 83.5% average accuracy across 36 benchmarks, a median latency of just 85 milliseconds, and a price of $0.042 per million input tokens — output tokens are free. The trade-off, however, is that the weights are closed, and every benchmark was run by Microsoft itself, so independent verification is still pending.

## 🇨🇳 中文总结

微软发布 Microsoft-Decision-1，这是一种「决策打分」模型：它不写文章，而是对给定的一组固定选项逐项打分、输出概率，让程序能直接拿结果去执行（分流、分类、校验、给 AI Agent 的动作打分）。它基于阿里 Qwen3.5-9B 后训练，微软自测 36 个基准平均准确率 83.5%、中位延迟 85 毫秒、输入价 $0.042/百万 token（输出免费）。代价是权重闭源、且全部跑分由微软自己发布，独立验证（JevBench）还没出，竞品 H2O.ai 已公开质疑其延迟对比不公平。
