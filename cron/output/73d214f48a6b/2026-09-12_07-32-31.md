## 📖 English Reading

On September 10, 2026, OpenAI released its **Agents API** in public beta. The API exposes the same orchestration "harness" that powers OpenAI's Codex product, but as a fully managed cloud service. Instead of building your own system for tool calling, context management, and long-running sessions, you simply specify a task, a model, a set of tools, and an environment — and OpenAI runs the agent for you. ## ✍️ 填空练习（Fill in the blanks）

用括号里的词的正确形式填空，或按语法补全：

1. OpenAI ______ (release) its Agents API in public beta on September 10, 2026.
2. Developers can build an agent by specifying a task and a set of tools, instead of ______ (build) their own orchestration system.
3. Orchestration, context management, and failure recovery ______ (handle) by OpenAI's managed service, so you don't need to write that code yourself.
4. The API ______ (charge) only standard token, tool, and container fees — there is no separate platform fee.

### ✅ 参考答案
1. **released**（明确过去时间点用一般过去时；若强调"已经发布"也可 has released）
2. **building**（instead of 是介词，后接动名词 -ing）
3. **are handled**（被动语态 + 复数主语）
4. **charges**（一般现在时，主语 the API 单数 → 加 -es）

> 小提示：第 3 题练"被动语态"，第 2 题练"介词后接 -ing"——这两个是技术英文里最高频的语法点。读的时候顺便把 `harness`「框架」和 `orchestration`「编排」记下来，看 AI Agent 相关英文文档会反复遇到。
