# 决策副驾驶 · 一人公司版

> **核心理念**：对于一人公司，你的时间就是你的钱。决策副驾驶不替你做决定，但让你看清「什么决定值得做」。

## 系统架构

```
每天（随手记） → 决策日志（结构化）
每周日（自动跑） → 复盘分析（模式识别）
决策前（按需调） → 决策支持（数据参考）
```

---

## 第一部分：决策日志（每日）

### 日志文件位置

每次记录存为一个文件：

```
~/Desktop/hermes/decisions/YYYY-MM-DD.md
```

### 日志模板

```markdown
## 今日决策记录

### 决策1：[简短标题]
- **类型**：[项目方向 | 时间分配 | 花钱/投资 | 内容策略 | 工具选用 | 合作伙伴 | 拒绝/放弃]
- **选项**：A=________  vs  B=________
- **选了哪个**：A / B
- **决策依据**：（一句话，为什么选这个）
- **预估收益**：¥___ / ___小时 / 其他
- **实际结果**：（事后补，¥收获 / 耗时 / 情绪变化）
- **后悔吗**：后悔 / 不后悔 / 不好说

### 决策2：[...]
```

### 关键规则

| 规则 | 说明 |
|------|------|
| **不要写日记** | 只记「有选择」的决策，不记流水账 |
| **每天最多3条** | 只记最重要的3个决策。没有就不记 |
| **随手记，不要拖** | 做了决定立刻写，30秒搞定 |
| **实际结果周末补** | 决策时写「预估」，周末复盘时补「实际」 |

### 何时算「一个决策」

值得记的标准：
- ⚡ 花了 ≥30分钟犹豫的 → 记
- 💰 涉及花钱（≥¥50）的 → 记
- 🔀 两个以上选项的 → 记
- ❌ 你拒绝了某个机会 → 记（拒绝也是决策）
- 🧠 需要我（AI）帮你分析的 → 记

**不值得记**：
- 午饭吃什么 → 不记
- 先回A消息还是B消息 → 不记
- 日常执行层面的自然动作 → 不记

## 第二部分：每周决策复盘（自动分析）

### 触发方式

每周日 18:00（精进时段），我（AI）自动触发复盘。

### 复盘流程

1. 读取本周所有 `~/Desktop/hermes/decisions/YYYY-MM-DD.md`
2. 按决策类型聚合分析
3. 输出复盘报告

📌 决策类型分布

- 决策日志满8周后，出一次8周趋势总报告

## 第三部分：红蓝论式决策支持（核心）

当你面临一个重大决策时，说 **「帮我分析一下XX vs YY」**，我触发红蓝辩论流程。

> **原则**：我不替你做决定，我替你把两边的枪都填满子弹，你自己扣扳机。

### 两种模式

| 模式 | 触发词 | 用途 |
|:----:|:------|:----:|
| **A vs B 决策**（默认） | 「帮我分析一下A vs B」 | 两个选项之间的选择 |
| **人生复盘模式** | 「帮我分析我的人生」「前半生诊断」 | 回顾过去多年的决策模式，识别重复错误 |

### ① 红蓝列阵（各自陈述）

输出格式如下。**每次必出红蓝双方，不准偷懒只给一方。**

触发框架：**马斯克第一性原理** → 剥离习惯假设，只看最基本事实

⚠️ 红蓝双方陈述时，必须执行一次第一性原理检查：
```
【第一性原理检查】
├─ 现有假设：关于这个选项，哪些是"别人都这么说"而不是"事实"？
├─ 剥到最底层：抛开所有类比和惯例，最基本的事实是什么？
└─ 重建逻辑：从这些基本事实出发，最合理的做法是什么？
```

```
═══════════════════════════════════════

🔴【红方 · 支持A：XXXX】
├── 核心论据1：___________（数据/事实）

**红方和蓝方都必须有数据支撑，不能只靠感觉说话。** 如果数据不足，标注「数据不足，基于假设」。

### ② 攻防回合（红蓝互驳）

红方说完蓝方说，蓝方说完红方回，至少一轮攻防。

触发框架：**芒格逆向思维（Inversion）** → "如果我知道会怎么死，我就永远不去那里"

攻防时双方必须执行逆向思维攻击：
```
【逆向思维攻击】
├─ 正向问题："怎么做才能成功？"
├─ 逆向问题："怎么做一定失败？"
└─ 检视：当前选项是否含有"通向失败的路径"？
```

```
═══════════════════════════════════════
⚔️ 攻防回合
═══════════════════════════════════════

🔵 蓝方反驳红方：
「红方说XXXX，但忽略了三件事——」
├── 反驳1：___________
├── 反驳2：___________
├── ➤ 逆向思维攻击：如果选A，___情况下会彻底失败？
└── 致命一击：红方最大的漏洞是_______

🔴 红方回击蓝方：
「蓝方说得有道理，但——」
├── 回击1：___________
├── 回击2：___________
├── ➤ 逆向思维攻击：如果选B，___情况下会彻底失败？
└── 致命一击：蓝方最大的漏洞是_______
```

**攻防环节必须用力，不要客气。** 蓝方要拆穿红方的理想假设，红方要戳破蓝方的避重就轻。

### ③ 铁律检查

触发框架：**段永平「Stop Doing List」（不为清单）**

> 段永平最核心的决策思维——不是"做什么"，而是"不做什么"。他的Stop Doing List包含：不做超出能力圈的事、不做不诚信的事、不做没有复利的事。你的铁律就是你的一人公司版Stop Doing List。

```
═══════════════════════════════════════
🚨 铁律检查（你的Stop Doing List）
═══════════════════════════════════════

✅ 财务红线 → A触犯 / B触犯 / 都不触犯
  ├─ 付费超过¥100要先问替代方案？
  ├─ 月度总支出≤¥200？
  └─ 定价做了竞品调研？

✅ 项目红线 → A触犯 / B触犯 / 都不触犯
  ├─ 当前项目还没PMF就开新方向？
  ├─ 同一时间只做1个主项目？
  ├─ 有近3月市场数据？
  └─ 普通人能看懂的需求？

✅ 内容红线 → A触犯 / B触犯 / 都不触犯
  ├─ 会不会导致断更？
  └─ 会不会陷入完美主义？

✅ 时间红线 → A触犯 / B触犯 / 都不触犯
  ├─ 会不会挤占18:00后的休息？
  ├─ 会不会占用周日？
  └─ 会不会让上午赚钱时段缩水？
```

**红线触犯=直接黄牌**。如果A触犯红线但B没有，蓝方直接赢一大截。

### ④ 历史参考（你的真实数据）

翻你的 `~/Desktop/hermes/decisions/` 日志，找同类决策。如果决策日志还没有数据（刚开始用），则改为：翻过往会话记录 + 你的口头描述，手动提取同类决策的历史结果。

触发框架：**张一鸣概率化决策** → 不要追求100%确定，用概率思考

> 张一鸣的核心决策观："做决策不需要100%的确定性，有80%的把握就应该行动。用概率思考代替非黑即白，每次决策都记录偏差，持续校准。"

```
═══════════════════════════════════════
📜 你的历史同类决策参考
═══════════════════════════════════════

你以前做过___次类似选择（翻决策日志）：
├── 选A类似方向 → 结果：¥___ / 后悔/不后悔
├── 选B类似方向 → 结果：¥___ / 后悔/不后悔
├── 你的预估 vs 实际偏差率：___%（帮你校准下次预估）
└── ➤ 概率判断：这次你有多大概率选对？（不要纠结100%，80%就可以动）
```

**预测偏差记录特别重要**——让你看到自己是不是总乐观高估。偏差率持续>30% = 你的预估系统需要校准。

### ⑤ 红蓝结论

触发框架：**贝索斯遗憾最小化（Regret Minimization）**

> 贝索斯做重大决策时的方法：想象自己80岁回头看今天，哪个选择会让你更少遗憾？"我知道等我80岁时，我不会因为尝试过而后悔，我会因为没试过而遗憾。"

结论环节必须增加遗憾最小化检视：

```
【遗憾最小化检视】
├─ 80岁的你回头看今天，选A会后悔吗？
├─ 80岁的你回头看今天，选B会后悔吗？
└─ 你更怕"试了失败"的遗憾，还是"没试"的遗憾？
```

```

═══════════════════════════════════════
🏁 红蓝结论
═══════════════════════════════════════

红方（A）综合得分：X/10
├── 论证强度：X
├── 数据支撑：X
├── 风险可控：X
├── 铁律兼容：✓/✗
└── 遗憾风险：低/中/高（80岁的你回头看的感受）

蓝方（B）综合得分：X/10
├── 论证强度：X
├── 数据支撑：X
├── 风险可控：X
├── 铁律兼容：✓/✗
└── 遗憾风险：低/中/高（80岁的你回头看的感受）

📊 数据优势方：红方 / 蓝方（客观数据上哪边更强）
💡 我的判断倾向：偏向___方
⚠️ 但最终决定权在你——扣扳机吧。

→ 选了之后记得记进今日决策日志 📝

### 人生复盘模式（Life Retrospective）

说 **「帮我分析我的人生/前半生/决策模式」** 触发。适用场景：回顾过去多年的生涯，找到重复的决策错误，而不是选A还是选B。

#### 人生复盘流程

```
① 时间线梳理 → 按时间排列经历，标出关键决策和结果
② 红蓝诊断 → 🔴严厉：决策问题在哪 🔵同理：客观因素是什么
③ 攻防互驳 → 两轮交锋，剥离「运气不好」vs「决策错了」
④ 铁律回测 → 用现有铁律检查过去——哪些当时就该执行？
⑤ 模式识别 → 找出重复出现的决策模式（最重要的输出）
⑥ 结论 → 继续什么、停止什么、开始什么？
```

#### 与A vs B模式的区别

| 维度 | A vs B模式 | 人生复盘模式 |
|:----:|:----------|:------------|
| **时间范围** | 未来 | 过去（5-20年） |
| **分析对象** | 两个选项 | 整段人生经历 |
| **核心输出** | 选A还是选B | 模式识别报告 |
| **数据来源** | 决策日志 | 用户口述 + 会话历史 |
| **框架侧重** | 第一性原理+遗憾最小化 | 逆向思维+偏差率分析 |

```

├── 第三次出现：___年  → 结果：___
├── 模式描述：（一句话说清）

## 第五部分：实施路径

### 第1周 · 建立习惯

| 天 | 动作 | 检查标准 |
|:--:|------|---------|
| Day 1 | 读完这个Skill | 理解了决策日志的「记什么/不记什么」 |
| Day 1-7 | 每天记1-3条决策 | 有记录的日期 ≥5/7天 |
| Day 7（周日） | 第一次复盘 | 触发复盘分析 |

### 第2周 · 优化

- 复盘Day1-7的决策日志质量：有没有漏记重要决策？有没有记了不该记的？
- 调整模板：不合适的字段删掉，缺的加上

### 第8周 · 趋势报告

满8周出第一份趋势报告，回答：
- 什么类型的决策你做得最多？
- 什么决策你最后悔？（模式识别）
- 你的时间花在哪类决策上性价比最高？
- 你的决策质量在上升还是下降？

## 复盘触发

每周复盘可以通过两种方式触发：

### 方式一：你主动说（推荐前2周）

在周日精进时段说「帮我做本周决策复盘」→ 我自动走复盘流程。

### 方式二：自动Cron Job（第3周起）

当决策日志积累稳定后，可以设一个每周日18:00的cron job自动触发复盘。

## 第六部分：名人决策工具箱（速查）

> 不是知识堆砌，是你做决策时可调用的**思维武器**。每个框架都标注了「用在哪个环节」。

---

### 1️⃣ 马斯克 · 第一性原理
**用在 → 红蓝列阵（①号位）**

| 维度 | 内容 |
|------|------|
| **原始问题** | 电池为什么这么贵？→ 材料成本只占2%，剩下98%是制造方式 |
| **核心公式** | 剥离假设 → 还原基本事实 → 重新推导 |
| **你的一人公司版** | "这个项目真的是必须这样的吗？还是只是别人都这么干？" |
| **一句话口诀** | 别人怎么做不重要，物理上可能才重要 |
| **别滥用** | 不是所有决策都要第一性原理。选中午吃什么用类比就行了。只在重大方向性决策用 |

---

### 2️⃣ 芒格 · 逆向思维（Inversion）
**用在 → 攻防回合（②号位）**

| 维度 | 内容 |
|------|------|
| **原始问题** | "如果我知道会死在哪里，我就永远不去那里" |
| **核心公式** | 不问"怎么成功"→ 问"怎么一定会失败" |
| **你的一人公司版** | "如果我要把这个项目搞砸，最快的方式是什么？" → 然后避开这些 |
| **一句话口诀** | 先想怎么死，再想怎么活 |
| **别滥用** | 容易让人只防守不进攻。逆向之后必须回到正向 |

---

### 3️⃣ 段永平 · Stop Doing List（不为清单）
**用在 → 铁律检查（③号位）**

| 维度 | 内容 |
|------|------|
| **原始问题** | 段永平的核心原则：知道"不做什么"比知道"做什么"更重要 |
| **核心公式** | 列出不能做的事 → 触犯=直接否决 |
| **你的一人公司版** | 你的财务红线/项目红线/时间红线全是Stop Doing List |
| **一句话口诀** | 先说不，再说好 |
| **别忘了** | Stop Doing List需要定期更新。每季度检查一次：哪些红线过时了？需要加什么新的？ |

---

### 4️⃣ 张一鸣 · 概率化决策
**用在 → 历史参考（④号位）**

| 维度 | 内容 |
|------|------|
| **原始问题** | "80%确定性就可以行动了，不要追求100%" |
| **核心公式** | 概率估算 → 容忍不确定性 → 用偏差率校准 |
| **你的一人公司版** | 不需要100%确定才发视频。60分发出去 > 100分没发 |
| **一句话口诀** | 八成把握就开枪 |
| **关键工具** | 预估vs实际偏差率：如果你总预估高了，那就打八折再行动 |

---

### 5️⃣ 贝索斯 · 遗憾最小化
**用在 → 红蓝结论（⑤号位）**

| 维度 | 内容 |
|------|------|
| **原始问题** | "我知道等我80岁时，我不会因为尝试过而后悔。我会因为没试过而遗憾" |
| **核心公式** | 投影到80岁 → 哪个选择遗憾更少 → 选它 |
| **你的一人公司版** | "一年后回头看今天，没做这个会更后悔吗？" |
| **一句话口诀** | 别让80岁的你骂现在的你怂 |
| **适用边界** | 对可逆决策（花时间学个技能）特别有效。对不可逆决策（花大钱买设备）要谨慎 |

---

### 6️⃣ 巴菲特 · 双目标清单
**用在 → 每周复盘（项目方向评估）**

| 维度 | 内容 |
|------|------|
| **原始问题** | 巴菲特让飞行员列出人生25个目标，圈出最重要的5个，然后说："剩下的20个，你要像躲避瘟疫一样避开它们" |
| **核心公式** | 列出所有想做的事 → 挑出最重要的5个 → **主动避开剩下的20个** |
| **你的一人公司版** | 你的待办池就在干这个——当前主项目=前5，探索池=后20 |
| **一句话口诀** | 不是你做不了的事害了你，是你能做但不该做的事害了你 |
| **每周应用** | 复盘时检查：我有没有偷偷去碰那"20个"之一？ |

---

### 7️⃣ 芒格 · 多元思维模型
**用在 → 整个系统（元框架）**

| 维度 | 内容 |
|------|------|
| **原始问题** | "手里只有锤子的人，看什么都像钉子" |
| **核心公式** | 一个决策至少用3个不同学科的角度看一遍 |
| **你的一人公司版** | 这个Skill本身就是多元思维模型的实践——5个步骤用了5种不同思维工具 |
| **一句话口诀** | 别只有一把锤子 |
| **为什么放在最后** | 这个不是具体的决策工具，是提醒你**别只用一种方法想问题**。红蓝辩论已经强迫你从至少两个角度看了 |
