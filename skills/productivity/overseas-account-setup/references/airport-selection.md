# 机场/翻墙线路选型方法论（2026-08 实测）

## 机场 ≠ VPN（先纠正概念再推荐）
| 维度 | 传统VPN | 机场(代理) |
|---|---|---|
| 协议 | WireGuard/OpenVPN/IPSec | V2Ray/SS/Trojan/Hysteria/AnyTLS |
| 原理 | 全量加密隧道 | 规则分流代理 |
| 墙内存活 | 裸连秒封 | TLS伪装+中转能活 |

速度排序：专线(IEPL/IPLC) > Hysteria2 > 普通中转(Trojan/Vmess) > WireGuard > OpenVPN。
用户说「VPN慢」多半是节点问题不是协议问题：晚高峰堵/落地带宽小/没开BBR。换冷门节点比换协议管用。

## 自建 vs 买机场
- 自建：海外VPS + X-UI面板(网页点几下配好)。香港轻量(腾讯云≈¥38/月)延迟最低。
  好处：独享带宽、IP干净不怕AI风控、不怕机场跑路。坏处：**IP会被墙封**(换IP收费$5-8/次)、线路不行不如好机场。
- 机场：月付¥15-30省心。结论：晚高峰堵→自建值得；IP被风控→自建或换干净机场；偶尔卡→换节点别折腾。

## 软文识别（90%「评测站」是SEO恰饭）
- 红旗信号：每家评测站推荐的机场都不一样、全带推广优惠码、注册送试用、无运营年限背书
- 可信来源排序：官方大厂背书(如Just My Socks=搬瓦工官方) > 运营3年+社区口碑 > 新开的
- 永不踩坑规则：**月付不年付**(机场跑路常态)、优先有试用/低价入门套餐的、7天内可退款优先
- 同一家机场电信/联通/移动体验完全不同，晚高峰20-22点才是照妖镜，白天测速都好看

## 孪生模板软文识别（新坑）
同一软文站可同时推两家「结构完全一样」的机场——**Tolink 和 Allblue 同模板**：同样2022年成立、同样全IEPL、同样¥15/100G、同样10G试用、同样「年付8折+60天」话术。大概率同一老板/同一套资源挂两个牌子，或软文站套同一模板。

## 灰色行业（机场）调研技术：搜索超时时 curl 直抓软文站
DuckDuckGo 搜索在灰产话题上频繁超时；web_extract 后端(ddgs)不能提取URL；浏览器CDP也可能超时。**可用路径：curl + 移动端UA 直抓已知软文站详情页**（vpngocn.com / tuijianvpn.com / 51fan.pro 等，HTTP 200 可直接抓）：
```bash
curl -sL --max-time 25 -A "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1" "https://vpngocn.com/tolink-jichang-pingce/" -o /tmp/tolink.html
# 然后用 python re 剥 script/style/标签 提取正文（见 china-market-research 第三步模板）
```
软文站首页的「相关推荐」就是同类机场清单——一次能挖出一整批候选（本次从 vpngocn 相关推荐发现 Allblue/Mikasa/蓝帆云 等一串）。
⚠️ 价格信息来自推广页，只能作为「候选+价格参考」，**速度/稳定性必须用户本地晚高峰实测**，评测站数据不能当结论。

无实测数据时不能编造排名。正确做法：

## 国外VPN在中国大陆基本失效（2026-08 外网调研结论）
用户说「去外网找最靠谱VPN」时先纠正认知：**外网好评的主流VPN（ExpressVPN/NordVPN/Surfshark）在中国大陆基本全废**——它们测速是在欧美网络下，墙内连都连不上。外网专门测「China VPN」的评测（comparitech/bleepingcomputer 等）翻来覆去只有几家能在中国用：
| VPN | 特点 | 价格(年付摊月) |
|---|---|---|
| Astrill | 公认"中国专用"，Stealth混淆，海外党在华首选 | 贵，约$30/月，年付$120+ |
| PureVPN | 中国能连，节点多 | 约$3-4/月 |
| PrivateVPN | Stealth Mode 能用 | 约$2-3/月 |
| Hotspot Shield | Hydra协议自带混淆 | 约$3-8/月 |
| 12VPX | 专为在华外国人 | 中等 |

**关键结论**：这些「China VPN」并不比国内机场强，反而更贵更慢——大厂协议特征明显，也常被墙针对；国内机场线路是为中国网络优化的（CN2/中转），国外VPN不是。**没有任何VPN能"永久不抽风"，包括Astrill**——都是靠不断换IP/换协议活着。给用户的路径排序：性价比→国内机场月付；稳定→自建香港+备用机场；国外VPN只适合「人在海外/公司合规要求/不在乎钱」场景。
⚠️ 抓取注意：外网评测站 Cloudflare 盾（bleepingcomputer 403/comparitech 超时），curl+浏览器都可能被挡，此时不要硬刚，用已有结论+软文站数据交叉即可。

## 「新机场刚买好用、几天后变慢」规律（用户高频痛点）
这是行业标配套路，不是错觉：**新客体验 → 付费 → 老客降质 → 换一批新客**。分层原因：
| 原因 | 说明 |
|---|---|
| IP是新的 | 新节点IP干净没被墙标记，用几天被识别封锁就掉速 |
| 测试时机 | 买时白天测的，晚高峰20-22点全国挤爆 |
| 超售 | 1G带宽卖500人，人少你跑满，人多一起卡 |
| 买前买后两副面孔 | 新用户喂好节点，续费切普通节点 |
| 算法先给甜头 | 新账号优先优质线路养依赖，再降速 |

**破法**：①先测换节点——换冷门节点能恢复=IP被墙（机场没换IP能力就换机场）；换节点也没用=整体降质/超售，直接换；只有晚上卡=正常现象。②月付！月付！年付哪怕便宜一半也别付。③同时持有2家机场当备胎，别押一家。

## 小火箭「代理」vs「配置」模式（分流原理，2026-08 用户实战）
| 模式 | 原理 | 结果 |
|---|---|---|
| 代理(Proxy) | 无脑全走代理，不读规则 | ✅ 外网能上，但国内App也走代理（变慢、扣流量） |
| 配置(Config/Rule) | 按规则文件分流，先读规则 | ❌ **没加载 .conf 规则文件 = 无规则可读 = 外网也上不去** |

- 「选配置上不了外网」= 只导入了节点、没导入规则。解决：用机场**完整订阅链接**（自带规则），或在配置页下载分流规则文件（如 blackmatrix7/ios_rule_script 的 Shadowrocket 规则，该仓库按App分类单文件，非一个全家桶文件）
- 判断分流是否生效：小火箭首页左上角显示 Rule/配置 = 分流中；显示 Global/全局 = 未分流
- 正确日常用法：配置模式+机场自带规则 = 国内直连、国外走代理、自动分流

## 自建节点数认知 + 只搞美国节点- **自建节点数 = 你买的VPS台数**：一台=一个节点。机场30-50个节点是它的核心卖点，自建PK不过数量。
- 1个香港节点对你够用：视频/日常✅，但 **ChatGPT 对香港IP有时不开放，需美国节点兜底**——所以组合拳留一家便宜机场专补美国节点。
- 大陆服务器（业务机）**不能翻墙**：43.138.221.174 这类腾讯云大陆机是跑业务的，翻墙违规且会被封；翻墙必须单独买海外地域（香港/美西）。
- 只搞美国节点：核心不是VPS便宜，是**线路**。美西（洛杉矶/圣何塞）比美东近；CN2 GIA 是唯一能保晚高峰稳定的优化线路（搬瓦工$50-100/年）。普通线路（Vultr/DO $6/月）白天行晚高峰看运气。
- 成本对比：自建美国CN2 GIA ¥35-60/月 vs 机场含美国节点 ¥10-20/月——**"只要美国节点"最省钱的是机场的美国节点**，自建美国只适合重度GPT+对IP纯净度要求高（怕风控）的场景。
- 最终推荐组合：腾讯云/阿里云香港轻量 ¥40/月 主力翻墙（视频+日常）+ 便宜机场 ¥6-10/月 补美国节点（GPT+自建被封时顶班）。

## Cloudflare WARP 不推荐当主力（用户问「cloudflare这个vpn好用吗」）
WARP 是免费 VPN（WireGuard），但**对墙内+GPT+视频需求几乎全废**：
| 维度 | 情况 |
|---|---|
| 价格 | 免费，Cloudflare官方 |
| 墙内直连 | ⚠️ 很难连，握手反复失败 |
| GPT | ❌ OpenAI 明确封锁 Cloudflare IP |
| 流媒体(Netflix等) | ❌ 识别数据中心IP，拒绝播放 |
| 真实定位 | 隐私保护/配合工具换IP的辅助工具，不是主力翻墙 |
结论：**别浪费时间折腾 WARP**，核心需求它一个都满足不了。免费的最贵——研究它2小时不如注册机场薅10G试用。

## 「解锁仅限XX节点」机制（用户高频疑问，先解释原理再给数据）
流媒体/OpenAI 封的是**机房IP段**，机场只对部分节点维护了「干净IP」（原生/优化IP），所以解锁能力按节点算：
- 解锁节点 = 机场特意养了没被封的IP（例：IKUUU只保港/日，追云只保台/美）
- 自动选择模式可能落到被封节点 → ChatGPT弹「区域不可用」、流媒体403
- 用法：**手动锁死解锁节点**；别在解锁节点上频繁横跳（公共干净IP用的人多，OpenAI风控会弹验证/要手机号）
- 判断机场别只看「支持ChatGPT」，要看「哪些节点支持」
