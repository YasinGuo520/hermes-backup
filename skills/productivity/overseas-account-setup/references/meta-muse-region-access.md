# Meta 系（Muse / Meta AI）地区开放与账号资格

## 事实基线
- Muse（Meta 个人 AI Agent）**仅在美国开放，18+**：iOS / Android / muse.ai / WhatsApp，Mac 版后补。官方公告只写美国——**没有第二国、没有时间表、没有官方 waitlist 页面**。
- 美区 App Store 应用名 **Muse from Meta**（包名 com.facebook.aura），**要求 iOS 18.0+**，只上架美区。
- **门槛在账号层，不在页面层**：muse.ai 从任何地区都能打开，卡在注册/登录那一步。所以「页面打得开、一登录就说地区不可用」是正常表现，不是缓存问题，别清 cookie 清到天亮。

## 两种报错要分清（决定「等」还是「修」）
| 报错原文 | 含义 | 动作 |
|---|---|---|
| Muse 尚未在你的国家或地区开放，我们会在向你开放时通知你 | 资格未开放 | 走下面的修复路径 |
| 你已加入等候名单 | 灰度排队中 | **先别改任何设置，24-48h 常自己开**；急着用就填邀请码 |

实测佐证：有人报「等候名单」，第二天什么都没改就可用；也有人同节点下新号全开、老号一直排队。

## 老号 vs 新号是分水岭
实测：同一批用美国 IP 新建的号全部开放；**绑着自己常用 Facebook 账号的老号一直留在等候名单**（被判常用地点/注册地为 CN）。
→ 修复合集里优先级最高的动作是「换新号」，不是「换节点」。

## 修复路径（按性价比）
### A 先试：原号 + 环境对齐（约 3 分钟，0 成本）
1. 代理切**全局**（不是规则分流）——实测：规则分流下注册概率进 waitlist
2. 或反向做：给这几个域名单独设规则强制走美国节点（**漏一个就前功尽弃**）：`muse.ai`、`meta.ai`、`meta.com`、`metaaivm.com`
3. 系统语言 `English (US)`；时区关掉自动、手动设成美国节点所在城市；关闭 Muse / FB / IG 的「精确位置」权限
4. 卸载 App → 保持全局 → 重装 → 登录
5. 报的是「等候名单」→ 等 24-48h，别反复点

### B 老号被判死：换新账号（唯一解）
1. **不绑任何老 FB/IG**，用全新 Gmail / Outlook
2. 全程美国节点 + **无痕窗口**打开 `muse.ai/join`（无痕是为了避开旧 cookie 里的地区缓存）
3. 邮箱验证码 → **年龄验证（18+）**，四条路（用户说「没有信用卡 / 咋整」时直接给这张表）：

   | # | 方式 | 成本 | 说明 |
   |---|---|---|---|
   | 1 | **绑 Facebook / Instagram** | ¥0 | 完全不用卡。官方流程写作「绑卡 $1 验证**或**绑定 FB/IG」，多篇社区实测靠 FB 直接过；⚠️ 也有人反馈走 FB 后仍被要求绑卡 → 不保证 |
   | 2 | **Visa / Mastercard 借记卡** | ¥0 | Meta 官方身份验证原文是「使用**借记卡或信用卡**……收取 $1 美元（等值货币），5-7 个工作日内退还」→ **不一定非要信用卡**；纯银联单标卡不行 |
   | 3 | 上传证件走 Yoti 人脸核验 | ¥0 | Meta 通用机制（护照/驾照，入口 `auth.meta.com/verify`）；Muse 页面是否提供该选项未见实测 → 标为待验证 |
   | 4 | 虚拟卡（starryblu 等） | $0-19.9 + 1-3 天 | 有实测「starryblu 卡可以过」；⚠️ Meta 对预付/虚拟卡风控敏感，且该类平台现多需白名单/会员 |

   **这一步有时会自己跳过**：社区多人反馈「卡了好久的年龄验证，终于打开了」→ 先别死磕，过 24-48h 再登一次看。交付顺序：先试 1（0 成本）→ 再试 2（借记卡）→ 其余待定。
4. 注册后进 `Settings → 通用 → 使用情况` 填**邀请码**：跳过 waitlist + 双方各 10 亿 token（标称永久，注册后 48h 内兑换）。公开邀请码在技术论坛满地都是，填别人的不影响自己账号权限，不用花钱买

### C 节点是硬伤时
- 机场机房共享 IP 会被 Meta 判「环境不真实」：**同一国家的不同节点有的通有的不通**就是它
- 实测建议**美国家宽/住宅 IP**；报「暂未开放」先换节点再下结论

## 配套检查（省一轮白跑）
- **iOS 18.0+ 才装得上 App**。老机（iOS 15/16/17 黄金组合机）只能走 muse.ai 网页版 —— 用户设备是 iPhone 11 / iOS 15.7 时先说明这点，别让他去 App Store 折腾
- 美区 Apple ID 只解决「能下载」，与「能不能用」无关

## 风险
- Meta 系风控严于 OpenAI / Anthropic：长期高频调用 + IP 跳动/断流会被判风险账号，有连坐 FB / WhatsApp 账号的先例；公开报道里也有用户仅因向 Meta 申诉资格问题而账号被封
- 不要用改地址、借他人账号、上传证件代实名这类绕过手段——代价是账号恢复、支付、数据权利全变复杂

## 检索这类「地区未开放」问题的有效姿势
- 中文技术社区（V2EX / NodeSeek / hostloc / 烧饼）是实测信息最厚的地方，**优先只读搜索结果快照**：这类站对机房 IP 常直接超时，不必强行进页面
- 官方页只能确认「是否仅限某国」，拿不到用户级判定逻辑；修复细节只在社区实测帖里
- 结论必须区分「官方口径」与「用户实测」，两者冲突时以多篇一致的实测为准，并把不确定的地方标成推断
