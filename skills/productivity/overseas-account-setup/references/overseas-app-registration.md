# 海外软件注册明细表

## 注册方式总表（2026实测）

| 软件 | 注册方式 | 需要翻墙吗 | 备注 |
|---|---|---|---|
| Google账号(Gmail) | +86 手机号直接收码 | 注册时开代理更稳 | 注册后是「根账号」，能 Google 登录的软件都先试它 |
| ChatGPT | 必须海外手机号 | 是 | 接码平台 sms-activate / 5sim，支付宝充¥10，一个号够注册多个软件 |
| Claude | 先用 Google 账号登录 | 是 | 能绕开手机验证；卡了再接码 |
| Telegram | +86 手机号直接注册 | 是（收码时开代理） | 短信可能延迟3-5分钟；一个号一个账号 |
| WhatsApp | +86 手机号直接注册 | 是 | 海外版微信，跨境客户沟通必备 |
| Facebook | **手机号比邮箱稳** | 是 | 邮箱注册卡住=风控，别耗，换+86手机号 |
| Instagram | +86 或邮箱 | 是 | 注册时美国节点 |
| Discord | 邮箱或海外号 | 是 | 风控时要求手机验证，接码兜底 |
| Twitter/X | 邮箱注册 | 是 | 风控时要求手机验证 |
| YouTube | 用 Google 账号 | 是 | 无需单独注册 |
| Notion | 用 Google 账号 | 否 | 国内可访问，用 Google 登录即可 |

## 接码平台用法（sms-activate / 5sim）
1. 注册平台账号（邮箱即可）
2. 支付宝充值 ¥10
3. 搜 OpenAI（或对应服务）
4. 选便宜国家号码（印度/印尼，¥3-5/次）
5. 把号码填进注册页 → 收验证码 → 完成
6. 一个号注册完全部要海外号的软件，总花费不到 ¥10

## Google 注册验证拦截（「需要先验证一些信息」）
症状：注册时出现 QR 码页「使用您的手机扫描二维码」
原因：机场共享节点 IP 被 Google 标记为可疑
解法（按成功率排序）：
1. **手机端直接注册**（手机开代理 → gmail.com → 创建账号）最稳
2. 手机相机扫码走 Google 给的验证通道（扫码不会关联设备到新账号，放心扫）
3. 换干净美国节点 / 换线路 / 换浏览器 / 无痕窗口
4. 收不到短信 → 找「改用语音电话接收」选项，语音通道成功率最高
5. 中国号码收 Google 短信本来就容易失败，语音是正解

## TikTok 专项
症状：显示「无网络连接」/ 第一次能开第二次不行
原因链：
1. 插着中国 SIM 卡 → TikTok 判定位在中国 → 无网络（即使代理开着）
2. 节点自动切换 → IP 变动 → 风控
3. 用第三方修改版（TikTok Pro）→ 客户端被检测为异常
解法：拔 SIM 卡 / 飞行模式 + WiFi → 固定一个美国节点（手动选，别用自动）→ 清缓存 → 官方版 App
网页版 tiktok.com（代理开着）作为兜底。

## 苹果设备兼容性
- iPhone 7 Plus 最高 iOS 15.8.8：升安全补丁不会明显变卡（15.x 内的小版本）
- 要求 iOS 16+ 的新版 App（如新版 ChatGPT）：7 Plus 装不了新版，App Store 会提示下载兼容旧版本；没有旧版本就只能换设备或用 Mac
- Mac 上 App 不受 iOS 版本限制，ChatGPT 等优先在 Mac 装
