# App Store「检查」界面死循环排查（2026-08 实战记录）

## 现象
新注册的美区Apple ID在iPhone App Store登录/下载App时，反复弹「此 Apple 账户尚未用于 iTunes Store 请检查」→ 点「检查」→ 输密码 → 又跳回检查界面，循环不止。购买付费App（如Shadowrocket $2.99）时必现。

## 核心判断原则
1. **电脑网页端（account.apple.com）能正常登录 = 账户本身没问题**，问题在设备端会话/风控/资料验证，别在手机上反复硬试（会触发风控锁）。
2. 反复失败后必须**停手冷却**：等10分钟再试，锁死则等4-6小时。
3. 新注册账户有**激活延迟**：刚注册的ID偶尔要等10-30分钟才完全激活，期间别狂点。

## 排查顺序（按实战优先级）

### 1. 检查网页端「付款与配送」资料完整 ✅ 必做
- account.apple.com → 付款与配送
- 必须有完整配送地址（免税州：俄勒冈 Portland 1234 NW Davis St / OR / 97209）
- 付款方式显示「无/None」（不需要绑卡，None + 礼品卡余额是标准玩法）
- 地址没保存成功 = 检查死循环最常见根因

### 2. 手机系统地区改为美国（关键！）
- iPhone 设置 → 通用 → 语言与地区 → **地区改为「美国」**（语言保持中文）
- 原因：检查流程按**手机系统地区**走，手机地区是中国 → 要求中国区信息 → 和美区账户冲突 → 死循环
- 改完重启手机再登

### 3. 用免费App触发条款流程
- App Store 搜 Instagram（免费）→ 点「获取」
- 走「同意条款」流程，有时能绕过付费检查卡点

### 4. Mac App Store 激活（最稳）
- 打开 Mac 系统自带 App Store → 登录美区ID → 随便下载免费App走完检查
- **电脑端走通一次，手机端同步解锁**

### 5. 网络/代理
- 登录App Store时**关掉代理**（App Store国内可直连，开代理反而验证失败）
- 用海外服务时才开代理，且用**美国节点**固定IP，别用自动切换/香港节点

## ⚠️ 死锁根因：设备端「完成创建 Apple 账户」强制付款方式（2026-08 二次实战新增）
- 新ID首次在设备端（iPhone/Mac App Store）登录会进入「完成创建 Apple 账户」流程，**两步后强制要求付款方式**（Visa/MC/Discover/Amex/PayPal 图标行），**没有「无/None」选项**，不填过不去。
- **关键认知：设备端要的是「账单地址」(billing address)，不是网页端已填的「配送地址」**。网页端「付款与配送」只有配送地址 ≠ 检查流程里的账单地址字段（全空，含城市下拉/邮编/区号/电话）。
- 解法路径（按序试）：
  1. 在「完成创建」页**填完整账单地址**（城市下拉选 Portland / 邮编 97209 / 区号 503 / 电话 5550100），付款方式图标**一个都别点**，填完点继续——地址完整后有时「无」选项才出现。
  2. **礼品卡余额 = 付款方式**：先买 $5 礼品卡（Pockyt 官网）→ 兑换 → 账户有余额后检查界面直接放行。**这是死锁的钥匙**：没有付款方式→过不了检查；没有余额→没法兑换。设备端 Mac App Store 登录成功后可兑换，或检查流程内找「兑换充值卡」入口。
  3. Mac App Store 端登录（左下角账号）走完整个流程，成功一次后手机端同步解锁。
- 已确认：强制付款方式页面填美国账单地址+不点卡图标 → 可以继续（Mac 端最终登录成功）。

## Pockyt 卡密位置（用户易卡）
- shop.pockyt.io **/balance 是余额页，不是卡券页**——卡密在「我的订单 / My Cards / 账户」里，或注册邮箱里。
- 购买记录入口一般在右上角头像/我的账户，不是 balance 页。

## 已验证事实
- 双重认证开启 + 受信任号码正确 ≠ 检查能过（检查卡的是资料/设备验证）
- 网页端能登录后台、能看到全部信息 = 账户没被锁
- Mac端新版App Store无退出登录按钮，切换账号走：系统设置 → Apple ID → 媒体与购买项目 → 管理 → 退出登录
