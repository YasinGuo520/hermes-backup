# 海外账号/翻墙/AI付费 全流程（墙内最省成本路径）

## 触发条件
用户要：注册美区Apple ID / 下载Shadowrocket / 翻墙 / 注册ChatGPT等海外软件 / 给AI平台付费 / 买礼品卡。

## 方案总览（先给成本再给步骤）
| 项目 | 方案 | 成本 |
|---|---|---|
| 手机翻墙 | 机场(用户自备) + Shadowrocket | ¥15-30/月 + $2.99一次性 |
| Mac翻墙 | 同一机场 + Clash Verge Rev | 免费 |
| 海外账号 | 自注册美区Apple ID + 接码平台 | 免费 + ¥3-5/次 |
| AI付费 | 美区礼品卡 → iOS App内购订阅 | $19.99/月无手续费 |

## Step 1 美区Apple ID注册
1. 邮箱：**用Outlook(outlook.com)**，国内直连秒收验证。**QQ邮箱会被苹果拒**，163同理；Gmail可用但需翻墙+手机验证，作备选。
2. appleid.apple.com → 创建账号 → 地区选 **United States**
3. 支付方式选 **None**（永远不用绑卡，礼品卡余额直接付）
4. 电话：区号默认+1是坑（没有美国号收不到验证码），**改 +86 填中国手机号**
5. 地址：免税州示例 `1234 NW Davis St, Portland, OR 97209`（俄勒冈/特拉华/蒙大拿）
6. 注册成功后去「付款与配送」**补填配送地址**，否则App Store下载应用会卡住要求地址

## Step 2 接码（需要海外手机号的软件：ChatGPT/Claude/Discord）
- sms-activate.org 或 5sim.net：邮箱注册 + 支付宝充值¥10
- 选目标服务 + 便宜国家号码（印度/印尼约¥3-5）→ 收验证码
- 能绕就绕：Google账号注册支持+86；Claude可先用Google账号登录，卡了再接码

## Step 3 礼品卡购买（Pockyt官网，替代支付宝App）
- **支付宝App内「切换地区/惠出境」入口已改版，找不到是正常的——别在App里耗，直接用官网**
- https://shop.pockyt.io → 注册 → 搜 **App Store & iTunes USA** → 面额 $5 → 结算选支付宝扫码付
- 注意选「App Store & iTunes USA」（蓝卡白苹果），**不是**「Apple Gift Card US」（彩色logo，面额大用不上）
- 卡密到手 → iPhone App Store头像 → 兑换充值卡 → 手动输卡密
- 渠道安全排序：Pockyt官方 > 淘宝/拼多多卡密直发 > 代充（黑卡封号，不碰）

## Step 4 客户端
- iPhone：App Store 退出国区 → 登录美区ID → 搜 Shadowrocket，$2.99 一次性
- Mac：Clash Verge Rev（开源免费）→ 导入同一机场订阅链接

## Step 5 AI平台付费（省钱关键）
- **礼品卡内购最省**：iOS App内购订阅ChatGPT Plus，$19.99/月，无手续费
- 虚拟信用卡（WildCard等）：开卡费$9.99+3.5%手续费，贵且麻烦
- 代充/拼车：便宜但封号风险，不碰
- 面额策略：小火箭用$5卡（剩$2备用），ChatGPT订阅另买$25卡，不共用

## Step 6 ⚠️ App Store「检查」卡循环排查（实战高频坑）
新注册美区ID在App Store登录/购买时反复跳回「检查」界面（登不上去/下载App时弹检查→返回），**按此顺序排查**：

1. **先确认账户没锁**：电脑网页 account.apple.com 能登录 = 账户正常（网页登录会发验证码到手机，正常现象）
2. **双重认证+受信任电话**：登录与安全性里确认开启、是+86号
3. **地址保存成功**：付款与配送里地址完整显示（最常见原因：注册时地址根本没保存成功，页面显示空）
4. **手机系统地区改美国**：设置→通用→语言与地区→地区改「美国」→重启
5. **关代理/用4G直连**：登录苹果账号不需要翻墙，代理IP跳动反而触发验证失败
6. **老系统workaround**（iPhone 7 Plus/iOS 15等）：先用国区账号登录App Store一次（能登=设备网络没问题）→退出→再登美区
7. **终极：风控冷却**：国区能登但美区卡 = **账户风控**。反复失败会**延长**风控，停手等24小时，第二天网页端先登录确认再手机登

**核心判断法**：设备没问题（国区能登）+网页能登录+资料完整 → 卡检查 = 美区新账户风控，**等是最快解法，别硬试**。

## 其他坑
- 新macOS App Store点名字没有退出登录按钮，入口在：系统设置 → Apple ID → 媒体与购买项目 → 管理 → 退出登录
- 网页版 apps.apple.com 登录/退出按钮隐藏难找，别耗时间，用 account.apple.com 判断账户状态
