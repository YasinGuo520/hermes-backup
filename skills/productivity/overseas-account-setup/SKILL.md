# 海外账号/翻墙/AI付费 全流程（墙内最省成本路径）

## 触发条件
用户要：注册美区Apple ID / 下载Shadowrocket / 翻墙 / 注册ChatGPT等海外软件 / 给AI平台付费 / 买礼品卡。

## 方案总览（先给成本再给步骤）
| 项目 | 方案 | 成本 |
|---|---|---|
| 手机翻墙 | 机场(用户自备) + Shadowrocket | ¥15-30/月 + $2.99一次性 |
| Mac翻墙 | 同一机场 + Clash Verge Rev | 免费 |
| 海外账号 | 自注册美区Apple ID + 接码平台 | 免费 + ¥3-5/次 |
| AI付费 | 美区礼品卡 → iOS App内购订阅 | $19.99/月无手续费 |

## Step 1 美区Apple ID注册
1. 邮箱：**用Outlook(outlook.com)**，国内直连秒收验证。**QQ邮箱会被苹果拒**，163同理；Gmail可用但需翻墙+手机验证，作备选。
2. appleid.apple.com → 创建账号 → 地区选 **United States**
3. 支付方式选 **None**（永远不用绑卡，礼品卡余额直接付）
4. 电话：区号默认+1是坑（没有美国号收不到验证码），**改 +86 填中国手机号**
5. 地址：免税州示例 `1234 NW Davis St, Portland, OR 97209`（俄勒冈/特拉华/蒙大拿）
6. 注册成功后去「付款与配送」**补填配送地址**，否则App Store下载应用会卡住要求地址

## Step 2 接码（需要海外手机号的软件：ChatGPT/Claude/Discord）
- ⚠️ **sms-activate.org 已于2025-12-29关停**，官方接盘方 **hero-sms.com**（老余额可转移）。任何自称 SMS-Activate 的来信/链接都是诈骗。现役平台：**hero-sms.com / 5sim.net**，邮箱注册 + 支付宝充值¥10
- 选目标服务 + 便宜国家号码（印度/印尼约¥3-5）→ 收验证码
- 能绕就绕：Google账号注册支持+86；Claude可先用Google账号登录，卡了再接码

### ChatGPT 注册的手机验证（2026实测）
- **邮箱注册（Outlook可以，QQ/163有被拒风险）几乎必验手机号**，+86 不行，需接码
- **Apple ID 登录有几率直接跳过手机验证**——优先试「Continue with Apple」，全程美国节点；⚠️ **别勾 Hide My Email**，否则账号绑在 privaterelay 随机别名上，以后找不回（可通过 iPhone 设置→Apple ID→Sign in with Apple 找回别名）
- Google 登录：老号（2024前）可能跳过，新号大概率要验
- 登录方式注册时锁定：SSO 建的账号只能用 SSO 登，邮箱+密码建的只能用密码登，不混用
- 注册/登录全程固定**同一美国节点**，中途切节点触发风控

### 提示「无法向该号码发送短信」= 号段被 OpenAI 拉黑（虚拟号识别）
按成功率顺序：①换新号（换不同区号前缀，别买同一批）→ ②换国家（印度/印尼/菲律宾通过率反而高，还便宜）→ ③换节点（Clash 确认美国，IP 不干净也拒发）→ ④换平台（hero-sms ↔ 5sim 号池不同）。**别死磕一个号，试2-3个基本能过。**

## Step 3 礼品卡购买（Pockyt官网，替代支付宝App）
- **支付宝App内「切换地区/惠出境」入口已改版，找不到是正常的——别在App里耗，直接用官网**
- https://shop.pockyt.io → 注册 → 搜 **App Store & iTunes USA** → 面额 $5 → 结算选支付宝扫码付
- 注意选「App Store & iTunes USA」（蓝卡白苹果），**不是**「Apple Gift Card US」（彩色logo，面额大用不上）
- 卡密在「我的账户 → 订单/我的卡券」（**不是 /balance 余额页**），点开订单查看卡密；也可能发到注册邮箱
- 卡密到手 → iPhone/Mac App Store → 兑换充值卡 → 手动输卡密
- 渠道安全排序：Pockyt官方 > 淘宝/拼多多卡密直发 > 代充（黑卡封号，不碰）

## Step 4 客户端
- iPhone：App Store 退出国区 → 登录美区ID → 搜 Shadowrocket，$2.99 一次性
- Mac：Clash Verge Rev（开源免费）→ 导入同一机场订阅链接
- **已购项目跟账号走不跟设备**：小火箭买断后，其他iPhone/iPad登录同一美区ID在「已购项目」里免费下载，不用重复买

## Step 4.5 小火箭配置 + Google打不开排查（实战高频）
配置：小火箭 → 右上角+ → 类型选 Subscribe → 粘贴机场订阅链接 → 保存 → 节点自动拉取 → 点节点 → 开关变绿（首次弹「添加VPN配置」→允许→输手机密码）

连接了但 Google 打不开，按此顺序：
1. **换节点**：选延迟数字最小的（当前节点可能挂/慢）
2. **切全局代理**：小火箭首页顶部「全局路由」默认「配置」→ 切「全局代理」（规则分流可能漏掉目标）
3. **确认VPN生效**：手机状态栏有VPN图标（小锁/VPN字样）= 网络层通了；没有 = 没真连上，重新开关
4. **清浏览器缓存**：Safari设置→清除历史记录与网站数据
5. 全局也打不开 = 节点全挂/机场问题，回官网看节点状态

**下载 vs 使用（用户常混淆）**：App Store 下载美区软件**不需要开小火箭**（走苹果服务器不墙），登录/使用 Google/ChatGPT/Twitter 才需要开。日常不挂代理（费电+可能被苹果风控）。少数App下载后打开就检测地区（TikTok等）→ 开着小火箭再打开。

**兑换后弹窗**：App Store 兑换礼品卡后常弹 Apple TV 免费2个月推广 → **别领**（2个月后自动扣 $12.99/月）。

## Step 5 AI平台付费（省钱关键）
- **礼品卡内购最省**：iOS App内购订阅ChatGPT Plus，$19.99/月，无手续费
- 虚拟信用卡（WildCard等）：开卡费$9.99+3.5%手续费，贵且麻烦
- 代充/拼车：便宜但封号风险，不碰
- 面额策略：小火箭用$5卡（剩$2备用），ChatGPT订阅另买$25卡，不共用

## Step 6 ⚠️ App Store「检查」卡循环排查（实战高频坑）
新注册美区ID在App Store登录/购买时反复跳回「检查」界面（登不上去/下载App时弹检查→返回），**按此顺序排查**：

1. **先确认账户没锁**：电脑网页 account.apple.com 能登录 = 账户正常（网页登录会发验证码到手机，正常现象）
2. **双重认证+受信任电话**：登录与安全性里确认开启、是+86号
3. **地址保存成功**：付款与配送里地址完整显示（最常见原因：注册时地址根本没保存成功，页面显示空）
4. **手机系统地区改美国**：设置→通用→语言与地区→地区改「美国」→重启
5. **关代理/用4G直连**：登录苹果账号不需要翻墙，代理IP跳动反而触发验证失败
6. **老系统workaround**（iPhone 7 Plus/iOS 15等）：先用国区账号登录App Store一次（能登=设备网络没问题）→退出→再登美区
7. **终极：风控冷却**：国区能登但美区卡 = **账户风控**。反复失败会**延长**风控，停手等24小时，第二天网页端先登录确认再手机登

**核心判断法**：设备没问题（国区能登）+网页能登录+资料完整 → 卡检查 = 美区新账户风控，**等是最快解法，别硬试**。

**真正的钥匙（先试这个，别干等）**：检查死锁的根因常是**账户无付款方式**——检查流程强制要求付款方式（仅信用卡/PayPal，无「无」选项），没卡没余额就永远循环。**礼品卡余额就是付款方式**：先在 Pockyt 买 $5 卡 → 设备 App Store 兑换 → 余额到账 → 再登录检查直接放行。这是同时解决「付款方式」和「买小火箭」的一步到位方案。

**账单地址 vs 配送地址（另一个隐藏坑）**：注册后填的「付款与配送」地址 ≠ 检查流程要的「账单地址」（billing address）。检查流程要求先填完整账单地址（街名/城市下拉/邮编/区号/电话），付款方式那栏才可能出现「无」选项。区号填州电话区号（俄勒冈503），电话填 5550100 这种美国格式。顶部 Visa/Mastercard 图标**一个都别点**（点了就要填卡号，没卡会卡死）。

## 其他坑
- 新macOS App Store点名字没有退出登录按钮，入口在：系统设置 → Apple ID → 媒体与购买项目 → 管理 → 退出登录
- 网页版 apps.apple.com 登录/退出按钮隐藏难找，别耗时间，用 account.apple.com 判断账户状态
