# B站视频快速分析方法论

从B站视频中提取内容信息的方法。适用于分析教程/测评/案例/观点类视频。

---

## 流程概览

```
① 获取BV号 → ② B站API提取元数据 → ③ 浏览器加载页面(滚屏) → ④ 提取描述+标签+评论 → ⑤ 交叉搜索补充 → ⑥ 结构化分析
```

---

## 第一步：获取BV号

B站视频URL格式：`https://www.bilibili.com/video/BV1wVRTBFEXR` — `BV1wVRTBFEXR` 就是BV号。

## 第二步：B站API提取元数据（最快，优先）

```bash
curl -s "https://api.bilibili.com/x/web-interface/view?bvid=BV1xx..."
```

返回JSON包含：

| 字段 | 内容 | 用途 |
|---|---|---|
| `data.title` | 视频标题 | 核心主题 |
| `data.desc` | 视频描述 | 核心信息（up主写的简介） |
| `data.duration` | 时长（秒） | 内容深度判断 |
| `data.pubdate` | 发布时间（Unix时间戳） | 时效性判断 |
| `data.owner.name` | up主名称 | 信源评估 |
| `data.stat` | 播放/点赞/评论/收藏数 | 热度判断 |
| `data.pages[].part` | 章节标题 | 内容结构（如果有分P） |
| `data.subtitle.list[].subtitle_url` | 字幕URL | **如果有字幕，可获取全文** |
| `data.tid` | 分区ID | 内容类目 |
| `data.desc_v2` | 分段描述 | 结构化描述 |

**注意**：B站API有频率限制，频繁调用会返回 `{"code": -352}` 或 `"请求过于频繁"`。

## 第三步：浏览器加载页面（获取页面级信息）

当API获取的信息不足以完成分析时（缺少章节结构、想看评论区），使用浏览器工具：

```python
# 1. 导航到视频页面
browser_navigate(url="https://www.bilibili.com/video/BV1xx...")

# 2. 获取页面快照（无需登录即可看到）
snapshot = browser_snapshot()  # 返回页面元素的accessibility tree

# 从快照中提取：
# - 完整描述（StaticText节点）
# - 标签（link节点，有href属性）
# - 视频时长（从player控件中）
# - 章节信息（从章节按钮或弹幕列表）
# - 热评（评论区域的前几条）
# - up主关注数
```

**关键定位技巧**：
- 视频标题在 `<heading level=1>` 中
- 描述在视频标题下方第一个 `StaticText` 段落
- 标签在 `link` 元素中，通常是 `#标签名` 格式
- 评论在 `评论` heading 之后
- 章节按钮（如果有）显示在播放器控件中，标注 `章节 · xxx`

### 获取章节信息

在浏览器快照中，章节信息通常出现在播放器的按钮或区域中。查看是否有标注 `章节 ·` 文本。

### 获取评论区信息（无需登录）

快照会显示前几条评论的作者和内容。评论区域在页面底部，标注为 `评论` heading。注意：
- 登录后才能查看更多评论（`登录后查看 N 条评论`）
- 但前几条热评通常已经包含足够信息
- 置顶评论（up主自己的评论）往往包含额外说明

## 第四步：交叉搜索补充（当B站信息不足时）

```python
web_search(query=f"视频标题 up主名 方法 教程")  # 搜索相关文章/讨论
web_search(query=f"视频主题关键词 经验 分享")
```

用途：
- 视频描述太短时，搜索相同主题的文字内容补充
- 查找up主其他平台的内容（博客/GitHub/公众号）
- 验证视频中的说法是否有其他来源支撑

## 常见陷阱

1. **B站API限频** — 连续多次请求会被限流，出现 `-352` 错误。每次请求间隔1秒以上。
2. **描述可能过短** — 很多B站视频的描述只有一句话。这时需要依靠浏览器获取更多上下文。
3. **浏览器渲染不完整** — 有些动态加载的内容需要滚动或点击才能显示。使用 `browser_scroll` 滚动到底部看评论区。
4. **登录限制** — 完整字幕、AI总结、点赞/投币等功能需要登录。但元数据和前几条评论不需要。
5. **视频实际内容 vs 标题** — B站标题党存在。描述和标题只是入口，实际内容可能和标题不完全一致。结合评论区判断。
6. **up主个人风格** — 每个up主有固定风格。查看up主的简介和其他视频了解其立场和可信度。
