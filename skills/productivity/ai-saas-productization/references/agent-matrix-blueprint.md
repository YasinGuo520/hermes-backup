# 岗位JD → Agent落地方案拆解（Agent Matrix Blueprint）

> 场景：用户丢来一堆岗位JD/职能清单（如"统筹运营/销售攻坚/市场战略/培训/招聘/流程优化/绩效评估，每个+AI Agent"），问"这些Agent怎么弄出来"。
> 验证来源：电商运营7职能矩阵实际方案讨论（2026-09），已入 Obsidian `entities/电商运营Agent矩阵.md`。

## 核心判断（第一反应）

**职能清单 ≠ N个独立Agent**。先拆成：
- **数据管道**（抓取/清洗/汇总/存储）——真正的工程量所在
- **LLM决策层**（读数据摘要→写报告/给建议）——最便宜、最快的一层
- **独立小件**（不依赖数据管道：RAG问答、简历解析、报告生成）

LLM只做最后一层，绝不能让它承担数据获取。

## 五步拆解法

1. **数据墙调查**：每个职能先问"数据从哪来？平台有无公开API？"——先调查再承诺，不吹全自动。
2. **可行档分级**：🟢独立小件 / 🟡半自动（数据汇总类，受数据墙限制）/ 🔴减配（需平台权限的部分砍成"建议清单"）。
3. **工具分工**：见下表。
4. **三件套交付**：每个Agent = 数据管道 + 工作台页面 + 消息推送（页面=同一数据的另一种展示，**不增加LLM成本**，不要另算钱）。
5. **成本透明**：给具体数字（日报≈¥0.01/天级别），规则引擎走0 token。

## 数据墙速查（已验证事实，别重复调查）

| 平台/数据 | 可用性 | 用法 |
|-----------|--------|------|
| 抖音电商数据 | ✅ TikHub 已打通（api.tikhub.io Bearer） | 账号搜索/热榜/用户画像（付费端点） |
| 淘宝/天猫/拼多多/京东 后台 | ❌ 无公开API | 手工导出Excel喂管道 → 半自动 |
| 抖店开放平台 openjinritemai.com | ✅ 个体工商户可入 | 客服消息API⭐，自动上下架需企业资质 |
| 蝉妈妈/飞瓜 | 无API，付费墙 | 免费公开页+浏览器兜底 |
| "预测趋势" | 能做到的=历史外推+竞品监控+规则预警 | 所有前瞻输出必须标"推断" |

## 工具分工（给个人/小团队自用时）

| 工具 | 角色 | 说明 |
|------|------|------|
| Hermes直接写脚本 | **主执行** | cron+Python管道、FastAPI、页面；改一行就行 |
| Dify | 只用于 RAG知识库（培训类Agent）+ 对外版"可视化工作流演示"卖点 | 已自部署（nginx 8850/API 8851/web 8852），模型要配SiliconFlow |
| n8n | **暂不用** | 它的活cron脚本全能干；多系统webhook链路复杂了再上 |

原则：**自用工具越少中间层越好**。Dify/n8n每次改节点要可视化调试一圈，脚本改一行完事。

## 对外 vs 自用（表现形态差异）

内核同一个，**对外版=自用版+一层壳**：

| 维度 | 自用 | 对外 |
|------|------|------|
| 入口 | 直接数据驾驶舱，无登录 | 官网→注册→套餐→工作区 |
| 数据 | 单租户 | 多租户隔离（tenant_id） |
| 接入 | 自己配 | 接入指引页+渠道管理页+扫码授权 |
| 计费 | 无 | 三级套餐+用量封顶+超额按量 |
| 演示 | 不需要 | 演示账号+预置数据 |
| 合规 | 无 | 备案+隐私政策 |
| 开发增量 | 基线 | +1~2周（全是机械工作） |

**建议路径**：先自用跑通验证"日报有没有价值"（约1个月）→ 再决定上不上壳。自用版本身就是对外版的活demo。壳的增量没有技术风险，真正不确定的是产品价值。

## 案例：电商运营7职能矩阵（2026-09）

| # | 职能 | 分类 | 可行档 |
|---|------|------|:------:|
| ① | 统筹运营 | 数据汇总+异常预警+AI日报 | 🟡（抖音自动/淘宝手工）——数据底座，先做 |
| ② | 销售分析 | 洞察报告 | 🟡 依赖①管道 |
| ③ | 趋势预测 | 竞品监控+预警 | 🟢 依赖①管道 |
| ④ | 培训 | RAG知识库问答 | 🟢 最易，用Dify或改服小助 |
| ⑤ | 招聘筛选 | LLM简历解析+评分 | 🟢 最独立 |
| ⑥ | 流程自动化 | 五环节工作流 | 🔴 自动上下架砍掉→改"建议清单" |
| ⑦ | 绩效评估 | 多维数据+LLM报告 | 🟢 依赖①数据 |

工期参考：①约4天，②③各+1-2天，④⑤⑦各2-4天，⑥减配2天 → 全部约2周。
