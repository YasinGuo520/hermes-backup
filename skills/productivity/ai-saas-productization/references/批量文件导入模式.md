# 批量文件导入模式 — SaaS数据导入通用方案

## 适用场景

用户需要把本地数据（CSV/Excel/JSON/MD）一次性导入SaaS系统，而不是一条一条手动添加。

## 支持的文件格式

| 格式 | 解析方式 | 列映射 |
|:----|:--------|:------|
| **CSV** | `csv.DictReader` + `utf-8-sig` 编码 | 自动匹配 中/英文 列名 |
| **XLSX** | openpyxl `read_only=True` | 首行作为表头，自动匹配列 |
| **JSON** | `json.loads` | 数组或 `{items: [...]}` 包裹格式 |
| **TXT/MD** | `## 标题` 分割条目 | 标题→title，正文→content |

## 后端实现模式

### FastAPI 上传端点模板

```python
from fastapi import APIRouter, UploadFile, File, HTTPException
from pathlib import Path

ALLOWED_EXTENSIONS = {".csv", ".xlsx", ".json", ".txt", ".md"}

@router.post("/upload")
async def upload_file(
    file: UploadFile = File(...),
    payload: dict = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    ext = Path(file.filename).suffix.lower()
    if ext not in ALLOWED_EXTENSIONS:
        raise HTTPException(400, detail=f"不支持格式: {ext}")

    content_bytes = await file.read()
    if len(content_bytes) > 50 * 1024 * 1024:
        raise HTTPException(400, detail="文件超过50MB")
    if not content_bytes:
        raise HTTPException(400, detail="文件为空")

    parser = {".csv": _parse_csv, ".xlsx": _parse_xlsx,
              ".json": _parse_json, ".txt": _parse_txt, ".md": _parse_txt}[ext]
    try:
        items = parser(content_bytes)
    except Exception as e:
        raise HTTPException(400, detail=f"解析失败: {str(e)}")

    if not items:
        raise HTTPException(400, detail="文件无有效内容")

    # 批量写入（本示例为知识库）
    imported = 0
    errors = 0
    for data in items:
        try:
            db.add(KnowledgeItem(tenant_id=..., title=data["title"],
                                 content=data["content"], category=data["category"]))
            imported += 1
        except Exception:
            errors += 1
    db.commit()
    return {"imported": imported, "errors": errors, "total": len(items)}
```

### CSV 解析（含中英文列名容错）

```python
def _parse_csv(content: bytes) -> list[dict]:
    text = content.decode("utf-8-sig")  # 兼容Excel保存的CSV（BOM头）
    reader = csv.DictReader(io.StringIO(text))
    items = []
    for row in reader:
        title = (row.get("title") or row.get("标题") or "").strip()
        content = (row.get("content") or row.get("内容")
                   or row.get("answer") or row.get("答案") or "").strip()
        category = (row.get("category") or row.get("分类") or "general").strip()
        if content:
            items.append({"title": title, "content": content, "category": category})
    return items
```

**关键细节：** `utf-8-sig` 而不是 `utf-8` —— Excel导出CSV会在文件头加BOM标记，用 `utf-8` 解码会在第一个字段前多一个 `\ufeff` 字符。

### XLSX 解析（read_only 防内存爆炸）

```python
def _parse_xlsx(content: bytes) -> list[dict]:
    import openpyxl
    wb = openpyxl.load_workbook(io.BytesIO(content), read_only=True, data_only=True)
    ws = wb.active
    rows = list(ws.iter_rows(values_only=True))
    if not rows:
        return []
    header = [str(h).lower().strip() if h else "" for h in rows[0]]
    col_map = {}
    for i, name in enumerate(header):
        if name in ("title", "标题"):          col_map["title"] = i
        elif name in ("content", "内容", "answer", "答案"): col_map["content"] = i
        elif name in ("category", "分类"):     col_map["category"] = i
    items = []
    for row in rows[1:]:
        title = str(row[col_map["title"]]).strip() if "title" in col_map and row[col_map["title"]] else ""
        content = str(row[col_map["content"]]).strip() if "content" in col_map and row[col_map["content"]] else ""
        category = str(row[col_map["category"]]).strip() if "category" in col_map and row[col_map["category"]] else "general"
        if content:
            items.append({"title": title, "content": content, "category": category})
    return items
```

### TXT/MD 解析（## 标题分割）

```python
def _parse_txt(content: bytes) -> list[dict]:
    lines = content.decode("utf-8").strip().split("\n")
    items, title, body = [], "", []
    for line in lines:
        if line.startswith("## "):
            if body_text := "\n".join(body).strip():
                items.append({"title": title, "content": body_text, "category": "general"})
            title, body = line[3:].strip(), []
        else:
            body.append(line)
    if body_text := "\n".join(body).strip():
        items.append({"title": title, "content": body_text, "category": "general"})
    return items
```

### JS 工作流

```
点击/拖拽 → 选文件 → 校验扩展名 → 显示文件名+大小 → 用户点"确认导入"
  → FormData POST到 upload 端点 → 进度条动画 → 显示结果（成功X条/失败Y条）
  → 自动刷新数据列表
```

**关键点：** 拖拽区域同时响应 click 和 drop 事件；form-data POST 不设 Content-Type 让浏览器自动处理 multipart boundary。

## 常见坑

| 坑 | 现象 | 解决 |
|:--|:-----|:-----|
| CSV用`utf-8`解码报错 | 第一列字段前面多一个字符 | 用 `utf-8-sig` |
| 大文件XLSX OOM | 内存暴涨 | `read_only=True` + `data_only=True` |
| JSON格式不确定 | 解析后是dict不是list | `isinstance(data, dict)` 兜底 |
| 上传后404 | 端点未注册 | 检查 `app.include_router(upload_router)` |
| 上传后无反应 | 服务跑的是旧进程 | `kill` 旧进程后重启 |
| XLSX首行空 | 全部行被跳过 | 检查表头行是否有值 |
