### 从业者三类画像

1. **程序员兼职**（最正规）：报价 200-500，真能配好环境 + 调通 Skills
2. **半路出家的「安装师」**：自学一两天就接单，有的自己都不用这个工具，纯粹照教程走一遍；报价 100-300
3. **卖铲子团队**：有组织，单店月营收 10-30 万（第三方盘点）；某团队自述 30-45 万

## 4. 风险面（做这个生意必须知道）

| 风险 | 事实 |
|:--|:--|
| 监管 | 工信部 NVDB 发布《关于防范 OpenClaw 开源 AI 智能体安全风险的预警提示》 |
| 已发生事故 | 超 **3 万个** OpenClaw 实例遭入侵，被用于窃取 API Key、拦截消息 |
| 高危漏洞 | CVE-2026-25253（CVSS 8.8，点击恶意链接即被完全控制）、CVE-2026-25593（零点击） |
| 供应链 | ClawHub 上 **12% 的 Skills** 被注入恶意代码 |
| 你的风险面 | 代装 = 你远程/上门操作客户电脑，权限等同「在客户电脑上做任何事」；反过来客户也怕你留后门 |

**反面即机会**：第三方原文「安全加固 —— 这是绝大多数代装师根本不做的」「安全加固无价」。带安全加固的代装是现成溢价点。自保/交付清单：客户自己注册输 API Key、全程录屏、装完检查 Skills 目录 / 配置文件外联地址 / crontab / 监听端口 / 启动项。

## 5. 生命周期判断

第三方推断（**非数据**）：这门生意 **3-6 个月快速萎缩**。理由：官方已出一键脚本+桌面安装包、云厂商提供一键镜像、中文教程烂大街、安全事件让用户开始怕让陌生人碰电脑。
历史同构：Windows 装机 50-100 → 手机刷机 20-50 → WordPress 建站 500-5000 → ChatGPT 代注册 50-200 → DeepSeek 代部署 100-500 → OpenClaw 代装 50-16000。**每一波都是信息差生意，窗口期越来越短。**

## 6. 三种形态对比（给用户的结论形状）

| 形态 | 做什么 | 客单价 | 开发成本 | 竞争 | 售后 | 判定 |
|:--|:--|:--|:--|:--|:--|:--|
| A 卖安装程序 | 封装上游+UI，打 .exe/.dmg 卖 | 30-100 | 几周 | 上游免费做 | OS/上游更新全你扛 | ❌ |
| B 纯代装服务 | 远程/上门装好 | 50-500 | 0 | 极卷 | 一单一结 | ⚠️ 地板 |
| C 行业定制包+教会用 | 装好 + **自有 skill 包** + 场景配置 + 1对1 教学 | **1000-3000** | 1-2 天整理 | 几乎无人做 | 需交付时间但可复用 | ✅ |

**C 的护城河三件套**：已跑通的 skill 包（别人装完是空壳）+ 行业经验（知道客户每天真正要什么）+ 现成的集成参照系。

**最小动作模板**：写一页服务清单（`××行业 AI 员工部署包 ¥1500，含装好+skill包+场景配置+2小时1对1`）→ 挂闲鱼/小红书 → 另挂一个低价引流款（`远程代装 ¥199 含安全加固`）把人引到高价包。
