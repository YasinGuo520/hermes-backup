# 各部门Agent功能模板

每个部门一个Dify工作区，工作区内含多个Agent。员工通过飞书/企微bot与Agent对话。

---

## 📱 产品部

| Agent | 功能 | 连接工具 |
|-------|------|---------|
| 用户需求分析 | 整理用户反馈/评论，提取高频需求 | 接客服系统/小红书评论API |
| 竞品监控 | 自动跟踪竞品更新、定价变化 | 爬虫/蝉妈妈 |
| PRD辅助生成 | 根据需求整理产品文档初稿 | 知识库+文档模板 |
| 数据看板 | DAU/留存/转化率一句话查询 | 接数据库/BI系统 |

---

## 📊 运营部

| Agent | 功能 | 连接工具 |
|-------|------|---------|
| 日报生成 | 自动聚合昨日数据，生成日报 | 接数据API |
| 活动策划助手 | 根据目标生成活动方案框架 | 知识库+历年活动库 |
| 用户分群分析 | 根据行为数据打标签、分群 | 接用户数据库 |
| SOP问答 | 运营流程的实时问答 | 上传SOP文档做RAG |

---

## 🚚 物流部

| Agent | 功能 | 连接工具 |
|-------|------|---------|
| 订单追踪 | 查物流状态/异常件 | 接快递100/菜鸟API |
| 库存预警 | 库存低于阈值自动提醒 | 接WMS系统 |
| 发货调度 | 按地址/时效推荐发货策略 | 接ERP |
| 物流对账 | 自动核对物流账单 | 接财务系统 |

---

## 💰 财务部

| Agent | 功能 | 连接工具 |
|-------|------|---------|
| 报销审核 | 审核报销单合规性，标记异常 | 接OA审批系统 |
| 对账查询 | "Q3市场部花了多少"直接回答 | 接金蝶/用友 |
| 发票核验 | 自动验真伪 | 接税务API |
| 预算追踪 | 部门预算使用进度实时查询 | 接财务系统 |

---

## 👥 人事部

| Agent | 功能 | 连接工具 |
|-------|------|---------|
| 员工手册问答 | 制度、考勤、社保等问题秒回 | 上传HR文档做RAG |
| 简历初筛 | 按JD关键词筛选简历 | 接招聘平台API |
| 入职流程助手 | 自动生成入职清单/提醒 | 接OA |
| 绩效数据查询 | "这个月各团队绩效排名" | 接绩效系统 |
