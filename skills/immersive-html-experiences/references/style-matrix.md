# 项目风格矩阵

为不同项目类型匹配独特视觉风格。每个项目应有**不同风格的动态背景**和**配色体系**，不重复。

## 实施原则

1. **同一页面不混搭** — 一个项目只能选一种风格，不要拼凑
2. **动态背景用Canvas** — CSS动画不够炫，Canvas粒子/代码雨/烟雾才有冲击力
3. **主色不超过3种** — 每个风格固定主色+辅色+强调色
4. **动效克制** — 背景可以炫，内容区动效不超过0.3s
5. **深色系优先** — 纯白底风格（杂志/名片）留白要大，不要杂色
