# 付费课程 / 网创资源站 真伪鉴别与官方替代源

## 何时用

用户要「找某某的课」「有没有网盘链接」「有没有免费的」——尤其点名某位讲师、某个「陪跑课/训练营/线下大课/密训营」。

这类请求本质是他「**收集资源代替开工**」的循环的另一种表现形态，处理方式和渠道库里的「警惕找项目循环陷阱」同源：**不要把资源递给他，把动作递给他**。

## 铁律一：不代捞盗版链接，但必须同时给等价物

拒绝的方式决定用户接不接受。

| ❌ 无效 | ✅ 有效 |
|---|---|
| 讲版权道德、长篇说教 | **一句**说清「这是盗版转卖，我不搬运」，不重复 |
| 只说「不给」，不给替代 | 立刻给**官方免费等价物**（往往是原文级，比课程更硬） |
| 假装「搜不到」 | 诚实给出流通全貌（渠道/价格/更新日期）再给判断 |
| 重述一次上面的理由 | 用户再问一次也只答一次，然后直接转交付物 |

**为什么必须给等价物**：用户的真实需求是「那部分知识」，不是「那个网盘文件」。原样拒绝 = 他转头自己去踩坑，等于没帮。

**拒绝理由要给「实际代价」，不要给「道德」**：
1. 付款后跳的网盘链接**短期就失效**，站方自己写着「失效找客服」——你拿到的是一张随时会死的链接
2. 「买邀请码/积分开会员」是网创圈最稳的一次性收割模型：**站点的产品是会员卡，不是课程**
3. 大包常带引流码/杂物，目的是把你拉进下一个更贵的私域
4. 「免费网盘搜索聚合站」= 死链 + 中间跳转页 + 伪装网盘登录，**钓鱼重灾区**；比花几十块更贵

## 铁律二：先给「你不需要这个」的证据，再给替代

用数据说话，不要用观点。三个最有说服力的角度，按顺序查：

1. **含量价** —— 看该课最新一期的目录：主讲人本人占几节？如果正主只出现 1-2 节、其余是团队其他讲师/往期内容，就说清楚
2. **重复度** —— 跨版本目录树比对（见下）
3. **适配度** —— 课程面向人群 ≠ 用户实际形态（典型：面向「带团队的主播」的课 vs 用户「不出镜桌播/挂播」）

## 鉴别：所谓「最新版」是不是旧包重贴

**可操作步骤**（资源站把目录直接贴在正文里，无需登录）：

1. 抓该课**最新版页面的目录树文本**
2. 在同一站找同课的**更早版本**页面，同样抓目录树
3. **逐月比对文件名**

**判据**：若两个「不同月份版本」里，早期月份（如去年的 1-6 月）文件名**一字不差完全一致**，只有末尾多了几个文件 → 就是**同一份老包 + 追加最新几节**，重新贴一次「最新」标签再定价。

**要点破给用户的推论**：这类资源「越新越值」的直觉是错的。真正新增的只有末尾那几节，而正主本人可能只占其中一节。

## 资源站是怎么赚你钱的（直接讲给用户）

| 表面 | 实际 |
|---|---|
| 「免费分享」 | 会员制/积分制：买邀请码开会员、用积分解锁 |
| 「仅收网站运维成本」 | 免责话术模板，几乎所有站一字不差拄同一段 |
| 付款后跳网盘 | 链接短期失效 → 「失效找客服」→ 加群 → **群才是产品** |
| 单个资源 几元~百余元 | 全站会员更高；复购靠「每次更新重新标价」 |
| 「网盘搜索聚合站」（爬公开分享链接） | 死链 + 跳转页，钓鱼重灾区 |
| 页面底部的热门推荐全是「日入千元/月入过万」 | 站子本身的定位就不是教学，是引流 |

**要点破**：**平台真实 ≠ 资源真实**。付了钱拿到的是链接，不是知识，更不是结果。

## 官方免费替代源（中文电商/AI 领域，实测可用）

优先给**规则/协议原文**：不会过时、不含二手解读。

| 领域 | 免费官方源 | 里面有什么 |
|---|---|---|
| 巨量千川（投放/ROI/出价） | 千川**规则中心** `qianchuan.jinritemai.com/support/content/<id>` | 成本保障规则等条款原文 |
| 同上 | **全域推广服务协议**（官方规则 CDN 文档） | 投放方式定义 / ROI 公式 / 互斥逻辑原文 |
| 同上 | **千川学堂** `school.oceanengine.com` | 官方认证讲师课，免费 |
| 同上 | 巨量千川官网 `shoppingads.cn` | 产品说明 + 案例库 + 白皮书下载 |
| 抖音电商平台规则 | 抖音电商学习中心（抖店后台进） | 新规解读 |
| 一般规律 | 任何产品的**帮助中心 + 官方服务协议** | 比任何讲师课都硬：它定义机制，而不是讲经验 |

具体到千川的机制内容（整体支付ROI、放量vs控成本、互斥逻辑、成本保障）见 `douyin-livestream-ecommerce` 技能 → `references/qianchuan-quanyu-promotion-roi-bidding.md`。

**讲法**：官方文档给的是**机制与边界**（不会过时），讲师课给的是**节奏经验**（会过时）。两者不冲突，但要先有机制。

## 二手 SEO 站的陷阱（这类搜索结果 90% 是 SEO 农场）

搜中文投放/电商知识，前排大量是 `*.com` 建站群（如 1984nian、hwds868、fuyuan7 这类），特征与对策：

- 正文反复插「《XX手册》」「资源包」「1对1诊断」 → **软文引流，不是知识**
- ⚠️ **同一篇文章内部就能自相矛盾**：同一个公式在摘要和正文里写两个版本。**采信前必须自己按逻辑验算**
- 引用时必须标「二手来源，需在后台/官方核实」，**不得当作官方口径转述给用户**
- 真实官方口径 → 去规则中心/帮助中心核对

## 提取这类页面的技法

资源站与 SEO 站都是服务端渲染的普通 HTML，用 `terminal` 里 `curl + 正则剥标签` 秒级拿到正文（含目录树），**不需要登录、不需要浏览器、不需要 web_extract backend**。命令见 `web-scraping` 技能 → 「最快路径：纯静态文章页」。注意中文站大量用 GBK，解码必须按 `utf-8 → gbk → gb18030` 顺序试。
