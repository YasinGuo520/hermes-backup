# 全球变现案例日报 v2 — 深度版

## 适用场景
- 用户Yasin，电商创业者，飞书接收
- 厌倦了翻来覆去的旧案例，要真正新鲜的、有数据的、能抄的
- 需要的不只是"知道有这个人"，而是"这个我能不能干、怎么干"

## 核心变革

v1的问题 → v2的解法：

| v1问题 | v2解法 |
|--------|--------|
| 案例太旧，翻来覆去那些人 | **先扫新品**，不搜"变现案例"这种老关键词，改搜"今天发布了什么" |
| 收集范围太小 | **国内源翻倍到15+**，再加**垂直赛道扫描** |
| 没有变现原理拆解 | 每案必拆：**产品形态→定价→收入→成本→增长→壁垒** |
| 不知道适不适合自己 | 每案必出：**星刃适配度评分+具体行动步骤** |
| 搜索关键词太宽泛 | **两阶段搜索**：阶段1找苗子，阶段2深挖 |

## 阶段2：深挖（过滤+拆解）

### 过滤规则

**保留**（任一满足即可）：
1. ✅ 有具体收入数字（¥/$+数字） 
2. ✅ 产品已上线且可验证
3. ✅ 上次日报没出现过（如重复标[续]）
4. ✅ 模式新颖/有趣（不全是SaaS订阅老套路）

**淘汰**：
1. ❌ 翻来覆去的老面孔（AudioPen/Marc Lou/Pieter Levels等）
2. ❌ 纯概念无实际产品
3. ❌ 收入模糊（"月入过万"不算）

## 搜索方法

```python
# 优先级
1. AnySearch batch_search(多query并行) —— 首选，一次发5个
2. AnySearch search(query, max_results=10) —— 单条深搜
3. AnySearch extract(url) —— 深度提取页面全文
4. web_search(query) —— DDGS兜底

# 关键：阶段1必须先于阶段2
# 阶段1：扫货（看有什么新鲜的）
batch_search(queries=[
  {query: "Product Hunt today AI tool launched"},
  {query: "site:news.ycombinator.com Show HN"},
  {query: "GitHub trending repositories today"},
  {query: "site:36kr.com AI 创业 案例"},
  {query: "site:huxiu.com 独立开发 SaaS"}
])

# 阶段2：根据阶段1结果，挑最有价值的深挖
extract(url) → 拿到全文 → 按深度结构拆解
```

## 硬性规则

1. **🧱 5国内+5国外** — 少一个都不行，注明"今日此区域不足5个"
2. **📊 必须带数字** — 没具体收入数字的不能算"案例"
3. **⏰ 不能重复** — 和昨天/前天重复的产品标[续]或跳过
4. **🔧 必须拆解原理** — 不是"某人做了个工具月入X"，而是"为什么他能收到这个钱"
5. **🎯 必须出适配度** — 没写"适不适合Yasin干"的不合格
6. **🔍 扫货优先** — 先搜"新发布"，不搜"变现案例"这种陈词

## 常见陷阱（必读）

### ❌ 直接用"变现 案例 月入"搜
→ 搜出来的永远是同一批人。**必须先搜"新发布"**

### ❌ 只深挖不扫货
→ 直接进入深挖模式，挖出来的还是旧案例。**先扫再挖**

### ❌ 拆解了但没适配度
→ 用户看了等于没看。**每案必须写「适不适合你」**

### ❌ 避重就轻（不写具体成本）
→ 只说收入不说成本等于没拆。**必须写成本结构**

### ❌ "这个适合你"毫无根据
→ 不能只说"适合"，要说"为什么适合"（你有XX资源/你懂XX领域）


## 快速变现/接单/日结渠道库（合并自 quick-cash-gig-channels）

触发「怎么快速赚钱/马上变现/接单/日结/兼职」或有短期资金压力时，加载渠道库（不跑每日案例管线）。完整内容见 `references/gig-platform-verification-2026.md`、`references/zhongbao-platforms-2026.md`、`references/tiktok-short-drama-outreach-2026.md` + `templates/wechat-consulting-pitch.md`，铁律速查：

1. **先问约束和期限**：不借钱？不出门？不用闲鱼？多久要入账？——用户常自我设限，方案必须匹配约束，否则白推；把紧迫感变成具体数字（月支出→每天→每小时）
2. **先验证再推荐**：平台验证五步（工商/ICP备案/应用商店评分/黑猫投诉/「XX 靠谱吗」实测）；**平台真实 ≠ 项目真实**（撮合平台单子由用户自发发布，官方不担保，先交钱一律拉黑）
3. **收入打3折**：网络宣传数字是理想值，新手第一周按宣传3折估（众包时薪7-15元不是「日赚200」）
4. **结算周期决定救急能力**：当天到账（外卖/分拣/临时工日结）> T+1（数据标注/众包）> 1-3天（代驾审核）> 2-3天+（视频/文案接单）> ⚠️次月结算（阿里众包，倒计时场景直接排除）
5. **救急评估框架**：缺口金额 vs 渠道日收入×剩余天数；算不够就坦白说。双轨方案：保底体力活（分拣日结180-220/天）+ 高单价技能（剪辑300-500/条）
6. **警惕「找项目」循环陷阱**：连续3次以上查「XX 靠谱吗」且没开工 = 行为回避不是信息不足——点破循环本身，把动作压缩到最小唯一（「打开闲鱼发布服务帖，10分钟」），不再给第6个渠道

**避坑（2026-08 实测）**：一品威客会员费4.8万/年接不到单；「老外本土短剧+TikTok短剧」培训=教科书级割韭菜（保证收益=广告法违法，忙活一个月入账47.84元）；游戏搬砖「日赚千元」=卖课/脚本/云手机骗局；「免费教学+日350+」招剪辑师=皮包公司引流；任何先交钱/押金=骗局；机器人数采「日赚200」实测时薪<20元。

**AI人机分工**：AI 做交付物（文案/视频/诊断/详情页），用户做接单/沟通/收款；线下体力两者都不行。组合：用户接单→AI 30分钟交付→用户收款。
