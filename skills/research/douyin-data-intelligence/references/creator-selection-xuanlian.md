# 精选联盟达人筛选协作工作流

> 用户有精选联盟后台权限（buyin.jinritemai.com），Agent负责分析用户导出的数据。
> 2026年7月19日会话验证。

## 核心限制

Agent **不能直接访问**精选联盟后台。原因：\n1. 需要用户扫码登录 + 2FA 验证，Agent 无法代劳\n2. 自动化登录有安全风险（触发抖音风控/封号）\n3. Camofox 浏览器已配置可运行，但仅用于访问公开数据页（蝉妈妈等），不能替代用户后台登录态

**唯一路径**：用户导出数据 → Agent分析

## 用户典型筛选链（已验证）

1. 进入达人广场
2. 按结算总额从高到低排序（或按销量高到低）
3. 手动看达人当前带的品是否跟自己匹配
4. 剔除付费渠道占比高的达人（只看自然流为主）
5. 条件：V0-V1等级 / 粉丝10万以内 / 月销售额10万-500万 / 客单价19.9-399

## 用户数据提交方式

### 方式A：复制粘贴（推荐，但数据不全）
从达人广场页面全选复制，粘贴到文本中发给Agent。
**问题**：分页加载导致只能复制当前页展示的内容，部分字段（头像、标签）会丢失。

### 方式B：截屏（最可靠）
每屏截屏发过来，Agent看图分析。
1. Command+Shift+4 选区截图
2. 或 Chrome 开发者工具 → Command+Shift+P → "Capture full size screenshot"（长截图）

### 方式C：用户列名单
用户把觉得不错的达人名字/ID列出来，Agent去公开渠道查带货数据。

## 达人数据清洗指南

用户从后台复制的原始数据格式通常是：

```
达人信息
粉丝数
综合匹配度（- ）
结算总额（¥10万-25万）
直播结算总额（¥10万-25万）
视频结算总额（- / 空白）
图文结算总额（- / 空白）
橱窗结算总额（¥5,000-1万）
操作
达人头像
达人昵称
类目
地区
回复率标签（无回复/回复率低/回复率高）
潜力合作标签
有联系方式标签
能开发票标签
```

清洗要点：
- 去掉头像、操作等无分析价值的列
- 结算区间统一处理（如"¥10万-25万"取中值约17.5万）
- 标记空白/"-"为0

## 关键分析：销售渠道结构

**这是最重要的分析维度，也是用户后台看不到的洞察。**

从达人广场数据提取：直播结算、视频结算、图文结算、橱窗结算四个值。

计算占比公式：
```
总结算 = 直播 + 视频 + 图文 + 橱窗
直播占比 = 直播 / 总结算
视频+图文占比 = (视频 + 图文) / 总结算
```

### 达人分类

| 类型 | 特征 | 合作方式 | 价值评估 |
|------|------|---------|---------|
| **纯直播型** | 直播结算占90%+ | 需直播合作/坑位费，纯佣挂车无效 | 没预算就pass |
| **内容型** | 视频+图文结算占20%+ | 适合"寄样→挂车→出视频"纯佣模式 | 高价值，持续曝光 |
| **混合型** | 直播+视频都有 | 可谈直播+视频打包合作 | 最高价值 |
| **橱窗型** | 橱窗结算占比较突出 | 被动展示，达人主动推概率低 | 低价值 |

### 实战关键发现（2026年7月数据验证）

来自一次实际数据清洗：
- 10个达人中，**9个直播结算占90%+**
- 仅有1个（史瑞杰谈英语）有视频结算（25-50万），直播结算（25-50万），属于混合型
- 大部分达人"视频结算"和"图文结算"字段为空白或"-"

**结论**：精选联盟达人广场按销量排序后，大部分是直播型达人。要做纯佣/挂车模式，需要针对性地筛选有视频带货能力的达人，不能只看结算总额排序。

## 针对性建议模板

### 当用户给出一批达人数据时

**第一步：发现模式**

```
数据观察：
- N个达人中有X个直播占比90%+
- 视频带货能力强的达人：{名单}
- 橱窗型达人：{名单}
- 粉丝最低/最高：X万 / X万
- 总体结算集中在：¥10-25万区间
```

**第二步：分类优先级**

```
优先级A（最适合纯佣/挂车）：
  达人名 | 理由：视频带货占比高 | 建联切入点

优先级B（适合直播合作）：
  达人名 | 理由：直播量大，需谈坑位费/专场

优先级C（不考虑）：
  达人名 | 理由：付费占比高/类目不匹配/回复率低
```

### 当用户说"没有固定品，想跟品"

回复策略：
1. 不问用户"卖什么"
2. 问用户"想看哪个类目"
3. 用公开数据扫近期新崛起的小达人 + 他们带的爆品
4. 用户看了哪个品觉得能打，再深挖货源和佣金

**参考话术**：你不是有固定品要推，你是想刷新号在带什么爆品，然后跟着卖。这是跟品打法。

## 用户痛点记录

| 用户说了什么 | 底层问题 | 应对策略 |
|-------------|---------|---------|
| "我是全页复制的为什么少了很多" | 分页加载导致复制不全 | 给长截屏方案，不要让他继续复制粘贴 |
| "这个网站你看得到吗" (buyin.jinritemai.com) | 以为Agent能直接访问后台 | 直接回答不能+给替代方案，不要绕弯子 |
| "如何长截屏" | 卡在工具细节上 | 给最短路径方案，问品类名代替截图 |
| "我不住卖哪些品，而是在最近新崛起的账号中找到同品来打" | 跟品打法 | 转问"想看哪个类目"，用公开数据扫 |

## 注意事项

- 用户提供的达人数据中，"综合匹配度""回复率""潜力合作"等标签无法校验真伪
- 付费渠道占比数据 Agent 拿不到，依赖用户自己在后台人工剔除
- 用户说"截图"时，优先建议直接报品类名，更快
- 浏览器不可用时，不要说"等我运行浏览器"，直接给替代方案
