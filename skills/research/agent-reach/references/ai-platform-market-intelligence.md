# AI Agent平台市场情报采集（Coze/Dify等）

## 问题背景

中国AI Agent开发平台（扣子Coze、Dify、百度秒哒、腾讯元器等）的**模板商店/作品社区**通常是：
- React SPA（客户端渲染，web_extract抓不到完整内容）
- 需要登录态才能访问API
- 没有公开的销量/排名API
- 第三方数据平台（如蝉妈妈之于抖音）尚未覆盖这些新兴平台

## 核心方法：二级来源交叉验证

当平台本身是「围墙花园」时，不从平台直接爬，而从**围绕平台的生态内容**反推市场热点。

### 数据源优先级

| 优先级 | 来源 | 价值 | 说明 |
|--------|------|------|------|
| 🔴 P0 | **CSDN/火山引擎开发者社区** | 最高 | 创作者会分享自己的模板案例和销量经验 |
| 🟡 P1 | **B站教程** | 高 | 教程播放量 = 该模板方向的需求热度 |
| 🟡 P1 | **知乎专栏** | 高 | 深度分析文章常包含市场判断 |
| 🟢 P2 | **搜索引擎定向搜索** | 中 | 搜"平台名+模板+热销/排行/赚钱" |
| 🟢 P2 | **淘宝/闲鱼** | 中 | 有人倒卖模板，销量可反映真实需求 |
| ⚪ P3 | **平台官方页面（web_extract尝试）** | 辅助 | 能抓到多少算多少，作为背景参考 |

### 搜索关键词模板

```
扣子 模板 热销 排行
Coze 工作流 最受欢迎
扣子 智能体 变现 月入
{平台名} 模板商店 热门
{平台名} 卖模板 赚钱
```

### 交叉验证维度

一个模板方向是否真的好卖，至少满足以下 **2/3**：

1. **教程量大** → B站搜该方向，有多个高播放教程视频
2. **多次被搬运** → CSDN/知乎有多篇「XX工作流模板合集」包含该方向
3. **有定价参考** → 有人在卖（闲鱼/淘宝/知识付费平台），且价格在9.9-39.9元区间

## Coze模板市场关键发现（截至2025年中）

### 定价规律
- **9.9-39.9元** 是销量最好的价格带
- 超过49.9元转化率断崖下降
- 企业级模板（99-299元）单价高但销量低，适合走量的是C端小模板

### 品类分布
- **短视频/自媒体相关占~70%**，变现路径最短
- 知识卡片+书单号是当前最热方向

### 已知热销模板方向（排序不分先后）

| 方向 | 定价区间 | 目标人群 | 判断依据 |
|------|---------|---------|---------|
| 短视频爆款文案生成 | 9.9-29.9 | 自媒体创作者 | CSDN/B站教程最多 |
| 知识卡片批量生产 | 19.9-39.9 | 小红书博主 | 日更痛点最强 |
| 书单视频自动化 | 29.9-49.9 | 书单号创作者 | 量大单价高 |
| AI智能客服工作流 | 99-299 | 中小企业 | 企业采购价高 |
| 历史/知识科普短视频 | 19.9-29.9 | 知识UP主 | 涨粉刚需 |
| 心理/情感类内容 | 29.9-49.9 | 情感赛道 | 小白友好 |
| 电商主图/详情图 | 19.9-39.9 | 电商卖家 | 直接变现 |
| 直播话术生成 | 9.9-19.9 | 直播间主播 | 桌播带货可用 |
| PPT自动生成 | 免费-19.9 | 职场人群 | 泛场景流量 |
| SEO标题/标签优化 | 9.9-29.9 | 内容创作者 | 入口级需求 |

### 平台分成
- 创作者拿70-80%，平台抽20-30%
- 一个29.9元的模板，月销500单 ≈ 月入1万

## 实操流程

```
1. web_search("扣子 模板 热销") → 获取CSDN/B站/知乎文章列表
2. web_extract 逐篇提取 → 收集提到的模板名称和描述
3. 去重归类 → 按品类聚合统计出现频次
4. 搜每个方向的定价 → 在闲鱼/淘宝/知识付费验证
5. 输出为结构化表格 → 品类|定价|目标人群|判断依据
```

## 局限性

- 无法获取精确销量数据（没有蝉妈妈这类第三方）
- 热门程度是估算值，不是精确排名
- 平台随时可能改版，信息有时效性
- 需要**至少3个独立来源**确认同一方向才能视为可靠
