# B站视频真实性/推广鉴别调查指南

判断一个B站视频是**真实经验分享**还是**推广引流/割韭菜内容**。

## 一、获取准确数据（不要相信页面抓取的数字）

### B站官方API（最可靠）

```python
# 视频详情（含UP主和统计数据）
GET https://api.bilibili.com/x/web-interface/view?bvid=BVxxxxxx

# UP主空间视频列表
GET https://api.bilibili.com/x/space/arc/search?mid={UID}&ps=30&pn=1

# 视频评论
GET https://api.bilibili.com/x/v2/reply?type=1&oid={aid}&pn=1
```

### API返回的关键字段

```json
{
  "data": {
    "desc": "",          // 视频简介 — 空=可疑
    "owner": {
      "mid": 385229392,  // UP主UID
      "name": "AI智子财阀君"
    },
    "stat": {
      "view": 243774,    // 播放量
      "danmaku": 51,     // 弹幕 — << 评论通常也是此量级
      "reply": 42,       // 评论
      "favorite": 3425,  // 收藏
      "coin": 331,       // 投币
      "share": 1091,     // 分享
      "like": 1762       // 点赞
    },
    "duration": 218,     // 秒
    "tid": 21            // 分区
  }
}
```

## 二、内容真实性评分矩阵

每个项目标 ✅（真实信号）或 ❌（推广信号）：

### 1. 视频简介检查

| 检查项 | 真实分享 ✅ | 推广内容 ❌ |
|--------|------------|------------|
| 简介内容 | 有详细文字说明、链接、时间轴 | **空字符串** 或只有标签 |
| 课程链接 | 直接贴在简介里（正规B站课堂/独立平台） | 不在B站留痕，引导私域 |

> ⚠️ **简介为空是最大的红旗** — 真实创作者会留文字；引流号不留痕迹防举报

### 2. 互动数据异常检测

| 指标 | 正常范围 | 推广/刷量特征 |
|------|---------|--------------|
| 弹幕/播放比 | >0.1%（24万播→至少240条弹幕） | **<0.05%**（24万播只有51弹幕） |
| 评论/播放比 | >0.02%（24万播→至少48条评论） | **接近0或远低于播放量级** |
| 投币/点赞比 | 通常<50% | 如果投币>点赞，说明引导投币 |
| 收藏/播放比 | 1%~5%正常 | 过高（>8%）可能是收藏型标题党 |
| 视频时长 | >5分钟才有干货 | **<4分钟**讲不了实质内容 |

### 3. UP主画像分析

从 UP主空间（`space.bilibili.com/{mid}`）检查：

```
访问UP主空间 → 看所有视频标题列表
```

**推广号特征：**
- 粉丝少但播放量高（3000粉却有24万播放）→ 投了推广
- 所有视频标题高度统一：全带"搞钱""翻身""副业""躺平"
- **同一封面用在多个不同BV号的视频上**（批量号铁证）
- 视频密集发布（一天发几条）
- 关注数极少（如关注10人，被3000人关注）
- 专栏文章数为0

**真实创作者特征：**
- 粉丝数与播放量成正比
- 内容主题多样化
- 有个人介绍/签名
- 有专栏文章、合集

### 4. 课程/培训机构溯源

推广视频的课程转化路径通常不在B站留证据：

```
视频内容暗示"想学的加我" → 引导到微信/公众号 → 私域卖课
```

溯源方法：
1. 搜索 `"UP主名" 课程`、`"UP主名" 收费`、`"UP主名" 骗子`
2. 检查视频中口播的微信号/公众号名称
3. 搜索小红书/知乎有没有曝光该UP主的帖子
4. 查看视频下方B站推广广告链接（有时会透出关联域名）

### 5. B站平台自带信号

| 信号 | 说明 |
|------|------|
| 视频有"推广"角标 | B站官方标注的商业合作内容 |
| 推荐位广告卡片 | 视频下方的跳转外链广告 |
| UP主课堂 | 正规B站课堂课程不会走私域 |

## 三、综合评分卡

```
内容可信度评分: ___/10

扣分项：
- □ 简介为空                     -3
- □ 弹幕/播放比 < 0.05%         -2
- □ 视频时长 < 4分钟             -2
- □ UP主粉丝少但播放量高         -1
- □ 标题含"躺平""翻身""暴富"     -1
- □ 同封面发多个视频             -2
- □ 所有视频都是同一套路         -1
- □ 无专栏文章                   -1
- □ 关注数极少                   -0.5

加分项：
- □ 有详细简介+时间轴            +2
- □ 评论区有真实讨论             +1
- □ UP主有长期内容历史           +1
- □ 引用具体数据/案例来源        +1
```

## 四、B站 API 调用注意事项

- B站API在国内可直接调用，但本环境（Linux容器）可能因墙超时
- 使用 `execute_code` + `web_extract` 代替 `curl` 可绕过部分限制
- URL格式：`https://api.bilibili.com/x/web-interface/view?bvid=BVxxx`
- 无需登录即可获取视频详情和UP主信息
- 评论API需要oid（aid），不是bvid
