# 🚀 通用流量获客SOP（零成本版）

> 核心思想：**AI批量生产内容 → 全平台自动分发 → 私域沉淀 → 裂变放大**
> 适用：小白/一人公司/小团队 | 成本：0元（除服务器） | 周期：3-6个月见收入

## ⚠️ 先过这一关再往下看

AI时代产品供给无限，缺的是**每天雷打不动发内容的人**。

过不了这关，这套SOP等于零：

- [ ] 能不能每天花1小时做内容，连续30天不中断？
- [ ] 数据惨淡的3-7天，能不能继续发？
- [ ] 能不能在分析/讨论/找方向的时候，直接说"先发一篇再说"？

过不了 → 关掉这个文件。问题不是方法论，是执行纪律。
过了 → 下面每一步都对你有用。

---

## ⚠️ 方法论型内容的残酷现实

你的方法论深不等于能卖内容。短视频平台用户要的是：
- 「揉碎喂嘴里的具体动作」— 明天干什么、怎么说、怎么写
- 「马上能赚钱的结果」— 不是学框架，是学怎么收款

**方法论的正确用法：藏在后台做分析工具，前台只展示「具体结果」。**

| 展示方式 | 标题 | 效果 |
|---------|------|:----:|
| ❌ 方法论直接输出 | 「创业者必学的红蓝七步分析法」 | 划走 |
| ✅ 结果前置，方法论隐身 | 「我帮粉丝拆了个XX项目，结论是不能做，原因3点」 | 看完+收藏 |

如果用户卖的是方法论型产品（决策框架/分析工具/商业模型），策略应该是：
1. 免费帮具体的人分析具体的问题，攒案例
2. 用案例截图证明"这套方法有效"
3. 把模板做成低价产品（¥19.9-39.9），而不是卖方法论课程

## 一、选品后的第一件事：建人设

不要直接卖产品，先建人设。中国人买的是「信任」不是「功能」。

### 人设模板（任选一个，直接套）：

| 人设类型 | 话术基调 | 适用产品 | 头像风格 |
|---------|---------|---------|---------|
| **技术极客** | "我做了一个AI工具，3秒搞定XX" | 工具类SaaS/小程序 | 深色背景+代码 |
| **宝妈亲测** | "我家娃用了这个，爱不释手" | 童书/教育/育儿 | 温馨生活照 |
| **行业专家** | "做了10年电商，告诉你一个秘诀" | 电商工具/选品 | 职业照 |
| **大学生逆袭** | "靠这个副业，我月入5万" | 赚钱/考证/约会 | 清新生活照 |
| **省钱达人** | "花了9.9元，解决了大问题" | AI写真/证件照 | 真实自拍 |

**规则：不换人设，不换头像，不换昵称。** 一个号只做一个细分。

## 二、内容生产流水线（AI全自动）

### 2.1 每天产出矩阵

| 平台 | 内容类型 | 每天数量 | 耗时 |
|------|---------|---------|------|
| 小红书 | 图文笔记 | 3-5篇 | AI 15分钟 |
| 抖音/视频号 | 短视频 | 2-3条 | AI 30分钟 |
| 闲鱼 | 商品贴 | 5条 | AI 10分钟 |
| 知乎 | 问答回答 | 2条 | AI 10分钟 |

**日总耗时：约1小时（全用AI）**

### 2.2 AI内容生产模板

通用模板，以后新产品来了直接填参数：

**小红书图文模板：**
```
标题：{痛点/数字}/{好奇钩子}
正文：
1. {共情开头 — 我曾经也...}
2. {发现这个产品/工具的过程}
3. {具体使用效果 — 配图}
4. {引导互动 — 评论区见}
标签：#相关热点话题 #产品关键词
配图：AI生成场景图 × 4-6张
```

**短视频脚本模板：**
```
0-3秒：痛点钩子（"你是不是也..."）
3-15秒：展示产品核心功能
15-40秒：具体使用场景
40-50秒：效果对比/数据
50-60秒：行动引导（评论区/私信）
```

### 2.3 批量生产指令

每次新产品，直接用以下Prompt批量生产一周内容：

```
你是一个小红书/抖音内容运营专家。
产品：{产品名称}
目标用户：{用户画像}
核心卖点：{3个卖点}
目标平台：{小红书/抖音/闲鱼}

请生成7天每天3篇的内容矩阵。
每篇包含：标题、正文、标签、配图建议。
风格要求：真实、不说教、有故事感。
输出格式：表格（日期|平台|标题|正文|标签）
```

## 三、全平台发布流程

### 3.1 平台选择矩阵

| 平台 | 适合产品 | 优先级 | 核心策略 |
|------|---------|:-----:|---------|
| **小红书** | 写真/绘本/育儿/情感 | 🥇 | 图文笔记 + 评论区引流 |
| **闲鱼** | AI写真/证件照/代做 | 🥇 | 直接挂商品，成交最快 |
| **抖音** | 工具展示/效果对比 | 🥈 | 短视频 + 直播展示 |
| **视频号** | 考证/育儿/老年 | 🥈 | 微信生态转发裂变 |
| **知乎** | 考证/工具/专业类 | 🥉 | 回答"如何""什么"类问题 |

### 3.2 发布节奏

| 周期 | 动作 | 每日耗时 |
|------|------|---------|
| 第1-7天 | 每天发布3-5条，不计较数据 | 1小时 |
| 第8-14天 | 追热点/蹭评论区，优化爆款方向 | 30分钟 |
| 第15天起 | 只放大爆款，砍掉0互动内容 | 15分钟 |

### 3.3 批量发布工具

用 Spreado CLI 或 浏览器自动化实现多平台自动发布。
- 所有内容先存一个 `content/` 文件夹
- 日期命名：`20260713_产品名_序号`
- 一次配置，永久复用

## 四、转化漏斗（私域/成交）

### 4.1 漏斗模型

```
公域流量（小红书/抖音/闲鱼/知乎）
    ↓ 免费内容引流
私域池（微信个人号/社群）
    ↓ 3天信任建立
低价体验（9.9-49元）
    ↓ 价值证明
正价产品（99-499元）
    ↓ 超预期交付
转介绍/裂变
```

### 4.2 各阶段转化工具

| 阶段 | 工具 | 自动化程度 |
|------|------|----------|
| 内容发布 | 脚本/手动（前期） | 20% |
| 评论区引流 | 预设话术，手动回复 | 30% |
| 私信回复 | 预设关键词自动回复 | 50% |
| 微信承接 | 自动通过+打招呼 | 100% |
| 社群运营 | AI自动发内容+维护 | 80% |
| 成交收款 | 小程序/收款码 | 100% |

### 4.3 私信话术模板（可复用）

**承接话术（用户问"这是什么"）：**
```
"这个{产品名}是我们做的{一句话卖点}，
现在可以免费试用/特价体验，
加我微信：{微信号}，我发给你～
不需要也没关系，先了解了解～"
```

**转化话术（用户犹豫）：**
```
"理解，我一开始也担心。
这样，你先试用3天，不满意随时停，
没有任何风险。"
```

**复购话术（用户体验后）：**
```
"用的怎么样？有没有遇到什么问题？
最近有个{新功能/活动}，老用户专享价，
要不要了解一下？"
```

## 五、裂变放大（零成本）

### 5.1 裂变机制（通用版）

| 方式 | 执行方法 | 裂变系数 |
|------|---------|:-------:|
| **老带新** | 推荐1人送7天/送1单 | ×1.2-1.5 |
| **社群任务** | 发朋友圈截图换资料 | ×1.5-2 |
| **拼团** | 3人成团打7折 | ×2-3 |
| **内容UGC** | 用户晒单@官方抽奖 | ×1.3-1.8 |

### 5.2 钩子素材包

每个新产品都先准备好这5个钩子：

1. **免费资料** — 《XX行业XX页干货指南》（低制作成本，高价值感）
2. **体验券** — 3天免费试用/免费1单
3. **效果展示** — 前后对比图/数据差值
4. **限时优惠** — 首周5折/买一送一
5. **稀缺性** — 限量100份/仅限前50名

提前存到 `~/Desktop/hermes/hooks/` 文件夹，新产品直接调。

- [ ] 准备3套私信话术（承接/转化/复购）
- [ ] 设置裂变机制（老带新/拼团/社群任务）

- [ ] 第15天：私域到200人启动裂变

## 八、关键原则

1. **内容>产品** — 用户先被内容吸引，才被产品转化
2. **先免费后收费** — 免费试用/体验版建立信任，再推正价
3. **爆款复制** — 一篇爆了，用同一结构出10篇变体
4. **私域为王** — 公域流量不留存等于没做
5. **日更不中断** — 断更3天，数据降50%
