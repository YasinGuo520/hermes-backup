# 扣子(Coze) 智能体模板设计开发指南

## 核心认知：Coze 模板生态

Coze（扣子）有三大内容分发渠道，模板开发者的机会主要在 **模板商店**：

| 渠道 | 链接 | 性质 | 变现模式 |
|------|------|------|---------|
| 模板商店 | coze.cn/template | 付费模板市场 | 用户按次/买断付费，平台抽佣20-30% |
| 作品社区 | coze.cn/store/agent | 免费/付费智能体 | 智能体内支付、订阅 |
| AI 模版库 | coze.cn/gallery | 免费AI预设（写作/PPT/设计等） | 官方提供，不可变现 |

**赛道热度排序（2025-2026）：**
1. 短视频/自媒体相关 — 占模板市场约70%，变现路径最短
2. 电商带货文案/商品图 — 卖家刚需，复购率高
3. 企业客服/工作流 — 单价高但销量低（¥99-299）
4. 知识卡片/书单视频 — 模板商店最热细分赛道

**主流定价带：**
- ¥9.9-19.9：薄利多销，适合冲销量冲首页
- ¥19.9-39.9：主力价格带，转化率最高
- ¥49.9+：需要强信任背书或企业级功能

## 工作流程

### Step 1: 产品定位

用 `web_search` 搜索扣子模板商店的同类产品：
- `coze.cn 模板 {关键词}`
- `扣子 {功能} 模板 热销`

**关键问题确认（用 `clarify` 向用户）：**
- 用户是谁？（内容创作者/电商卖家/企业）
- 解决什么问题？（文案/设计/客服/数据分析）
- 定价多少？（参照同类模板）
- 用户想上架卖还是自用？

### Step 2: 模板结构设计

一个完整的 Coze 模板包含以下组件：

#### 2.1 智能体配置（Bot Config）

| 组件 | 说明 | 必填 |
|------|------|:----:|
| 人设与回复逻辑 | 角色设定 + 工作流程 + 输出规范 | ✅ |
| 模型选择 | DeepSeek-R1（推荐）或豆包Pro-32k | ✅ |
| 插件 | 按功能选配（视频下载/字幕提取/搜索等） | 视功能 |
| 知识库 | 上传参考素材提升效果（可选但提分） | 可选 |

**人设提示词结构模板：**
```markdown
# 角色
你是[角色名]，[身份描述+经验背书]

# 核心能力
1. [能力1]：[一句话说明]
2. [能力2]：[一句话说明]

# 工作流程
当用户输入[触发条件]时：
1. → 调用 [工作流A] 执行[任务]
2. → 输出[格式规范]

# 输出规范
- [格式要求1]
- [格式要求2]
```

#### 2.2 工作流设计（Workflow）

**常见工作流节点类型：**

| 节点类型 | 用途 | 示例 |
|---------|------|------|
| 开始节点 | 定义输入参数 | video_url, product_name |
| LLM节点 | 调用大模型 | 分析文案、生成内容 |
| 插件节点 | 调用外部工具 | 视频下载、字幕提取、搜索 |
| 代码节点 | 执行Python/JS | 数据处理、格式转换 |
| 条件分支 | 按条件分流 | if/else逻辑 |
| 循环节点 | 重复执行 | 批量处理 |
| 结束节点 | 输出结果 | 返回生成内容 |

**工作流设计原则：**
1. **最少节点原则** — 能用3个不做5个，每个多余节点增加故障率
2. **模型一致性** — 同一工作流内尽量用同一模型（避免幻觉不连贯）
3. **输入校验** — 开始节点做必要参数验证
4. **管道设计** — 前一个节点的输出就是后一个节点的输入，保证数据流连通
5. **兜底输出** — LLM节点设置默认输出，防止空结果

### Step 3: 开发实现（两种方式）

#### 方式A：纯扣子模板（上架卖钱）
直接在 coze.cn 上通过可视化界面拖拽搭建。

**创建步骤：**
1. 登录 coze.cn → 创建智能体
2. 填人设与回复逻辑（见上面的提示词模板）
3. 创建工作流（资源库 → 工作流 → 新建）
4. 配置各节点（开始→插件→LLM→结束）
5. 绑定工作流到智能体
6. 预览调试 → 测试通过后发布
7. 上传模板商店 → 填写标题/描述/标签/定价

#### 方式B：本地Python工具（自用/面向技术用户）
用 DeepSeek API + OpenAI 兼容接口写命令行工具。

**本地工具标准结构：**
```
#!/usr/bin/env python3
from openai import OpenAI

# 配置管理（优先级：环境变量 > 配置文件 > 交互输入）
CONFIG_FILE = os.path.expanduser("~/.{tool_name}_config.json")

def load_config():
    key = os.environ.get("API_KEY", "")
    if not key and os.path.exists(CONFIG_FILE):
        with open(CONFIG_FILE) as f:
            cfg = json.load(f)
            key = cfg.get("api_key", "")
    if not key:
        key = input("输入 API Key: ")
        # 保存到配置文件
    return key
```

**推荐模式：先做本地工具验证逻辑 → 验证通过再做扣子版上架**

### Step 4: 测试与发布

**测试Checklist：**
- [ ] 每个输入字段都填值测试
- [ ] 空值/边界值测试
- [ ] 插件节点测试（API是否正常返回）
- [ ] LLM节点输出格式测试
- [ ] 全链路测试（开始→结束）
- [ ] 多轮对话测试（智能体记忆是否正常）

**发布渠道优先级：**
1. 扣子模板商店（自然流量最大）
2. 抖音/B站发演示视频（带购买链接）
3. 小红书教程（引流到模板商店）
4. 私域朋友圈/群（已有信任基础）

### Step 5: 推广与运营

**定价策略：**
| 阶段 | 价格 | 策略 |
|------|------|------|
| 冲量期（前100单） | ¥9.9 | 快速积累销量和好评 → 冲上首页推荐 |
| 稳定期（100-500单） | ¥19.9 | 正常定价，走量为主 |
| 成熟期（500单+） | ¥29.9-39.9 | 品牌溢价 |

**推广话术模板（短视频/笔记）：**
- 标题：`扣子上这个模板让我[效果]，[数字]分钟搞定[任务]`
- 内容：`以前要花[时间]做的事，现在用扣子模板[操作步骤]，[结果]`

## 用户格式偏好（此用户）

此用户是**带货变现导向**，设计模板时要：
- 每个模板包含**完整可复制的人设提示词**（直接能用）
- 工作流节点列出**所有配置参数**（字段名/类型/输入来源）
- 必须包含**定价建议和推广策略**（用户要上架卖）
- 如果设计本地工具，必须 **支持配置文件持久化**（环境变量不可靠）
- 提供 **双版本方案**：扣子版上架卖 + 本地版自用

## 常见陷阱

| 陷阱 | 避免方法 |
|------|---------|
| 扣子平台是React SPA，API需登录态 | 设计文档让人工配置，不要尝试直接调用扣子API |
| 模板设计只写描述不写可复制内容 | 所有提示词、节点配置必须**完整可复制粘贴** |
| 忽略平台抽佣成本 | 定价时预留30%平台抽佣空间 |
| 一次只做模板，不做本地验证 | 先做本地Python工具验证逻辑，验证通过再上扣子 |
| 完美主义拖延 | 最小可行模板先上架，后续迭代优化 |
| 不关注用户终端使用门槛 | 非技术用户可能不知道"终端运行"是什么，提供一键alias方案 |
