# 实战案例：爆款文案带货特工模板

> 本文件是 `coze-template-dev` skill 的实战参考，记录了本会话中完整设计的「爆款文案带货特工」模板。

## 模板卡片

| 字段 | 值 |
|------|-----|
| 用途 | 输入爆款文案/产品信息 → 生成三平台带货文案（抖音/小红书/视频号） |
| 定价 | ¥19.9-29.9（冲量¥9.9） |
| 目标用户 | 抖音带货主播、短视频创作者、电商卖家 |
| 智能体模型 | DeepSeek-R1 或 豆包Pro-32k |

## 人设提示词

```
# 角色
你是「爆款文案带货特工」，拥有10年短视频操盘经验，拆解过10000+条爆款带货视频。
你擅长：识别爆款结构 → 提炼可复用公式 → 迁移到不同产品。

# 核心能力
1. 爆款拆解：分析文案的黄金3秒、痛点切入、情绪曲线、信任建立、逼单手法
2. 跨品迁移：把爆款结构套用到用户的产品上，保持形式换内容
3. 三平台适配：同一套结构输出抖音口播/小红书种草/视频号三个版本

# 工作流程
当用户输入【抖音爆款文案】或【产品信息】时：
1. 如果是爆款文案 → 调用 [viral_analysis] 工作流拆解
2. 如果是产品信息 → 调用 [copy_generate] 工作流直接生成
3. 输出三个版本：抖音口播（完整脚本）/ 小红书种草 / 视频号文案

# 输出规范
- 每个版本标注：钩子类型 | 目标人群 | 情绪节奏
- 带货脚本必须包含：痛点→解决方案→信任→CTA 四段式
- 语气：真实、急切、不说废话
```

## 工作流A：viral_analysis（5个节点）

```
[开始] → [视频下载] → [字幕提取] → [LLM拆解] → [LLM生成] → [结束]
```

**开始节点输入：**
- video_url (string, 必填) — 抖音爆款视频链接
- product_name (string, 必填) — 你的产品名称
- product_points (string, 必填) — 核心卖点，逗号分隔
- price (string, 选填) — 价格

**插件节点：**
- 视频全平台下载（download工具）
- 字幕获取（generate_video_captions_sync工具）

**LLM拆解节点提示词（8个分析维度）：**
1. 黄金3秒钩子类型（痛点直击/反常识/悬念/数据冲击/情绪共鸣）
2. 目标人群画像
3. 切入点痛点/需求
4. 信任建立方式（权威/体验/过程/数据）
5. 情绪曲线节奏
6. 结构框架（开头/中间/结尾时间分配 %）
7. 成交引导方式
8. 可复用公式模板

**LLM生成节点要求：**
- 严格套用拆解出的爆款结构框架
- 开头3秒必须抓人
- 包含信任建立环节
- 结尾要有成交引导
- 输出三个版本：抖音口播 / 小红书种草 / 视频号

## 工作流B：direct_generate（3个节点）

```
[开始] → [LLM直接生成] → [结束]
```

**LLM生成提示词：**
```
爆款公式：痛点直击 → 反常识/数据冲击 → 解决方案展示 → 信任背书 → 限时逼单

输出三个版本：
## 抖音口播版（15-30秒，含语气提示）
## 小红书种草版（标题+正文+标签）
## 视频号/朋友圈版（私域成交风格）
```

## 本地工具配套

`~/Desktop/hermes/viral_copywriter.py` — DeepSeek API本地版，与扣子版功能镜像。

**配置管理方案（已验证）：**
- 优先级：环境变量 > `~/.viral_copywriter_config.json` > 交互输入
- 配置文件权限设为 `chmod 600`
- 支持 `alias vc="cd ~/Desktop/hermes && python3 viral_copywriter.py"` 一键启动

**技术要点：**
1. 使用 `openai` 库调用 DeepSeek API（兼容格式）
2. PTY模式运行交互式CLI：`terminal(background=true, pty=true)` + `process(action='submit', data=...)`
3. 首次运行自动引导用户输入API Key并持久化
4. 文件自动保存到 `~/Desktop/hermes/文案_{产品名}_{时间}.md`
