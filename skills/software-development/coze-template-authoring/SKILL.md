## 环境概览

- **国内版：** https://www.coze.cn（主要目标平台）
- **国际版：** https://www.coze.com
- **模板商店：** https://www.coze.cn/template（需登录，React SPA，无公开API）
- **作品社区：** https://www.coze.cn/store/agent
- **AI模版库（免费）：** https://www.coze.cn/gallery

## 设计流程

### Step 1：需求定位

确认用户要做的模板类型：
- **C端小模板（¥9.9-¥39.9）：** 短视频文案/小红书笔记/电商主图/书单视频/直播话术——走量
- **B端企业模板（¥99-¥299）：** 智能客服/销售陪练/数据分析——单价高但销量低
- **技能插件（Skill）：** 调用分成模式，被动收入

> **销量最好的C端方向（交叉验证自CSDN热帖/火山引擎文章/B站教程）：**
> 1. 短视频爆款文案生成 → ¥9.9-29.9
> 2. 小红书知识卡片批量生产 → ¥19.9-39.9
> 3. 书单视频自动化 → ¥29.9-49.9
> 4. AI智能客服工作流 → ¥99-299（企业）
> 5. 历史/知识科普短视频 → ¥19.9-29.9
> 6. 商品详情图/电商主图生成 → ¥19.9-39.9
> 7. 抖音口播/直播话术 → ¥9.9-19.9
> 8. AI PPT生成 → 免费-¥19.9

### Step 3：工作流节点类型速查

| 节点类型 | 说明 | 典型配置 |
|---------|------|---------|
| **开始节点** | 定义输入参数 | 字段名+类型+描述+是否必填 |

### Step 5：构建配套本地工具（重要）

对于每个C端模板方向，**同时构建一个本地Python工具**。原因：
1. **用户马上能用** — 不等扣子审核上架
2. **验证工作流** — 跑通逻辑后再搬上扣子，减少调试成本
3. **差异化竞争** — 扣子模板可卖，本地工具自用，双线并行

**本地工具构建规范：**

```yaml
技术栈:
  语言: Python 3
  API: DeepSeek API（兼容OpenAI SDK）
  配置: 首次运行交互输入 → 保存到 ~/.<tool_name>_config.json
  部署: ~/Desktop/hermes/<tool_name>.py
  调用: 给用户配 alias（如 alias vc="cd ~/Desktop/hermes && python3 <tool>.py"）

用户终端偏好:
  - 用户对终端操作不熟悉/有抗拒
  - 必须给 alias（2-3字母），不要长命令
  - 工具使用说明=一句话+一个命令，不要解释pip/python/环境
  - 在后台帮用户运行（background+pty模式），做完告诉他结果

Python环境注意:
  - 用户mac的python3路径是 /Users/mac/.video-maker/runtime/python/bin/python3
  - pip3 install要用这个路径的pip（否则装错环境）
  - DeepSeek API Key 存在 ~/.hermes/.env，用 terminal+grep 提取
```

**工具设计模板：**
```python
# 两种模式：
# 模式A：输入参考素材 → AI分析 → 生成用户版本
# 模式B：直接输入需求 → AI生成
#
# 输出：保存到 ~/Desktop/hermes/内容_<产品名>_<时间戳>.md
```

## 用户偏好

- 用户是做抖音带货的，模板设计要**带货向优先**
- 输出必须附带**本地Python工具**，不等扣子审核，马上能用
- 模板文档要**完整到可以直接复制粘贴**，不留空
- 不要爬扣子模板排行（无公开API），用交叉验证法推断热门方向
- 工作流中的LLM提示词必须完整，变量引用用 `{{变量名}}` 格式

## 注意事项

1. **扣子是React SPA**——不登录拿不到数据，不要尝试无痕爬取
2. **DeepSeek-R1是扣子上性价比最高的模型**——分析任务首选
3. **C端模板¥19.9是黄金价格带**——超过¥49.9转化率断崖
4. **工作流一定要测试**——LLM节点变量引用格式错误会导致整个工作流报错
5. **定价要留余量**——模板商店会做促销，¥19.9折后¥9.9也还有赚
