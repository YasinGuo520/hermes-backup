# Frontend Design（前端设计）

当你需要构建新UI或改造现有界面时，遵循以下设计流程。

## 设计原则

1. **主题先行** — 用主题本身的世界观、材料、工具、文化语言来驱动设计选择
2. **排版即个性** — 展示字体和正文字体要刻意搭配，不要用默认组合
3. **结构即信息** — 用编号、分割线、标签等结构元素编码真实信息，不只是装饰
4. **动效应服务内容** — 有选择地使用动画，每次动效都要有目的
5. **复杂度要匹配** — 极简设计需要精确的间距/字体/细节；繁复设计需要完整的执行

## 设计流程

### 第一轮：头脑风暴
创建一个紧凑的设计标记系统：
- **颜色**：4-6个命名色值的调色板
- **字体**：2+个角色的字体（展示字体+正文字体+工具字体）
- **布局**：一个布局概念，用一句描述+ASCII线框图
- **签名元素**：这个页面会被记住的一个独特元素

### 第二轮：自我审查
在写代码前检查：这个设计是"为这个主题专门做的"还是"套模板的"？
- 如果换一个完全不相关的主题这个设计还"成立" → 重做
- 明确说了改了哪里、为什么改

### 第三轮：构建+再审查
- 写完代码后截图自我审查
- 找出至少一个问题再宣布完成

## 个人主页 / 个人品牌页设计

当用户要做「个人主页 / 个人品牌页 / 博主落地页」时，遵循：

### 第一步：先定定位（决定一切，先问再动手）

| 类型 | 核心目的 | 页面重点 |
|------|---------|---------|
| 求职/作品集 | 证明能力 | 作品案例 > 自我介绍 |
| 个人品牌/博主 | 建立信任、导流 | 方法论、内容、联系方式 |
| 工具/产品官网 | 转化付费 | 产品演示、价格、CTA |
| 纯个人名片 | 让别人找到你 | 一句话+头像+链接 |

### 第二步：信息架构（通用骨架）

```
Hero区（第一屏，3秒抓住人）：一句话定位 + 身份标签 + 主CTA
信任区：数据/高光履历/Logo墙
作品/方法论区：3-6个精选案例，图大字少
关于我：3-5行，有人格不油腻
收尾CTA：再次引导 + 社媒/联系方式
```

### 第三步：内容组织要点

- Hero 主文案**一行说清定位**，副行给证据（年限/成绩/身份），不要"你好我是XX"
- 案例用**叙事钩子**："我用X方法，3天否掉了一个看似蓝海的项目"
- 数据背书用具体数字（年限/销售额/效率提升），不写虚的
- 关于我写成**成长线**（入行→转折→现在），不是简历时间轴平铺

### 第四步：简历页 → 个人主页的转化（常见需求）

- 保留简历里**全部真实素材**（业绩数字、项目、学历、联系方式）
- 但叙事从「求职证明自己」改成「品牌展示价值」：结构化方法论 + 案例墙 + 数据背书
- 求职信息（期望薪资/期望城市/性别年龄标签）删掉，换成品牌定位
- 英文名/品牌名放Hero最显眼处

### 第五步：Hero 区排版 — 简约高端大气配方（用户校准过）

第一屏的黄金标准：**极简 = 高端**。信息越密越廉价。

**自上而下结构（元素宁少勿多）：**
1. 一行小字 mono 英文点缀（`E-COMMERCE × AI AGENT · EST. 2008`），letter-spacing .4em+，uppercase
2. **巨型英文名**（`YASIN`）：mono 字体，weight 800，`font-size:clamp(4.5rem,15vw,9.5rem)`，line-height 1
3. 细竖线分隔（1px 高 ~50px，红蓝渐变）——不要横线，竖线更大气
4. **中文标语一行**：weight 300 细体 + `letter-spacing:.4em` + `text-indent:.4em`（平衡末字间距），短句 6-8 字内
5. 一行小字 mono meta（`GUO YUEXING · 18 YEARS · SCUT CS`）
6. 两个 CTA 按钮，文案两字内

**中英排版大气感来源：** 巨型粗体英文 × 纤细大字距中文的**字重对比** + 大留白，不是字体多花哨。

**Pitfalls（用户逐条纠正过）：**
- ❌ 首屏堆信息：大段副标题/红蓝流程条/标签行/meta 徽章全放 Hero = "废话太多"。全部砍掉。
- ❌ 英文名后加装饰点（`YASIN.`）→ 不协调，去掉。
- ❌ 英文名纯白 → 用户要渐变：`background:linear-gradient(...)` + `background-clip:text` + `-webkit-text-fill-color:transparent` + `filter:drop-shadow()` 做光晕（注意：text-shadow 对透明渐变文字无效，必须用 filter）。
- ❌ 标语写成长定位句（"帮创业者少踩坑的实战派"）→ 太啰嗦。浓缩短句："决策，不靠感觉"。
- ❌ 按钮带箭头/长文案（"看方法论 →"）→ 两字："方法论" / "案例"。

## 避免的设计（AI常见默认值）

- ❌ 暖白背景(#F4F1EA)+衬线字体+陶土色强调
- ❌ 纯黑背景+荧光绿/朱红强调
- ❌ 报纸式布局+细分割线+零圆角+密集列
