# 生日/庆祝页设计模式

> 2025-07-24 为 Yasin 女儿郭泽莹 13岁生日页面设计过程中发现和验证的模式。下次做同类页面直接套。

## 调研来源

搜索 `best birthday website design inspiration` 后发现的关键项目：

| 项目 | 亮点 | 参考价值 |
|------|------|---------|
| **Birthday Bloom** (naborajs/birthday-bloom) | 多阶段叙事引擎，Framer Motion，环境变量驱动 | 叙事节奏设计 |
| **Birthday V4** (sapthesh/Birthday-V4) | 故事书式五步揭示，3D CSS翻页 | 悬念构建方式 |
| **Netflix Birthday** (py-kalki) | 影院级开场+profile选择+滚动credits | 沉浸感打造 |
| **Interactive Birthday Blast** | Party popper互动，3D倾斜玻璃卡片 | 交互趣味性 |

## 核心模式：多阶段叙事

```
阶段1: 名字逐字弹出（200ms/字，弹性cubic-bezier）
  ↓ 1.2s 停顿
阶段2: 副标题/年龄信息淡入
  ↓ 2s 停顿  
阶段3: 主视觉元素（吧唧/徽章）从下方弹入 + 轨道光环旋转
  ↓ 1.5s 停顿
阶段4: 祝福文字打字机效果逐行显现（600ms/行）
  ↓ 同时：浮动装饰开始出现
阶段5: 交互元素激活（礼物盒/气球/音乐）
```

## 技术实现要点

### Canvas流动星光
- 120-150颗粒子
- 每颗有trail数组（10-12个历史点）
- 逐步降低透明度绘制拖尾
- 连接距离150px内的星星（浅紫色连线）
- 方向：斜上漂移 + 随机水平抖动

### 多阶段切换
```javascript
// 不要用scroll，用timeline setTimeout
chars.forEach((ch,i)=> setTimeout(()=> ch.classList.add('show'), i*200));
setTimeout(()=> stage2.classList.add('show'), nameRevealTime + 2800);
setTimeout(()=> stage3.classList.add('show'), nameRevealTime + 5000);
```

### Confetti物理引擎
- 150-200片，随机角度+速度
- 重力0.2，阻力0.97
- 旋转+透明度衰减
- 生命周期150-300帧

### 吧唧设计
- 多层圆环（3层不同速度旋转）
- 5个小卫星粒子沿轨道飞旋
- 内圈渐变+脉冲发光
- 头像居中（130px圆形，支持图片替换）

## Yasin的偏好（从本次对话提取）

- 大气 = 深色背景 + 全屏撑满 + 环境光晕
- 不要居中卡片，要沉浸感
- 不要一次显示完所有内容
- 交互要有（点击放彩花/礼物盒/点气球爆炸）
- 先调研再动手，不要凭感觉写
- 凹凸/二次元元素：旋转星、水晶、菱形图案
- 文案直接、不肉麻、有性格感
