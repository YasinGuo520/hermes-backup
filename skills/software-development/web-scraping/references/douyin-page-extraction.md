# 抖音视频页内容提取（无需登录）

场景：用户发抖音分享短链（v.douyin.com/xxx），要分析视频内容/数据/评论区。

## 方法

1. `browser_navigate` 打开短链 → 自动 302 到 `www.douyin.com/video/{aweme_id}`
2. 页面会弹「登录后免费畅享高清视频」——不用管，视频本体看不到，但**整个页面的文本数据都在 DOM 里**
3. `browser_console` 执行 `document.body.innerText` 提取全文（长页面先取前 6000 字符）
4. 也可以直接跑 JS 精确抓某个元素

## 无需登录即可拿到的数据

| 数据 | 说明 |
|---|---|
| 标题 + 话题标签 | heading 元素，含全部 #tag |
| 官方章节要点 | 「章节要点」区域：AI 生成的分段总结+时间戳，**快速还原视频叙事的捷径** |
| 互动数据 | 顺序出现：点赞 → 评论 → 收藏 → 分享 |
| 作者信息 | 昵称、粉丝数、获赞数 |
| 评论区 | 含作者回复；「请先登录后发表评论」不遮挡已有评论 |
| 推荐视频 | 同领域视频标题+点赞数（能看出博主内容矩阵） |
| 作者声明 | 「内容由 AI 生成」标记 |

## 要点

- **不要用 browser_vision 截图分析内容**——只会看到登录弹窗；用 innerText
- 评论区作者回复是金矿：博主真实意图、工具分工、对争议的回应都在里面
- 收藏/点赞比 >1 是实用型教程内容信号（用户存起来以后用）；评论少=内容没争议性
- 章节要点带时间戳，直接还原视频结构（引言→介绍→实操→结语）
- 数据顺序固定：点赞/评论/收藏/分享（173=分享是最后一个）
