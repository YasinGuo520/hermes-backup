# Content Polish 中文 — 文档美化排版

## 核心原则（用户偏好，不可违反）

1. **保留原文全部内容**，不浓缩、不删减、不改写。用户要的是格式美化，不是内容重写。
2. 只优化：结构层级、段落分段、排版格式、视觉呈现（颜色/高亮/表格）。
3. 原文的每一项要点、每一条数据、每一个标题，必须全数保留。
4. 如果用户说"帮我美化简历"，输出格式优先：**A4 PDF**（用 weasyprint HTML→PDF）。

## 排版规范（中文简历/文档）

- 分节清晰：个人优势 / 工作经历 / AI Agent体系 / 教育背景
- 工作经历按公司分块，每块包含：公司名称 + 时间段 + 职位 + 详细职责（保留原文全部条目）
- 数据/量化结果用高亮标注（绿色或品牌色）
- AI相关能力用标签+效果标注独立展示，不混在正文段落里
- 表格式信息（如Agent能力对比）用网格/卡片布局，比纯表格更直观

## PDF 输出流程

```bash
# 1. 创建排版好的 HTML 文件（A4打印格式）
#    @page { size: A4; margin: 1.8cm 1.5cm; }

# 2. weasyprint 转 PDF
pip install weasyprint  # 首次安装
python -m weasyprint input.html output.pdf

# 3. 验证文件格式
file output.pdf  # 应返回 "PDF document, version 1.7"
```

## 常见错误（避坑）

- ❌ 把原文缩减成短句/要点 → 用户会说"这是缩减版不是美化"
- ❌ 只改格式不改结构 → 用户需要更清晰的层级
- ❌ 用 markdown 直接输出 → 用户要 PDF
- ✅ HTML → weasyprint → PDF 是最稳的路径

## 触发场景

当用户说以下内容时触发此技能：
- "帮我把我的简历美化下发给我"
- "帮我润色/美化一下这份文档"
- "把我的简历做得漂亮点"
- "排版一下这份内容"
