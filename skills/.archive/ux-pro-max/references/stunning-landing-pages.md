# 炫酷落地页灵感合集

## 🔥 视觉天花板

### 1. Ivress Utsubo（日本网络安全品牌站）
- **URL**: https://brand.ivress.co.jp
- **作品解析**: https://www.zcool.com.cn/work/ZNzM0ODgwMDA=.html
- **技术栈**: Three.js + WebGPU + 自定义GLSL Shader + 空间音效
- **特点**: 7幕3D叙事旅程，滚动驱动电影级体验，粒子系统+体积光
- **炫酷指数**: ★★★★★
- **适合**: 想要沉浸式3D叙事型页面的用户
- **一句话**: 目前web视觉天花板，没有之一

### 2. Apple MacBook Pro 3D Landing Page
- **Demo**: https://macbook-landing-page-ten.vercel.app
- **源码**: https://github.com/Itssanthoshhere/Macbook-Landing-Page
- **技术栈**: React + Three.js + GSAP + TailwindCSS + Zustand
- **特点**: 3D笔记本模型，滚动驱动动画，Apple级光影，遮罩转场
- **炫酷指数**: ★★★★★
- **适合**: 想做Apple风格产品展示页的用户

## ⚡ 现代AI风格

### 3. Brainwave AI SaaS Landing Page
- **Demo**: https://app-brainwave.netlify.app
- **源码**: https://github.com/bluesky-520/brainwave
- **技术栈**: React + Vite + Tailwind CSS + 全页动画
- **特点**: 深色主题，霓虹光效，卡片悬浮，AI产品展示，开箱即用
- **炫酷指数**: ★★★★
- **适合**: "看起来像那么回事的AI产品站"——最省事的起点

### 4. SILLAGE（高端香水品牌站）
- **源码**: https://github.com/shaozheng0503/SILLAGE
- **技术栈**: React 19 + React Three Fiber + GSAP + TypeScript
- **特点**: 3D玻璃香水瓶实时渲染，光折射物理效果，鼠标视差多层级
- **炫酷指数**: ★★★★★
- **适合**: 想做奢侈品/高端品牌风格

## 🎨 多风格模板集

### 5. Stunning Landing Page（5种风格模板）
- **在线预览**: https://rgzn7.github.io/stunning-landing-page/
- **源码**: https://github.com/rgzn7/stunning-landing-page

- **炫酷指数**: ★★★★
- **适合**: 想先看多种风格再选方向
