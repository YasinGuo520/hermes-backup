# Markdown to HTML（公众号排版）

将Markdown格式文章转换为适合公众号发布的HTML排版。

## 功能

- 多套主题模板（简约/商务/文艺/科技）
- 代码语法高亮
- 外链自动转为底部引用格式
- 图片居中/自适应
- 段落间距自动优化
- 移动端预览

## 使用方式

输入Markdown内容 → 选择主题 → 输出HTML → 复制到公众号编辑器

## 支持的主题

1. 简约白 — 干净利落，适合大多数文章
2. 暖灰 — 文艺感，适合散文/生活类
3. 墨绿 — 知识干货类，专业感
4. 科技蓝 — 技术/数码类文章
5. 暗色模式 — 极客风
