# 海外服务访问搭建（美区账号 + 翻墙 + 海外软件）

## 触发条件
用户要：注册美区Apple ID、买礼品卡、配翻墙、注册海外软件（Google/ChatGPT/Telegram/Facebook/TikTok）、给AI平台付费、问海外软件能否使用。

## 核心框架（先讲这套，避免逐个试错）
- **根账号 = Google**（+86可注册），能「Continue with Google」的软件不单独注册
- **唯一必须海外号的：ChatGPT**（接码平台 ¥3-5）
- **付费方式 = 美区Apple ID + 礼品卡余额**，永不绑卡
- **下载不用翻墙，登录使用才需要**；平时关代理，避免触发风控
- 翻墙费用不夸张：机场 ¥15-30/月，贵的是AI订阅（ChatGPT Plus $20/月）

## 一、美区 Apple ID 注册
1. appleid.apple.com → 创建账号
2. 国家/地区选 **United States**，支付方式 **None**
3. **QQ邮箱可能被苹果拒** → 用 Outlook 邮箱（国内直连，验证邮件秒到）
4. 手机号填 **+86 中国号**（能收短信即可，不需要美国号）
5. 地址填免税州（俄勒冈 Portland 97209 / 特拉华 / 蒙大拿）

## 二、礼品卡购买（唯一推荐渠道）
- **Pockyt 官网 shop.pockyt.io**（支付宝内置的礼品卡服务，网页端支付宝扫码付款）
- 选 **App Store & iTunes USA**，面额 **$5** 起
- ❌ 不推荐拼多多/淘宝卡密（黑卡封号风险），❌ 不代充
- 支付宝App内「切换地区/惠出境」入口改版后常找不到 → 直接用 Pockyt 官网，别绕
- 卡密在 Pockyt 网站「订单/我的卡券」，**不是 /balance 页面**
- 兑换：App Store 头像 → 兑换充值卡 → 手动输卡密

## 三、App Store「检查」死锁解法（最值钱的一课）
症状：新美区ID登录 App Store 反复弹「此 Apple 账户尚未用于 iTunes Store → 检查 → 输入密码 → 又弹检查」，手机/Mac 都卡。
根因：**账户无付款方式**（没绑卡、没余额），苹果强制要求，形成死循环。
解法（按序）：
1. 网页端 account.apple.com 能登录 = 账户没锁，问题在设备端或付款方式
2. 网页端补**账单地址**（付款与配送；注意账单地址 ≠ 配送地址，都要填）
3. **充值礼品卡余额 = 付款方式** → 余额到账后检查自动放行（钥匙）
4. 还不行 = 新账户风控 → **停手等 6-24h**，失败次数越多冷却越久
5. 手机反复失败触发风控 → 换 Mac App Store / 电脑网页激活一次再回手机

## 四、翻墙工具配置
- iPhone：**Shadowrocket**（小火箭）$2.99 美区一次性买断，**已购项目跟账号走，所有设备免费重装**
- Mac：**Clash Verge**（免费开源）或 macOS App Store 登录美区
- 配置：机场官网复制订阅链接 → 小火箭右上角 + → 类型 **Subscribe** → 粘贴 → 保存
- 打不开目标网站：**切「全局代理」+ 换延迟最低节点**（解决80%）
- 连接后状态栏无 VPN 图标 = 没真正连上，重新开关
- 日常：用才开，用完关（省电 + 防风控）

## 六、常见坑速查
- **Google注册「需要验证信息」+ 扫码**：机场共享节点IP被标记 → 手机相机扫码 / 换干净美国节点 / 无痕窗口 / 手机端注册最稳
- **Google短信收不到**（中国号常见）→ 找「**改用语音电话接收**」选项，成功率最高
- **TikTok 无网络连接**：①插中国SIM卡=判在中国（拔SIM）②节点自动切换IP变动触发风控（**固定一个美国节点**）③第三方修改版 TikTok Pro 客户端被检测 → 用官方版
- **iPhone 7 Plus（iOS 15.8.8）**：升安全补丁不卡；要求 iOS16+ 的 App 装不了新版，苹果给兼容旧版本，没有就换设备；Mac 不受 iOS 限制
- **英语不好**：App 自带中文界面 + 截图发给 AI 当翻译官 + 浏览器自带翻译，不构成障碍
