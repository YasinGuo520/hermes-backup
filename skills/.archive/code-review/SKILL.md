# Code Review（代码审查）

当用户请求审查代码时，遵循以下流程。

## 审查步骤

1. **阅读代码** — 仔细理解逻辑
2. **检查问题**：
   - 语法错误
   - 逻辑缺陷
   - 安全隐患
   - 性能问题
   - 代码风格（遵循PEP8/Standard等）
3. **提供建议** — 具体可执行的改进
4. **输出报告** — 结构化审查报告

## 输出格式

```markdown
## 代码审查报告

### 概述
[简要总结]

### 发现的问题
- [ ] 问题1
- [ ] 问题2

### 改进建议
1. 建议1
2. 建议2

### 评分
- 代码质量: X/10
- 可读性: X/10
- 可维护性: X/10
```

## 重点检查项

- 变量/函数命名是否有意义
- 是否有类型提示（Python）/ TypeScript类型
- 是否有文档字符串/注释
- 是否有重复代码可提取
- 是否有硬编码值
- 边界条件是否处理
- 错误处理是否完备
