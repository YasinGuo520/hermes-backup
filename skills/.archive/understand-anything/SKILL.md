# Understand Anything（深度理解大代码库）

多Agent协同分析大型项目，构建完整知识图谱。

## 核心能力

| 能力 | 说明 |
|------|------|
| 多Agent分析 | 多个Agent并行分析不同模块 |
| 知识图谱构建 | 生成项目全貌图 |
| 关键路径定位 | 快速找到核心代码逻辑 |
| 依赖分析 | 理清模块间调用关系 |

## 工作流程

1. 扫描项目结构和文件
2. 多Agent并行分析各模块
3. 构建依赖关系图谱
4. 生成项目理解报告

## 输出

- 项目架构概览
- 核心模块清单
- 关键代码路径
- 潜在问题区域

## 适用场景

- 接手他人代码
- 理解大型开源项目
- 评估技术债务
