# Graphify（项目知识图谱）

自动扫描项目文件，构建知识图谱，发现隐藏结构和关系。

## 核心能力

| 能力 | 说明 |
|------|------|
| 自动扫描 | 扫描代码、文档、PDF、图片等所有文件 |
| 知识图谱 | 构建可视化的文件关联图 |
| 关系发现 | 发现隐藏的依赖和调用关系 |
| Token节省 | 图谱化后最高节省71.5倍token |

## 使用方式

```bash
# 构建当前项目的知识图谱
/graphify

# 指定目录
/graphify --path ./src
```

## 输出

- 知识图谱JSON文件：`graphify-output.json`
- 可视化HTML：`graphify-visualization.html`

## 适用场景

- 接手新项目时快速理解代码结构
- 发现模块间的隐藏依赖
- 评估重构影响范围
