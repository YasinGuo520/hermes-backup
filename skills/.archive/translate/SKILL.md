# Translate（出版级翻译）

四步翻译流程，产出自然流畅、适合目标读者的译文。

## 四步流程

1. **理解原文** — 通读全文，把握主旨和语气
2. **确定读者** — 明确译文面向谁，调整语言风格
3. **翻译初稿** — 一句一句翻，保持原意
4. **润色定稿** — 读一遍，修正不自然的地方

## 可选参数

| 参数 | 说明 |
|------|------|
| 读者身份 | 普通读者/专业人士/学生/儿童 |
| 风格 | 正式/口语/学术/营销 |
| 语言对 | 英→中 / 中→英 / 日语→中等 |
