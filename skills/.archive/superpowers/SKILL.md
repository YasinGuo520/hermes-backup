# Superpowers（AI编程工作流）

标准化AI编程流程，确保生成的代码不仅"能工作"，而且"做对了"。

## 四步工作流

### Step 1: 拆需求（头脑风暴）
- 理解用户想要什么
- 问清楚边界条件
- 列出功能清单

### Step 2: 写计划（规划）
- 确定技术方案
- 拆分子任务
- 预估每个子任务的工作量

### Step 3: TDD开发（测试驱动）
- 先写测试
- 再写实现
- 跑通所有测试
- 小步迭代

### Step 4: Code Review（审查）
- 检查代码质量
- 验证测试覆盖
- 优化性能/安全

## 原则

- 先想清楚再写代码
- 小步提交、频繁测试
- 不跳过Code Review
- 每个任务完成后清理上下文
