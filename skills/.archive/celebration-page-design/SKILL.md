# 庆祝页面设计模式

当 Yasin 要求做生日/庆祝类前端页面时，套用此模式。

## 一、配色（深空庆祝系）

```
背景:      #0a0a12 / #0b0c12
主色(紫):  #a78bfa / #818cf8
强调(粉):  #f472b6 / #ec4899
强调(金):  #fbbf24 / #fcd34d
强调(青):  #67e8f9 / #06b6d4
文字主:    #e2e8f0 / #cbd5e1
文字次:    #94a3b8 / #64748b
环境光晕:  radial-gradient(ellipse, rgba(紫/粉/金, 0.06-0.10), transparent)
```

❌ 不要用 ux-pro-max 的 indigo 主色（庆祝页用紫粉金）。

## 二、布局结构（3层z-index）

```
z-index 0 — Canvas星空粒子 (130粒子, 拖尾效果)
z-index 1 — 环境光晕 + 浮动六角晶体 (clip-path:polygon六边形)
z-index 2 — 英雄内容区 (凹凸星行 + 吧唧 + 名字 + 祝福语 + 蛋糕)
z-index 3 — 浮动气球 (固定定位, 点击pop)
z-index 4 — 礼物盒 (右下角固定)
z-index 5 — 音乐开关 (右上角固定)
z-index 999 — 彩花Canvas (触发式物理粒子)
```

## 三、必加交互元素

| 元素 | 实现方式 | 细节 |
|------|---------|------|
| 吧唧徽章 | 圆形div + 光环旋转 | 脉冲box-shadow动画, 3层旋转环, 5颗轨道卫星粒子 |
| 点彩花 | Canvas粒子物理引擎 | 150片, 随机颜色/角度/速度, 重力0.2, 拖拽0.97 |
| 浮动气球 | 固定定位div | 5个, 随机位置, 自动浮动动画, 点击pop消失 |
| 礼物盒 | 右下角固定 + overlay | 点击弹出磨砂背景卡片, 有关闭按钮 |
| 音乐 | Web Audio API | sine波简单旋律, 不需要MP3文件 |
| 打字效果 | 逐行stagger | 每行500-800ms间隔, opacity+translateY过渡 |

## 四、头像动漫化工作流（按优先级）

```
方案A [推荐]: 外部AI工具
  → 即梦AI/可灵AI 生成动漫风格头像
  → 提示词: "动漫风格头像，二次元，扁平色块，清晰轮廓线，日系"
  → 直接嵌入HTML

方案B: Python PIL处理（快速近似）
  → median filter平滑 → 颜色quantize(16色) → 增强饱和/对比
  → 边缘检测叠加（find_edges + invert）
  → 效果：写实风动漫感，无轮廓线

方案C: CSS SVG滤镜（浏览器端）
  → feComponentTransfer色块化 + feConvolveMatrix边缘检测
  → 效果：有轮廓线但不够自然
```

❌ CSS滤镜/SVG滤镜/PIL处理都不能真正动漫化。用户不接受。
✅ 必须用外部AI工具（即梦AI等）生成真正的二次元头像。

## 五、关键禁忌

- ❌ 不要分阶段切换/屏幕切换（用户偏好一切同时可见）
- ❌ 不要只放文字没有交互
- ❌ 头像不要用真人照片直接放
- ❌ 不要用indigo主色
- ❌ 不要用卡片居中布局
