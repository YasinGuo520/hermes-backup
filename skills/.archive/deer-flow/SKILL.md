# Deer Flow（字节跳动开源Agent框架）

一个长周期自主SuperAgent框架，能研究、编码、创作。整合沙箱执行、记忆系统、工具调用、子Agent和Skill生态。

## 核心能力

| 能力 | 说明 |
|------|------|
| 长周期任务 | 支持数小时到数天的自主运行 |
| 沙箱执行 | 隔离环境运行代码，安全可控 |
| 记忆系统 | 跨会话记忆，持续学习 |
| 子Agent | 复杂任务拆解并行处理 |
| Skill生态 | 可插拔技能，扩展能力 |

## 工作模式

1. **研究模式**：自动搜索资料→整理分析→生成报告
2. **编码模式**：理解需求→设计方案→编写代码→测试
3. **创作模式**：内容策划→生成→优化→输出

## 适用场景

- 长时间自主研究
- 大型项目开发
- 内容批量生产
