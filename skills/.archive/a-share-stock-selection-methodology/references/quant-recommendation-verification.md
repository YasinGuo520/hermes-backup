# 量化推荐收盘验证

用新浪财经API验证早盘量化推荐收盘成绩。

## 流程

```
① 读取 cron 输出 → ② 批量查收盘价 → ③ 计算涨跌幅 → ④ 输出成绩表
```

## Cron 输出文件位置

```bash
# 量化早报 cron job_id: ea324446676f
ls ~/.hermes/cron/output/ea324446676f/
```

文件名格式：`YYYY-MM-DD_HH-MM-SS.md`，按日期选当天文件。

输出表格结构（从markdown中提取）：

| 排名 | 代码 | 股票 | 总分 | 因子分 | Kronos | 分歧度 | 建议 |

提取代码列（第2列），构建 Sina 查询列表。

## 收盘价查询

股票代码转 Sina 前缀规则：

| 代码开头 | 前缀 | 示例 |
|:--------:|:----:|:----:|
| 000 / 001 / 002 / 003 | `sz` | sz000338 |
| 300 / 301 | `sz` | sz300750 |
| 600 / 601 / 603 / 605 | `sh` | sh601127 |
| 688 | `sh` | sh688256 |

### 批量查询

```bash
curl -s -H "Referer: https://finance.sina.com.cn" \
  "https://hq.sinajs.cn/list=sz000338,sh601127,sz300750" | iconv -f GBK -t UTF-8
```

### 关键字段

| 新浪索引 | 字段 | 用途 |
|:--------:|:----:|:----:|
| 0 | 股票名称 | 验证匹配 |
| 1 | 开盘价 | 参考 |
| **2** | **昨收价** | 涨跌幅基准 |
| **3** | **当前价/收盘** | 对比早盘推荐 |
| 4 | 最高价 | 盘中振幅 |
| 5 | 最低价 | 盘中振幅 |
| 8 | 成交量(手) | 量能判断 |
| 30 | 日期 | 确认数据日 |

## 涨跌幅计算

```python
change_pct = (current_price - prev_close) / prev_close * 100
```

- `current_price` = 新浪字段索引3（收盘时 = 收盘价）
- `prev_close` = 新浪字段索引2（昨日收盘价）
- 注意：新浪的当前价在收盘后就是收盘价。如果盘中有延迟，确认字段30的日期为当日。

## 输出格式

| 排名 | 代码 | 股票 | 早盘推荐价 | 今收 | 涨跌幅 | 早盘建议 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | 000338 | 潍柴动力 | 27.73 | 28.45 | +3.01% 🟢 | ✅ 推荐 |

使用 `🟢` 标记正收益，`🔴` 负收益。全部正收益时加总结行。

## 总结行

前6推荐标的平均涨幅 = sum(涨幅) / 6 × 100%

两个观望票应与推荐标的区分展示，注明分歧度预警是否应验。

## 注意

- 确认数据日期（新浪字段30）为当日，避免拿前一日数据
- 早盘推荐价 = 开盘价（新浪字段1），非昨日收盘价，方便对比盘中表现
- 收盘时间15:00-15:35之间数据已稳定，查询时返回的时间戳在15:xx说明是收盘数据
