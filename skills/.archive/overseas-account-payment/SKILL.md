# 海外账号与付费（墙内方案）

目标：中国大陆环境下，最快最省成本搞定 ①手机/Mac翻墙 ②注册海外软件账号 ③支付AI平台订阅。

## 核心链路
美区Apple ID（免费）→ 机场（¥15-30/月）→ 小火箭/Clash Verge → Pockyt礼品卡 → App内购订阅

总成本：首月约¥250，之后每月约¥175。

## 成本速查
| 项目 | 成本 | 说明 |
|---|---|---|
| 机场 | ¥15-30/月 | 只月付不年付，防跑路 |
| Shadowrocket(小火箭) | $2.99一次性 | 美区App Store买 |
| Clash Verge Rev | 免费 | Mac用，GitHub下载 |
| ChatGPT Plus | $19.99/月≈¥145 | 礼品卡App内购，无手续费 |
| 接码 | ¥3-5/次 | 支付宝充值¥10够用 |

## 步骤

### 1. 注册美区Apple ID（免费，10分钟）
- appleid.apple.com → 创建账号，地区选 **United States**
- 邮箱：QQ邮箱可能被拒（提示"无法使用"），**直接用Outlook**（outlook.com注册，国内直连，+86手机验证）
- 手机号：填 **+86 中国号**（默认+1美国是坑，必须改区号下拉框），不需要美国手机
- 支付方式：**None**（不绑卡，永远不用改）
- 地址填免税州：俄勒冈 Portland，例：1234 NW Davis St / Portland / OR / 97209
- 注册完去「付款与配送」**补填地址**（选None注册时不强制填，但下载App会卡）

### 2. 翻墙
- iPhone：App Store登录美区ID → 买Shadowrocket → 右上角+ → 粘贴机场订阅链接 → 选节点
- Mac：Clash Verge Rev（免费开源），导入同一订阅，开系统代理
- 登录/购买App Store时**关代理**（App Store国内可直连，开代理反而验证失败）；要用海外服务时切**美国节点**

### 3. 买礼品卡（Pockyt官网）
- **https://shop.pockyt.io** 官网直接买（支付宝内置服务，有独立官网）
- 支付宝App内"切换地区/惠出境"入口新版经常找不到，**别折腾，直接用官网**
- 选 **App Store & iTunes USA**（蓝卡白苹果logo）——不是 Apple Gift Card US（彩色logo，面额大，用不上）
- $5面额：够买小火箭$2.99 + 剩$2
- 别买代充（黑卡封号）；拼多多/淘宝卡密有风险，官方渠道最干净
- 兑换：App Store头像 → 兑换充值卡或代码 → 手动输入卡密

### 4. 登录美区ID
- **只登 App Store**，不登设置顶部 iCloud（iCloud保持国区）
- 新ID首次使用弹「检查」：同意条款 + 确认地址 + 付款方式None
- ⚠️ 设备端「完成创建」流程强制付款方式且无「无」选项时：**先填完整账单地址**（不是配送地址！城市/邮编/区号都要）→ 或 **先充值礼品卡余额**（余额=付款方式，充了检查放行，这是死锁钥匙）
- 检查死循环排查 → 见 references/appstore-check-loop.md

### 5. 注册海外软件（要手机号的情况）
| 软件 | 要海外号？ | 解法 |
|---|---|---|
| Apple ID | 不用 | +86即可 |
| Google | 不用 | +86可以 |
| ChatGPT/Claude/Discord | 要 | 接码平台 |
- 接码：**sms-activate.org** 或 **5sim.net**，支付宝充值¥10，搜OpenAI/Claude，租印度/印尼号约¥3-5
- Claude 先试 **Google账号登录**绕过手机验证

### 6. 支付对比
| 方式 | 成本 | 结论 |
|---|---|---|
| 礼品卡App内购 | $19.99/月无手续费 | ✅ 最省 |
| 虚拟信用卡(WildCard) | 开卡$9.99+3.5%手续费 | ❌ 贵 |
| 代充/拼车 | 便宜 | ❌ 封号风险 |

## 风险预警
- 礼品卡黑卡封号 → 只走官方渠道（Pockyt/Apple）
- 美区ID被锁 → 地址别乱填，验证邮件查垃圾箱
- 机场跑路 → 只月付
- 风控 → 别频繁重试，等4-6小时

## 铁律
- 网页端能登录 = 账户没问题，问题在设备端，不要反复硬试
- 永远先给最小行动单元（今天就能做的一步），不堆方法论
