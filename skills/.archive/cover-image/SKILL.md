# Cover Image（封面图生成）

生成高质量封面图，五维控制参数，77种预设组合。

## 控制维度

| 维度 | 选项 |
|------|------|
| 风格 | 极简/插画/渐变/科技/手绘/复古/商务 |
| 配色 | 明亮/暗黑/莫兰迪/高饱和/单色 |
| 布局 | 居中/左文右图/上图下文/全图+文字叠加 |
| 字体 | 衬线/无衬线/手写/标题体 |
| 尺寸 | 公众号首图(900x383)/视频封面(1920x1080)/小红书(1242x1660) |

## 77种预设组合

5种风格 × 5种配色 × 3种布局 ≈ 77种有效组合。

## 使用方法

描述你的内容主题和想要的风格方向，自动推荐最佳封面方案并生成。
