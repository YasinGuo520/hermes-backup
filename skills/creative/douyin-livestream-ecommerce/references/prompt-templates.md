# Prompt 模板参考库

> 用于 `douyin-livestream-ecommerce` 技能。直接从Obsidian `_kb/prompts/` 复制使用。

## 万能公式

```
你是一个【角色】。
现在需要你帮我完成【任务】。
背景信息：【相关上下文】。
要求：【具体要求】。
输出格式：【表格/列表/段落/JSON】。
```

---

## 一、带货直播 Prompt

### 1.1 直播话术生成

```
你是一个有10年经验的带货主播，最擅长不露脸桌播。
现在你要卖的是：【填写产品名称】
核心卖点：【填写卖点】
价格：【填写价格】

请写一段3分钟的开播话术，包括：
1. 开场留人（前30秒让人停下）
2. 痛点描述（为什么需要这个产品）
3. 产品介绍（卖点+使用场景）
4. 价格锚点（对比原价/竞品）
5. 逼单（限时+稀缺+承诺）

语气要求：真实，口语化，像跟朋友聊天，不要AI味，不要假大空。
```

### 1.2 逼单话术

```
我卖的是【产品】，价格【XX】，正在直播中。
写一段30秒的逼单话术，包含：
- 限时紧迫感
- 稀缺性（库存有限）
- 承诺保障（运费险/退换）
- 直接行动指令（下单）
```

### 1.3 选品分析框架

```
分析抖音【品类】的选品机会。
请从以下维度分析：
1. 当前热销TOP10产品及价格带
2. 用户痛点是什么
3. 什么类型的产品还有机会
4. 推荐3个适合桌播带货的产品
5. 预估佣金和退货率
```

## 二、短视频 Prompt

### 2.1 短视频脚本生成

```
你是一个短视频编导，最擅长写15-30秒的带货/种草短视频脚本。
产品：【产品名称】
卖点：【卖点】
目标人群：【人群】

请写一个15秒短视频脚本，包含：
- 开头3秒钩子（让人停下来的话）
- 中间8秒展示（产品亮点演示）
- 结尾4秒转化（引导点击/购买）

格式：
【画面】xxx
【台词】xxx
```

### 2.2 开头钩子

```
请根据这个产品：【产品名称】
写5个不同的开头3秒钩子，类型包括：
1. 痛点型："你家是不是也..."
2. 反差型："千万别买XX，因为..."
3. 好奇型："这个才XX钱，你敢信？"
4. 结果型："用了XX天后，我..."
5. 指令型："所有XX的人都注意了"
```

## 三、自媒体 Prompt

### 3.1 AI工具测评

```
你是一个AI工具深度用户，现在要写一篇关于【工具名称】的测评笔记。
要求：
1. 先说这个工具是干什么的（一句话）
2. 你的真实使用感受（好的和不好的都要说）
3. 适合什么人用
4. 怎么开始用（简单步骤）
5. 最后的建议

语气：像一个朋友在分享，不要官方腔，不要AI味。
篇幅：300-500字
```

### 3.2 AI教程（大白话版）

```
用最简单的话解释【AI概念/工具】给完全不懂的人听。
要求：
- 不用专业术语
- 多用类比
- 控制在200字内
- 最后加一句"一句话总结"
```

## 四、通用 Prompt

### 4.1 去AI味润色

```
把下面这段文字改得更像真人写的，去掉AI味：
- 去掉"此外""值得注意的是""在这个背景下"
- 去掉破折号和排比句
- 短句为主，口语化
- 不要"金句"，要真实感

文字内容：
[粘贴你的文字]
```

### 4.2 内容总结

```
用3句话总结下面的内容，每句话不超过20个字：
[粘贴内容]
```

### 4.3 改写风格

```
把下面的内容改写成【小红书/抖音/公众号/朋友圈】风格：
[粘贴内容]
要求：保留核心信息，调整语气和格式。
```
