## 三率框架总览

```
AI客服投入
    │
    ├─ 3秒回复+顺滑转人工 → 投诉率↓30-50%（基础能力，见效最快）
    ├─ 精准尺码推荐      → 退货率↓5-15%（核心差异化护城河）

    └→ 综合效果：转化率↑（三个做好了自然涨，不是直接功能）
```

## 一、投诉率：3秒回复+顺滑转人工

### 核心机制

| 技术点 | 实现方式 | 效果 |
|:------|:--------|:----|
| 意图识别 | DeepSeek V4-Flash判断意图类型（查物流/问尺码/投诉/退货） | 理解率>95% |
| 知识库RAG | 商家上传的产品资料→向量化→匹配回复 | 准确率>90% |
| 转人工规则 | 连续3次负面情绪/同一问题3次/大额退款/客户说"转人工" | 客户不焦虑 |

### 转人工触发条件（默认配置）

| 条件 | 说明 | 优先级 |
|:----|:------|:-----:|
| 客户说"转人工" | 强制 | 🔴 最高 |
| 连续3次负面情绪 | 检测"不好""退货""投诉""差评"等 | 🔴 |
| 同一问题重复3次 | AI已回答但客户继续问 | 🟡 |
| 退款金额>¥200 | 大金额需人工确认 | 🟡 |
| 对话超过10轮 | AI兜不住了 | 🟢 |
| 客户发图片 | 质量问题/破损需人工判断 | 🟢 |

### 预期效果

首次响应时间从15-60秒降至**<3秒**，投诉率降30-50%，平台3分钟响应率考核100%达标。

## 二、退货率（1）：精准尺码推荐

### 算法逻辑（三层推荐）

```
1️⃣ BMI计算：身高+体重→理论基准尺码
   偏瘦→S / 正常→M / 偏胖→L / 肥胖→XL
   
2️⃣ 版型修正：商家标注"偏小/标准/偏大"
   偏小→升1码 / 标准→不变 / 偏大→降1码

3️⃣ 三围交叉验证（如有）：胸围+腰围+臀围→精确匹配尺码表
   → 置信度从0.7提升到0.9
```

### 配置方式（最低门槛）

商家只需做一步：**告诉系统每款衣服"偏大/标准/偏小"**。系统结合BMI算法自动推码。

更精细的可选：上传完整尺码表（胸围/腰围/臀围/衣长）、设置模特信息做参考。

### 预期效果

服装类目退货#1原因是尺码（占30-50%），尺码推荐做准后，退货率可降5-15个百分点。

## 三、退货率（2）：面料材质专业解答

### 预设面料库（开箱即用）

| 面料 | 核心要点 | 常见客户问题 |
|:----|:---------|:-----------|
| 纯棉 | 缩水3-5%，容易皱，透气好 | 会缩吗？容易皱吗？ |
| 涤纶 | 不缩水，不易皱，透气差，速干 | 闷不闷？起球吗？ |
| 天丝/莱赛尔 | 透气极佳，垂感好，需低温熨烫 | 怎么洗？容易皱吗？ |
| 莫代尔 | 比棉软，易变形，不适合机洗 | 会变形吗？ |
| 羊毛 | 缩水严重，只能干洗，保暖好 | 怎么洗？扎人吗？ |
| 真丝 | 不可机洗，怕晒怕汗渍 | 怎么保养？ |

### 回答规则

AI回答面料问题时：
1. ✅ 优先从知识库提取→准确
2. ❌ 禁止说"100%不缩水""完全不掉色"（违法广告法+不真实）
3. ❌ 禁止编造具体缩水率数字（除非知识库里有）
4. ✅ 客户问痛点→主动提供解决方案（"容易皱→建议晾晒时抖平"）

### 预期效果

面料相关退货占服装退货的10-20%，面料知识库可将其降低3-8个百分点。
