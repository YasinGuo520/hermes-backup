# 抖音桌播/挂播带货选品技能

## 用户画像（此用户）

- **平台**: 抖音
- **形式**: 桌播/挂播，不出镜，不露脸
- **账号阶段**: 0粉冷启动
- **目标类目**: 日用创意小商品 / 玩具 / 男装 / 新奇好物
- **内容能力**: 室内实景，可实拍开箱/对比/演示，不可真人出镜

## 用户格式偏好（重要）

- 输出必须 **结构化表格优先**（Markdown表格）
- 每个产品必须标注：售价、佣金率、单件佣金、退货率、风险等级
- 附 **3秒短视频钩子 + 种草文案 + 封面关键词** 三件套
- 必须有 **风险预警** 部分（同款内卷、材质差评、物流破损等）
- 结尾必须给 **可执行Checklist**，不输出空洞描述
- 禁止冗长解释；数据驱动，每个品必须说明 **适配核心理由**

## 选品核心方法论

### 1. 货盘分层结构（新号必守）

| 层级 | 定位 | 客单价 | 数量 | 目的 |
|------|------|--------|------|------|
| 引流款 | 破零拉新 | 9.9-19.9元 | 3款 | 跑数据、建标签 |
| 利润款 | 核心GMV | 20-39.9元 | 2-3款 | 赚佣金、撑时长 |
| 套装高佣款 | 拉ARPU | 40+元 | 1款 | 组合装拉高客单价 |

### 2. 硬性风控门槛

| 指标 | 门槛 |
|------|------|
| 佣金底线 | ≥25%（日用品类） |
| 退货率 | <6.5% |
| 店铺评分 | ≥4.8 |
| 发货时效 | 48小时极速发货 |
| 高危品 | 剔除三无产品、带电违规玩具、易碎品、夸大宣传品 |

### 3. 达人分层选品规则

| 阶段 | 货盘策略 |
|------|---------|
| 0粉-1万粉 | 引流款为主（占60%），只选视觉强、无需复杂讲解的品 |
| 1-10万粉 | 引流+利润组合（各40%），加入男装等高客单品类 |
| 10万+ | 搭配独家高佣款，可接坑位费合作 |

### 4. 类目差异化选品要点

| 类目 | 选品原则 | 典型方向 |
|------|---------|---------|
| 日用创意小商品 | 功能细分、痛点直击、视觉反差 | 厨房神器、收纳、除霉清洁、理线 |
| 玩具 | 可桌播演示、视觉冲击、好奇心驱动 | 对战棋、3D笔、卡皮巴拉挂件、戏水玩具 |

**玩具类目销量基准（速查）**：参考 `references/toy-volume-benchmarks-2026.md`
- 头部通货月销10万+（烟花水枪、指尖陀螺、仙法金箍棒）
- 稳定爆款月销3-5万（八轮机械狗、戳戳礼盒、敲冰块企鹅）
| 男装 | 展示面料/版型即可、适合挂播 | 纯色T恤、Polo衫、基础款 |
| 新奇好物 | 开箱惊喜感、差异化、不适合上述三类的边角 | 桌面支架、氛围灯、DIY工具 |

### 5. 销量门槛过滤器（本用户关键约束）

当用户要求推荐"爆款"或"热卖品"时，**必须主动检查或确认销量门槛**。否则可能推荐了利润高但跑不动量的品。

**销量门槛分级**：
| 用户表述 | 对应日销 | 月销底线 | 数据验证要求 |
|---------|:-------:|:--------:|------------|
| "爆款" | 500+ | 1.5万+ | 需有第三方平台/榜单可查数据 |
| "日成交量500以上" | **500+** | **1.5万+** | **必须找到月销3万+以上产品才稳妥** |
| "月销10万+" | 3300+ | 10万+ | 仅限头部通货品（如烟花水枪等） |

**数据验证渠道（按可靠性排序）**：
1. 中外玩具网（ctoy.com.cn）— 定期发布抖音玩具&潮玩热卖榜，有明确月销售额/销量区间
2. 亿邦动力（ebrun.com）— 抖音潮玩热卖榜TOP10月度更新
3. 蝉妈妈/飞瓜数据 — 付费平台有精确日销数据
4. 淘宝「抖音玩具」关键词 → 店铺评价数交叉验证（5万+评价 ≈ 月销可观）
5. 精选联盟搜索 → 看商品销量标签（10万+、5万+、1万+等）

**当数据不足时的应对**：
- 优先引用有明确月销区间的第三方榜单数据
- 对"品牌方未公开销量"的品，标注"销量未公开"并加黄标
- **绝对禁止编造销量数字**

### 6. 抖音精选联盟操作路径

1. 打开抖音 → 选品广场 → 搜索目标商品关键词
2. 按佣金率降序排列，过滤店铺评分<4.8的商品
3. 逐个查看近30天销量趋势 + 退货率
4. 同款找到3-5个供应商，选佣金最高的加入橱窗
5. 下单样品实测后再开播（成本一般150元内）

### 用户接受度注意点

用户对终端操作有轻度抗拒（提问"怎么用那两个是要在终端运行吗"）。应对：
- 优先**主动提出在后台帮跑**（"我帮你跑"成功率 > "你自己跑"）
- 需要终端时，给**可复制粘贴的单条命令**，不要分步骤解释
- WeChat 场景：用户说"跑一下"即可，不需要用户自己开终端

### 后台交互模式（Hermes PTY）

对于交互式Python脚本（有input()调用），用 `terminal(background=true, pty=true)` 启动，然后通过 `process(action='submit', data='...')` 逐条输入：
1. 启动：`terminal(background=true, pty=true, command=...)`
2. 等待菜单：`process(action='wait', timeout=3)` 或 `process(action='poll')`
3. 选择模式：`process(action='submit', data='1'/'2')`
4. 填产品信息：逐项 submit（产品名、卖点、人群、价格、赠品）
5. 等待结果：`process(action='wait', timeout=30)` 或设置 notify_on_complete

**注意：** 多行输入（如粘贴爆款文案）用 `process(action='write', data='...')` 写入，然后用两次 `process(action='submit', data='')` 发送空行触发结束。若仍不结束，尝试 `process(action='close')` 发送 EOF。

#### AI SaaS成本建模铁律

**核心教训（2026-07-11会话反复修正后确定）：**

1. 单次对话成本**不要用¥0.001-0.003/次**，用 **¥0.005-0.01/次** 作为安全估值
2. 缓存命中率别信70%，客服场景每次问法不同，实际**30-50%**
3. 一条AI回复不是200tokens，含完整话术/尺码推荐/表情要**300-500tokens**
4. 高峰时段（9-12,14-18）价格翻倍
5. 多轮对话每多1轮，成本增加¥0.002-0.004

**起点取高，再调低。** 成本用¥0.01/次估算，而不是¥0.001。错了还能调，亏了补不回。

DeepSeek V4-Flash 定价（2026年7月）：输入（命中）¥0.02/百万tokens / 输入（未命中）¥1/百万tokens / 输出¥2/百万tokens。高峰时段（9-12,14-18）翻倍。

#### SaaS定价铁律

**套餐含免费额度 + 超额按量计费 + 月消费封顶 + 用量透明**

典型模板（以电商AI客服为例，第二版修正：含对话次数比第一版砍半才不亏）：
- 入门¥49/月=**1,500**次（原3,000），超出¥0.04/次，封顶¥30
- 标准¥99/月=**5,000**次（原10,000），超出¥0.03/次，封顶¥50
- 专业¥299/月=**20,000**次（原50,000），超出¥0.02/次，封顶¥150
- 企业¥699/月=**50,000**次（原150,000），超出¥0.015/次，封顶¥300
- 毛利率目标14-28%，取低更安全，别贪高

## ⚠️ 执行心理学（此用户关键卡点）

该用户的核心问题不是**不知道怎么做**，而是**启动阻力过大**（完美主义 + 惯性缺失）。备忘录自述反复出现同一模式：准备充分 → 拖→ 自我批判 → 更不想动。

### 应对策略

| 原则 | 说明 |
|:----|------|
| **缩小到不可能失败** | 不要提"创业/月入十万"，提"今天播3分钟" |
| **移除选择权** | 不要给多选项，给唯一动作指令 |
| **先完成再完美** | 第一场的目标是"按了开始按钮"，不是"卖了多少" |
| **不输出更多方法论** | 用户方法论已经过剩，缺的是单一可执行动作 |
| **预览再执行** | 对日历写入/文件创建等不可逆操作，先输出文字版让用户确认再执行 |

## 带货视频生产：百炼图生视频(I2V)管线

> 2026-07-11 实测验证。用一张实拍产品图 → 阿里百炼 I2V → 生成5秒动态视频，产品100%一致，成本 ¥0.06/条。详见 `references/bailian-i2v-product-video.md`

### 核心原则

**AI视频在带货里最大的价值不是"生成产品"，而是"生成动效和氛围"。产品本身必须用实拍。**

| 场景 | 正确做法 | 一致性 |
|------|---------|:------:|
| 产品展示 | 实拍产品照 → 百炼I2V让产品动起来 | ✅ 100% |
| 产品使用场景 | 实拍产品抠图 → 合成AI背景 → I2V | ✅ 产品实拍 |
| 人物+产品 | 真人出镜实拍，不要AI生成 | ✅ 完全真实 |
| 纯氛围片段（无产品） | 直接文生视频（T2V） | N/A |

### 产线对比（5秒竖屏视频）

| 方案 | 费用 | 产品一致性 | 适合 |
|------|:----:|:---------:|:----:|
| **百炼 I2V**（推荐） | **¥0.06** | ✅ 100% | 带货素材 |
| SiliconFlow I2V | $0.21-0.29（≈¥1.5-2.1） | ✅ 100% | 同上但贵 |
| 直接文生视频T2V | ¥2.1-5.0/条 | ❌ 无法控产品 | 纯氛围 |
| 文生图→图生视频 | ¥0.14 | ⚠️ 图是AI生成 | 产品细节不可控 |

### 风险预警

- I2V画面会有轻微光线/角度变化，但不影响产品识别
- 避免"模特转身"类复杂动作指令，优先用推拉摇移镜头运动
- 原图至少1080x1080，太小I2V放大效果差
- 单段5秒，多段后期剪辑拼接

## 每日时间表写入日历（AppleScript方法）

当用户要求将日程写入Mac日历，首选「个人」日历（iCloud同步到iPhone），不要写入本地「日历」：

```bash
# 创建一个日历事件
osascript -e 'tell application "Calendar" to tell calendar "个人" to \
  make new event with properties {summary:"📦 选品·写话术", \
  start date:date "2026-07-06 09:00:00", end date:date "2026-07-06 12:00:00"}'

# 注意：每次osascript调用只创建一个事件，需要逐条创建
```

**关键规则：**
- 使用 `calendar "个人"`（Personal，iCloud同步）而非 `calendar "日历"`（本地）
- 创建前先清理旧事件（避免月初残留）
- 写完事件后告知用户**关闭Mac端通知** + **打开iPhone端通知**（各人操作）
- 飞书日历需开发者后台开通 `calendar:calendar` 权限并重新发布应用

## 内容合规审查（合并自 content-risk-detector）

发布任何文案/脚本/话术前，先做内容安全扫描防限流/封号。完整检测维度见 `references/content-risk-detector.md`，要点：

**检测维度（8项）：**
| 维度 | 检查内容 | 严重程度 |
|------|---------|:-------:|
| 违禁词 | 政治敏感、色情擦边、赌博相关 | 🔴 高 |
| 夸大宣传 | "最好""第一""全网最低""包治"等绝对化用语 | 🟡 中 |
| 功效宣称 | 食品说疗效、日用品说医疗效果 | 🔴 高 |
| 价格违规 | 虚构原价、虚假折扣 | 🟡 中 |
| 引流违规 | 诱导关注/分享/外链引流 | 🟡 中 |
| 版权风险 | 未授权音乐/图片/品牌logo | 🟡 中 |
| 未成年保护 | 涉及未成年人不当内容 | 🔴 高 |
| 虚假人设 | 冒充专家/医生/教授身份 | 🔴 高 |

**抖音特别敏感词：** 绝对化用语（最好、第一、NO.1、极致、唯一、独创）、虚假宣传（包治、根治、安全无毒、不复发）、诱导（点击这里、加我微信、私聊我）、价格（原价XX现价XX需有真实交易记录）。

**处理流程：** 扫描风险词 → 标记风险等级（🔴/🟡/🟢）→ 给替换建议 → 输出安全版文案。

## Mission Control 任务看板（每日运营状态总览）

此用户有一个 **Mission Control 看板**，汇总所有定时任务、今日运行记录、持仓行情、待办阻塞项，一屏看清。

### 看板文件位置

| 文件 | 路径 |
|------|------|
| 当前看板（最新） | `~/Desktop/hermes/mission-control.html` |
| 模板（下次刷新用） | 本 skill 的 `templates/mission-control.html` |

### 看板内容模块

| 模块 | 来源 | 说明 |
|------|------|------|
| 定时任务列表 | `cronjob(action='list')` | 所有任务时间、最后/下次运行、状态 |
| 今日运行记录 | 会话记录 / cron输出 | 当天跑了哪些任务 |
| 持仓快速查看 | 股票数据搜索 | 欧菲光/诺德/高伟达 现价涨跌 |
| 待办事项 | `todo` 工具 | 当前进行中的任务 |
| 阻塞列表 | 人工维护 | 卡住的事项（如需付费账号等） |
| 快速通道 | 固定链接 | 蝉妈妈/新浪财经等常用链接 |

### 更新方式

- **手动更新**：由 AI 在每次对话时获取最新 cron + todo + 股票数据，重新生成 HTML
- **定时刷新**（可选）：设置 cron job 每天开盘前自动刷新一次看板

### 模板占位符

模板使用 `{{PLACEHOLDER}}` 变量标记，AI 在生成时替换为实时数据：

```
{{USER_NAME}} → 用户名称
{{SUBTITLE}} → 副标题
{{CRON_COUNT}} → 定时任务数量
{{TODAY_OK}} → 今日已运行数
{{PENDING_COUNT}} → 待运行数
{{CRON_ROWS}} → Cron任务表格行（<tr>...</tr>）
{{STOCK_ROWS}} → 持仓行情表格行
{{QUICK_LINKS}} → 快速通道列表
{{TODO_CONTENT}} → 待办内容
{{BLOCKERS}} → 阻塞列表
```
