## 设计核心理念 (7大支柱)
1. **中式民俗恐怖**: 纸人/冥婚/皮影/棺材/红白对冲 — 中国人文化基因里的恐惧
2. **借鬼喻人**: 鬼故事外壳批判人心，反封建迷信内核
3. **剧情为王**: 每部以古典文学为原型（聊斋/梁祝/西厢记/牡丹亭）
4. **爱情+恐怖绝配**: "鬼故事比现实更容易表达至死不渝"
5. **高密度民俗考据**: 每部2-3个月查古籍/实地考察
6. **宇宙化+快节奏**: 统一世界观，每半年一部，互相带动热度
7. **轻量化**: 竖屏纯点击，4-5小时通关，低门槛适合直播传播

## 对AI游戏开发的启示
- **可以做**: 互动叙事 + 点击解谜Web版 + AI动态文案
- **做不了的**: 原画级美术 / Cocos引擎原版 / 双端上架
- **差异化方向**: AI生成分支剧情（纸嫁衣做不到的）、即时配音、动态谜题
