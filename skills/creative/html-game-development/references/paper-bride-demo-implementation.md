# 棺中新娘 — 纸嫁衣风格点击解谜游戏DEMO

## 概述

2026-07-24 用3小时完成的纸嫁衣风格中式恐怖点击解谜游戏DEMO。
3个场景（祠堂→偏殿→后院），12个交互物品，完整谜题链。
单文件HTML（~20KB，无外部依赖）。

**位置：** `~/Desktop/hermes/demo/index.html`
**端口：** 8898（本地预览）

## 核心功能

| 特性 | 实现方式 |
|------|---------|
| 3场景切换 | Canvas渲染 + 场景状态机 |
| 12个交互物品 | Canvas热区碰撞检测 |
| 谜题链 | 状态机驱动（香炉→火柴→点蜡烛→暗格→符纸→铜铃→开门） |
| 4格道具栏 | DOM渲染，拾取+使用 |
| 对话系统 | 多行叙事流，点击推进 |
| 动态氛围 | Canvas粒子系统（纸灰飘落） |
| 完整结局 | 从被困到逃离的完整故事弧 |

## 技术架构

```
┌────────────────────────────────────┐
│  Title Screen                      │
│  → click "焚香入村"                │
├────────────────────────────────────┤
│  Game Loop (requestAnimationFrame) │
│  ├─ drawScene()                    │
│  │   ├─ 背景渲染（渐变+纹理）      │
│  │   ├─ 场景建筑（Canvas绘制）     │
│  │   ├─ 交互物品高亮              │
│  │   ├─ 出口标记                  │
│  │   └─ 雾效+纸灰粒子            │
│  ├─ hitTest(mx, my)               │
│  └─ 状态更新                      │
├────────────────────────────────────┤
│  Event Handlers                   │
│  ├─ click → hitTest → interact()  │
│  └─ mousemove → hoverItem更新     │
├────────────────────────────────────┤
│  Puzzle State Machine              │
│  └─ G.flags.{candleLit/ashChecked │
│       curtainChecked/scrollRead/  │
│       bellRung/gateOpen}           │
└────────────────────────────────────┘
```

## 谜题链设计

```
发现棺材 → 推开棺盖 → 拿到提示
    ↓
找到火柴(香炉) → 点燃蜡烛(烛台)
    ↓
光照亮帷幔 → 找到符纸
    ↓
阅读卷轴(偏殿) → 铜铃+符纸=开门
    ↓
推开院门 → ENDING
```
