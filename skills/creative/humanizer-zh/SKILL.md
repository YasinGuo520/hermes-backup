# Humanizer-ZH: 中文去AI味润色

你的任务是去除文字中的AI写作痕迹，使其听起来更像真人写的。适用于带货文案、短视频脚本、种草笔记等场景。

## 核心原则

1. **删填充** — 去掉"此外""值得注意的是""在这个背景下"等空话
2. **破公式** — 避免"不仅…而且…""从X到Y"三段式结构
3. **变节奏** — 长短句交替，段落结尾不统一
4. **信读者** — 直接说事实，别铺垫别解释
5. **去金句** — 如果听起来像能截屏的"金句"，重写

## 常见AI痕迹模式

| 模式 | 问题 | 改前 | 改后 |
|------|------|------|------|
| 过度升华 | 夸大意义 | "这款产品标志着厨房收纳的革命" | "这个收纳架能多放3个锅" |
| 宣传腔 | 广告式语言 | "坐落在充满活力的社区" | "小区门口有菜市场" |
| 三段式 | 强分三组 | "美观、实用、性价比高" | "好看又好用" |
| 模糊归因 | 空泛引用 | "业内专家认为" | "用过的都说" |
| 叠词病 | 同义反复 | "关键的核心要素是至关重要的" | "关键是" |
| 虚假范围 | "从X到Y" | "从厨房到浴室到客厅全覆盖" | "厨房浴室都能用" |
| 破折号滥用 | 模仿有力文案 | "这款产品——让人爱不释手——你值得拥有" | "用了就回不去了" |
| 否定排比 | "不仅…而且" | "它不仅好用，而且耐用" | "好用还皮实" |

## 输出检查清单

- ✓ 句子长度有变化吗？（不要连续3句一样长）
- ✓ 去掉"此外""然而""值得注意的是"了吗？
- ✓ 去掉破折号了吗？
- ✓ 去掉三段式列举了吗？
- ✓ 去掉表情符号了吗？（除非用户要求保留）
- ✓ 读起来像真人说话吗？

## 使用场景

- 带货短视频文案 → 去AI味 + 加口语感
- 直播话术 → 去掉模板感，加真实感
- 小红书种草笔记 → 去掉"种草感"，加自然分享感
- 产品描述 → 去掉宣传腔，直接说人话
