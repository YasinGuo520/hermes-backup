# 抖音罗盘数据分析诊断

> 参考文档：海纳《罗盘基础与深度运营知识》
> 适用场景：分析直播间罗盘数据，诊断标签/层级/流量问题，输出可执行动作指令

## 核心指标体系

### 三大率

| 指标 | 参考值 | 含义 |
|------|--------|------|
| **曝光进入率** | <15% → 精准；>15% → 泛 | 起号前期不要追求高曝光，先洗标签再提曝光 |
| **停留** | >45秒 → 及格；<45秒 → 承接不住 | 破层级后第一波需拉停留≥25秒 |
| **转化率（成交人数）** | 较昨日涨/跌 | 成交人数决定第二天开口流速大小 |

### 千次（GPM）体系

- **客单价 × 10 = 目标千次**（估算公式）
- 千次高 → 人群精准 → 可憋停留推流量
- 千次低 → 人群偏泛 → 先追千次再放量
- 千次够才能放低价福利品（福利品会稀释千次）
- 千次高流速低 → 人精准，可强憋单破场观
- 千次低流速高 → 泛流量，先洗标签

### 层级 & 流速

- **流速 = 层级。** 流速决定你在哪个层级，不是场观
- **成交人数决定开口流速（黄线），千次决定人群质量**
- 破层级后第一波：拉停留 ≥ 25秒 → 拉时长追千次 → 一场大于一场
- 每破一个层级，稳2-3场洗标签再破下一层
- 不要轻易破层级——掉下来不止掉场观，还掉标签

### 开广场条件

推荐占比 > 90% + 停留 > 45秒（需先有标签）

## 诊断流程

### Step 1 - 标签精准度判断

```
千次 > 同层级均线 ×1.2   → 标签精准
千次 < 同层级均线 ×0.8   → 人群偏泛
千次高 + 场观低          → 人精准，可憋单破场观
千次低 + 场观高          → 泛流量，先洗标签别放量
```

### Step 2 - 层级状态判断

```
推荐占比 > 90% + 停留 > 45秒   → 已开广场
推荐占比 < 70%                 → 未进广场，先做标签
流速环比涨 30%+               → 正在破层级
流速掉回原值                    → 可能掉标签，需重新洗
```

### Step 3 - 三率诊断

| 现象 | 诊断 |
|------|------|
| 曝光进入率 > 15% | 流量泛，先压曝光做精准 |
| 曝光进入率 < 15% 且千次在涨 | 模型健康，继续追千次 |
| 停留 < 45秒 | 场景/话术/品承接不住，优化开播前3分钟 |
| 成交人数较昨日降 | 明天流速会掉，本场需追成交 |

### Step 4 - 排品诊断

| 指标状态 | 动作指令 |
|----------|---------|
| 千次足够 | 可憋停留，谨慎放低价（稀释千次） |
| 千次不够 | 先追千次到目标值，别放太多低价 |
| 老粉占比 > 40% | 可用福利品承接极速流（前提：标签清晰+千次高） |
| 老粉占比 > 60% | 警惕：老粉标签重叠度高会拉偏账号标签 |

### Step 5 - 保层级 & 破层级策略

**保层级：**
- 开播先卖低价福利品，成交人数做到 ≥ 前一天总成交人数
- 成交人数保住→层级保住
- 后面卖什么都行

**破层级：**
- 靠千次破层级最精准：先标签→再拉流→千次够→做成交节奏→破层级
- 破层级当天千次肯定会掉 → 专注保成交人数
- 破了后：憋单拉停留 + 拉时长追千次
- 快破阀值时用红包顶一顶

### Step 6 - 人为干预（鱼）注意事项

- 鱼通过关注进场，有粘性可带其他鱼
- 突然补大额无意义，补的是人群质量
- 鱼的退款率跟它历史消费水平有关，跟当场无关
- 鱼的核心是停留，不是补单
- 同场景+同主播+同网络→老粉滑进新号帮忙做数据

## 动作指令模板

每个诊断必须输出具体动作，例子：

```
"千次420偏低，较上轮跌8%。建议：暂停放福利品，上正价款憋停留，目标千次拉到600+"
"成交人数25高于昨天18，明天开口流速会涨。保持节奏，注意别放太多低价稀释千次"
"推荐占比82%未到90%，还没完全开广场。先洗2场再考虑破层级"
"老粉占比55%偏高，小心拉偏标签。控制福利品比例，多拉新粉灯牌"
```

## 自动盯盘（配合 cron + computer_use）

### 每轮数据采集

用 computer_use 捕获浏览器中的罗盘页面，读取：
- 场观/在线人数/累计观看
- 千次(GPM)
- 成交人数/成交件数
- 平均停留/人均观看时长
- 新加粉丝团/新增粉丝
- 老粉成交占比
- 推荐占比
- 曝光进入率

### 状态追踪

每次诊断后写入状态文件（`~/.hermes/luopan_state.json`），包含：
- 当前所有指标
- 时间戳
- 下一轮用于对比趋势

### 趋势告警

- 连续两轮千次下滑 → 升级提醒
- 停留连续两轮 < 40秒 → 升级提醒
- 成交人数较昨日同时间段大幅下降 → 升级提醒

## 排品节奏框架（参考）

### 三段式

| 时间段 | 品类 | 目的 |
|--------|------|------|
| 前期 | 性价比款/低价福利品 | 保层级，做成交人数，卖到≥前一天总成交 |
| 中期 | 相对高价值品 | 拉平均停留，追千次 |
| 后期 | 利润款（高客单） | 赚钱，尾部流速收割 |

### 三条产品线

- A品：低价无库存 → 冲量
- B品：正价 → 拉停留
- C品：高价 → 利润

### 低客单价产品注意事项

- 吃泛流量推流 → 靠场景+内容+话术控停留
- 低价放越多越快 → 越难转正价
- 需平衡福利品比例
