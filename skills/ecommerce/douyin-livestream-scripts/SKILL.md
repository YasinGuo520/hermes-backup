# 抖音直播话术框架

> 参考文档：《直播话术》方法论
> 适用场景：编写/优化直播间话术框架，根据人群特征匹配话术策略

## 一、核心话术框架：一圈半

两套话术同时运转：

### 成交话术（4步）

```
① 找人群 给理由（发红包）点对点
② 放大价值（产品细节/制作过程/信任背书/功效包装材质）
③ 人群-场景-痛点（为什么要用→找人群；什么场合用→场景；解决什么问题→痛点）
④ 保障话术（七天无理由+运费险 / 质量保障 / 信任背书 / 主播承诺真诚+慢）
```

### 稀缺话术（6环）

```
① 价格对比（客户要的不是便宜，是占便宜的感觉）
② 给指令
③ 玩运营
④ 钩子
⑤ 7 8 9 10 11（持续输出）
⑥ 灯牌（每轮目的）
```

## 二、四轮话术节奏

| 轮次 | 类型 | 重点 | 目的 |
|------|------|------|------|
| 第一轮 | 拉新（泛流互动） | 找人群→给理由红包→点对点→放大价值→价格对比 | 灯牌 |
| 第二轮 | 颜色尺码（精准互动） | 尺码颜色→价值/价格放大 | 灯牌 |
| 第三轮 | 人群拉人 | 场景+痛点→卖点解决痛点 | 灯牌 |
| 第四轮 | 保障确认 | 七天/运费/质保→信任闭环 | 灯牌 |

## 三、八大人群话术策略

| 人群 | 话术策略 |
|------|---------|
| 小镇青年 | 性价比/稀缺话术；精致人货场；联名大牌热度 |
| 新锐白领 | 细节品质话术；认同感；深层挖掘痛点；又懒又精致 |
| 精致妈妈 | 品质安全话术；品牌资质；使用感受；囤货心理 |
| 资深中产 | 品质话术+知识降维；高端产品；精神满足 |
| 都市蓝领 | 福利话术为主；简单明了说人话 |
| 都市银发 | 福利为主；人性化话术 |
| 小镇中老年 | 价格对比+福利话术；说人话不拽品牌 |

## 四、起号三阶段话术

### 第一天：平播点对点
- 前35分钟~2小时流量不要
- 曝光降至15以下开始点对点
- 3-5单后微憋聚人

### 微憋期（3-5-7天）
- 塑品+细节+保障为主
- 适用人群/使用场景/评价调动被动互动
- 强对比细节、实验、直播内容设计

### 憋单期（10-15天）
- 福利+浅层+点对点
- 破层级用强福利技术
- 配合红包，千次掉了拉付费

## 五、平播/微憋 话术模板（3-5分钟循环）

```
① 报名+赠品留人+品牌背书+价值放大
② 选颜色+配合场景+福利及福利理由
③ 选尺码+使用人群+统计单+点对点
④ 福利+福利理由（新用户直接颜色尺码+询问还要看什么）
⑤ 塑品+细节塑造（放大价值）+福利内容+洗价格
⑥ 保障3连+上车
⑦ 品牌+价值+福利+赠品+价格对比+确认上车
⑧ 拍了的留下给惊喜（话术停留）/ 没领到福利的...
```

## 六、低客单 vs 高客单 话术

| | 低客单 | 高客单 |
|--|--------|--------|
| 话术 | 福利钩子+简塑价值+主动互动灯牌+点对点 | 福利内容+福利原因+被动互动话术+点对点 |
| 重点 | 停留/互动/灯牌/泛流互动 | 合理/真诚/可信/品上钩子 |
| 注意 | 憋单弹窗违规，频繁诱导互动违规 | 利益诱导违规，送的理由真实高端 |

## 七、保证停留三要素

1. **画面**（场景高逼格）→ 占便宜心理
2. **福利**（有价值的东西）→ 与我有关
3. **公屏节奏**（看热闹的心理）→ 吸引力

## 八、话术说给三种人

- **泛流互动** → 新人话术（傻的人）
- **被动互动** → 老粉话术（聪明的人）
- **公屏互动** → 逼单催单（等着急的人）

## 九、起号阶段关键动作速查

| 阶段 | 动作 | 注意 |
|------|------|------|
| 第一天 | 前2小时流量不要，平播出单，点对点 | 曝光降至15以下才开始点对点 |
| 第二天 | 看feed曝光，破层级介入付费 | 层级最少4-6炸 |
| 微憋3-7天 | 塑品细节保障 | 调动被动互动 |
| 憋单10-15天 | 福利技术，强憋单破层级 | 千次掉了拉付费 |
