## 与 quant_stock_scanner.py 的区别

| 维度 | quant_stock_scanner | daily_stock_brief |
|------|---------------------|-------------------|
| 股票池 | 17只手工精选 | **45+只**（15+板块，每板块3-4只） |
| 评分因子 | 8维度（含布林/KDJ/盈亏比） | **8维度简化版**（含因子同，无独立盈亏比） |
| 板块处理 | 硬编码SECTOR_MAP | 硬编码SECTOR_MAP + **自动聚类取TOP3** |
| 过滤条件 | 无 | **价格≤100 + 非ST/退市** |
| 输出 | Markdown自由格式 | **固定标题+三段式简报** |
| 性能 | 每只0.5秒间隔 | 批量行情+0.35秒K线间隔 |

## 已知问题

- 东方财富板块排名API偶发空响应，脚本不依赖此数据（用个股评分聚类反推板块）
- 新浪K线API价格字段是字符串需float()转型
- 科创板/创业板20%涨跌幅vs主板10%，脚本目前在极端涨跌判断上未区分
- 涨停股次日容易高开低走，简报不自动过滤此场景（依赖用户自行判断）
