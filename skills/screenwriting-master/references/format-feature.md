# 长片格式指南（90分钟电影）
## 核心特征
- **时长**：75-120分钟
- **角色**：主角有完整的Ghost/Lie/Flaw/Want/Need，配角承载B-Story
- **结构**：根据题材选择结构方法论
- **弧光**：多次伪变化后的真正转变
- **世界观**：可复杂，分层展示
- **节奏**：需要"呼吸感"——张弛交替，不能持续高密度
---
## 人物深度设计（长片级）
长片的人物设计比短片多了三个维度：
### Ghost（前史创伤）
角色过去经历的某个事件，塑造了他/她当前的世界观和行为模式。
### Lie（角色相信的谎言）
角色因为Ghost而形成的一个错误信念。这个Lie驱动着角色的Want。
### Flaw（性格缺陷）
Lie在行为层面的外化。Flaw是角色不断伤害自己和他人的行为模式。
人物弧光的完整链条：Ghost → Lie → Flaw → Want（错误的追求）→ 一系列考验 → 面对Need（真正的需求）→ 关键选择 → 新常态
---
## 结构选型指南
| 题材/意图 | 推荐方法论 |
|----------|-----------|
| 商业类型片 | Save the Cat 15节拍 |
| 成长/冒险/变形记 | Dan Harmon Story Circle |
| 角色复杂度高的剧情片 | McKee 故事原理 |
| 角色驱动型文艺片 | 内在节拍表 |
### 模板A：Save the Cat 商业片15节拍
第一幕（约25分钟）：Opening Image → Theme Stated → Set-Up → Catalyst → Debate
第二幕前半（约30分钟）：Break into Two → B Story → Fun and Games → Midpoint
第二幕后半（约30分钟）：Bad Guys Close In → All Is Lost → Dark Night of the Soul
第三幕（约15分钟）：Break into Three → Finale（五步高潮法） → Final Image
### 模板B：Dan Harmon Story Circle（故事圆环）
1. YOU → 2. NEED → 3. GO → 4. SEARCH → 5. FIND → 6. TAKE → 7. RETURN → 8. CHANGE
### 模板C：McKee 故事原理
控制性理念 → 价值转变 → 鸿沟 → 激励事件 → 进展纠葛 → 危机选择 → 高潮 → 结局
### 模板D：文艺片内在节拍表
1. 常态与裂缝 → 2. 扰动 → 3. 游走与回避 → 4. 对峙 → 5. 选择或接受 → 6. 余震
---
## Subplot交织（长片专用）
- **A Plot（主线）**：主角的外在旅程
- **B Plot（副线）**：一段关系，承载主题论点
- **C Plot（第三条线，可选）**：节奏调剂
---
## 长片必备元素
- **伏笔与回扣系统**：至少3-5个伏笔/回扣对，分布在道具/台词/行为/结构各层次
- **次要角色与群像设计**：每个角色有功能（镜像/催化/主题/节奏）
- **暗线设计**：1-2条隐藏在水面下的故事线
- **世界观分层展示**：三层模型（表层规则→运行逻辑→底层真相）
