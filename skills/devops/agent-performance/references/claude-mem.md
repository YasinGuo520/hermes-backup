# Claude-Mem（跨会话长期记忆）

自动捕获会话中的工具使用、关键决策、代码变更，生成语义摘要，在下次会话中自动注入。

## 核心能力

| 能力 | 说明 |
|------|------|
| 自动捕获 | 记录会话中的关键决策、代码变更、教训 |
| 语义摘要 | 压缩长会话为结构化记忆 |
| 跨会话注入 | 下次打开自动加载相关记忆 |
| 记忆搜索 | 搜索历史记忆中的特定信息 |

## 工作流程

1. 会话结束时 → 自动生成记忆摘要
2. 记忆存储在 `~/.hermes/memories/` 目录
3. 下个会话启动 → 搜索并注入相关记忆
4. 避免重复犯错，累积项目知识

## 注意事项

- 记忆自动管理，无需手动操作
- 敏感信息不会记录
- 定期清理过期记忆
