# Yasin 页面视觉规范（深蓝科技风 · 2026-09-02 拍板版）

> 用户三次纠正后的最终结论。**全站统一深蓝科技风视觉，但每页布局必须各自不同。**
> 完整token规范见 `~/Desktop/hermes/company-agents/design-system.md` v2。

## 视觉铁律（用户拍板）

1. **背景必须明显**：`#0a0f1e` 深蓝底 + 蓝紫径向光晕 + 网格线（`rgba(148,163,184,0.05)`，36px）——**不要极简炭黑/Linear 风**（用户明确否决过："统筹页你还是弄回原来的吧，原来的还好看很多"）
2. **页头标题居中放大**：标题 2.2rem+ 加粗、字距 2px、蓝紫粉渐变（`linear-gradient(135deg,#60a5fa,#a78bfa,#f472b6)`）+ `-webkit-background-clip:text` + 发光 `filter:drop-shadow(...)`，居中
3. **玻璃卡片**：`rgba(15,23,42,0.75)` + `backdrop-filter:blur(6px)` + 细边框 `rgba(148,163,184,0.16-0.18)` + 圆角 12-14px
4. **按钮分三级**：主=蓝紫渐变（`#2563eb→#7c3aed`）、次=ghost（`rgba(148,163,184,0.14)`）、AI=绿渐变（`#059669→#0d9488`）
5. **数字**：`font-variant-numeric:tabular-nums`（等宽数字）
6. **状态色只用于数据语义**：绿`#4ade80`/黄`#fbbf24`/橙`#fb923c`/红`#f87171`
7. hover：卡片边框亮蓝 + 微光晕（`0 0 18px rgba(59,130,246,0.08)`）

## ⚠️ 布局铁律：视觉统一，布局必须各异

**用户纠正（2026-09-02）："生成的页面不要全部是一个样的……布局啥的还是按照你自己的方式来吧。不要用那个skill的了，千篇一律没有特色"**

- ✅ 共享**视觉语言**（背景/玻璃卡/按钮/标题渐变）
- ❌ 禁止用统一模板批量生成页面（同结构复制=千篇一律=廉价）
- 每个页面按**功能设计独有布局**，示例模式：
  - 数据对比 → 柱状图仪表（8928）
  - 追踪类 → 纵向时间线（8929）
  - 档案类 → 卡片墙（8937）
  - 台账类 → 表格+状态带（8939）
  - 列表对比 → 对决卡/排行榜（8925/8926）
  - 问答类 → 聊天窗布局（8927）
  - 生成类 → 分屏编辑器（8932）
  - 审查类 → 扫描仪式单栏（8933）
  - 评论类 → 评论墙+处理面板（8934）
  - 节点类 → 横向流水线（8930）

## 批量页面开发的执行序（防廉价+防bug）

1. 先写 `design-system.md`（视觉token唯一来源），再写页面
2. **页面文件直接用 write_file 写**，不要 execute_code 里大段 f-string 拼接（SyntaxError 高发）
3. 每页先想布局（对照模式表），再写 CSS/HTML/JS
4. 静态文件改动免重启（FastAPI StaticFiles 读盘），浏览器强刷 Ctrl+Shift+R
5. 用户看效果后逐个微调
