# 域名管理与ICP备案（腾讯云）

## 核心规则

**国内云服务商（腾讯云/阿里云/华为云）对未备案域名的限制：**
- 未备案域名 **禁止通过80/443端口** 访问
- 通过非标准端口（如8000）访问不受限制
- 直接访问公网IP不受限制

## 排查步骤

当用户反映域名打不开时：

1. **从服务器内部测试**
   ```bash
   dig 域名 A +short                    # DNS解析是否正确
   curl -sI http://域名                  # 80端口是否可达
   curl -sI https://域名                 # 443端口是否可达
   ```

2. **从外部DNS验证**
   ```bash
   dig @114.114.114.114 域名 A +short   # 国内DNS
   dig @8.8.8.8 域名 A +short           # 国际DNS
   ```

3. **判断问题类型**

   | 现象 | 原因 | 解决方案 |
   |------|------|---------|
   | IP直连通，域名不通（80/443） | **备案拦截** | 完成ICP备案 |
   | IP直连通，域名通但时好时坏 | DNS缓存 | 清DNS/切网络 |
   | IP直连不通 | 安全组/防火墙 | 开控制台放行端口 |
   | 服务器内通，外部不通 | 云服务商安全组 | 检查防火墙规则 |

## 备案流程

- **备案平台**：腾讯云ICP备案控制台
- **所需材料**：身份证 + 营业执照（个体户可用）
- **备案时长**：2-20个工作日
- **可备案后缀**：.com / .cn / .icu / .top 等常见后缀均可
- **域名需实名认证**后才能提交备案

## 腾讯云轻量服务器配置要点

| 项 | 说明 |
|----|------|
| 安全组位置 | 控制台 → 轻量应用服务器 → 防火墙 |
| 默认规则 | 仅开放少量端口，80/443需手动添加 |
| 常用端口 | 80(HTTP), 443(HTTPS), 8000(FastAPI) |

## DNS配置（DNSPod）

本机DNS托管在DNSPod（腾讯云），添加记录后一般5-30分钟生效。
