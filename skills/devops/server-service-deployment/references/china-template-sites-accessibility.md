# 国内模板/素材站可达性（腾讯云服务器）

## 排查原则
用户说"参考这个网站"但服务器打不开时：
- DNS解析正常但TCP超时 → 网站屏蔽了云服务商IP段（常见于国内模板站/个人站）
- 整站403 → 海外站限制国内IP访问

处理：让用户截图或右键存图发来，换可访问的替代站。
