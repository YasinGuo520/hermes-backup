# AI电商视觉内容产品设计方法论

> 核心定位：不是教怎么用AI生成一张好看的图，是教怎么设计一套"生成能卖货的图"的产品逻辑。
> 适用场景：产品经理角色分析AI电商视觉类工具产品时使用。

## 触发条件

当用户在以下场景提出产品设计需求时加载：
- "设计一个AI爆款主图生成器"
- "AI主图工具的产品方案"
- "电商AI视觉工具怎么做"
- 任何涉及"主图点击率"、"详情页转化"、"AI商品图"的产品设计讨论

## 核心方法论：14步爆款主图生成管线

> **核心定位：** 不是"生成好看的图"，是"研究透市场再出图"。
> 14步管线从"竞品研究→差异化→卖点攻击→人群适配→多方案→变体→A/B测试→CTR跟踪"全链路保障爆款生成率。
> 比竞品多花¥1-2/次，爆款命中率预估提升50-100%。

### 管线总图

```
上传产品图 + 选平台 + 选类目 + 设置目标人群
        ↓
【S1】用户产品分析（颜色/品类/价位带）
【S2】品类TOP100范式拆解（每周自动更新）
【S10】竞品差评→攻击点提取 ⭐核武器
        ↓
【S11】季节/节日/节气自动适配
【S12】人群审美画像适配
        ↓
【S3】差异化检测（CLIP向量距离）
【S4】范式驱动的多方案生成（5-8张）
【S5】卖点文案优化（含差评攻击点+违禁词过滤）
        ↓
【S6】CTR预评分排序
【S13】视觉注意力热力图验证
        ↓
【S7】手机端模拟预览
【S8】用户微调 → 变体生成
【S14】A/B测试方案输出
        ↓
【S9】上架后7天CTR跟踪 → 数据飞轮
```

### 各步骤详解

#### S1 — 用户产品深度分析

| 输入 | 分析维度 | 输出 | 作用 |
|------|---------|------|------|
| 上传的产品原图 | 主色/辅色/强调色提取 | 推荐背景配色方案 | 生成图色彩不违和 |
| 上传的产品原图 | 品类识别（服装/数码/家居...） | 匹配该类目TOP100范式权重 | 范式更加精准 |
| 用户填的售价 | 低(¥9-49)/中(¥50-299)/高(¥300+) | 视觉风格策略 | 低客单强调促销感，高客单强调品质感 |
| 产品标题 | 关键词提取 | 同步给卖点文案生成 | 文案与标题一致 |

**成本：** ¥0.01/次（LLM分析）

#### S2 — 品类TOP100范式拆解

爬取范围：抖音/淘宝/拼多多 当前搜索热销TOP100。

分析维度：色彩基调、构图模式、文字位置和大小、产品占比、背景风格、卖点关键词频次、广告法违规词检测。

**缓存策略：** 每个类目每周爬一次缓存，同品类后续用户免费复用。
**成本：** ¥1.00/类目/周，均摊约¥0.10/次
**详见：** `references/top100-analysis-methodology.md`

#### S3 — 竞品差异化检测 ⭐⭐

**最大增量价值——不让你的图跟竞品撞脸。**

| 步骤 | 技术方案 | 成本 |
|------|---------|------|
| 生成后→CLIP向量化→与TOP100向量余弦距离 | 距离<0.15=同质化过高，自动打回重生成 | ¥0.005/次 |
| 输出差异化指数 | "与同类目主图相似度 72%"展示给用户 | - |
| 同质化检测触发 | 相似度>85%时自动调整配色/构图生成差异化版本 | 重生成¥0.50-1.00 |

**效果：** 在抖音商品卡里，用户刷到3个同类商品——如果1张明显不同，先点那张。

#### S4 — 范式驱动的多方案生成

基于S2范式参数 + S3差异化要求，生成5-8张候选：
- 至少2张紧跟范式（"像爆款那样好看"）
- 至少2张差异化试探（"万一用户不吃范式那套"）
- 至少1张人群定制（基于S12画像）

**成本：** ¥2.00-4.00

#### S5 — 卖点文案优化（含竞品差评攻击）

| 步骤 | 做法 |
|------|------|
| ① 从TOP100提取高频卖点词 | "透气""显瘦""冰丝"出现频次排序 |
| ② 从竞品差评提取攻击词 ⭐ | "勒→不勒""闷热→透气""掉色→固色" |
| ③ 筛选匹配产品特性的卖点 | 黑色产品优先"显瘦"而非"百搭" |
| ④ 过滤广告法违禁词 | 极致/第一/最/唯一 → 替换为推荐/精选/优选 |
| ⑤ 输出3条文案候选 | 用户选1条放主图上 |

**成本：** ¥0.01/次

#### S6 — CTR预评分排序

| 因子 | 权重 |
|------|------|
| 范式合规度 | 25% |
| 差异化指数 | 20% |
| 色彩冲击力 | 15% |
| 文案有效性 | 15% |
| 产品突出度 | 15% |
| 手机端可读性 | 10% |

**成本：** ¥0.01/次

#### S7 — 手机端模拟预览

防止"PC好看手机糊"。裁剪为搜索结果页尺寸（约160×160px）展示，OCR检测文字在手机尺寸下是否清晰。

**成本：** ¥0（本地处理）

#### S8 — 用户微调 → 变体生成

用户选1-2张喜欢的 → 基于选中的图生成3张变体（改色调/改文案/改产品位置）→ 用户再选→最终确认。

**成本：** ¥1.50-3.00（3张变体）

#### S9 — 7天CTR跟踪（数据飞轮）

上架7天后 → 微信/公众号主动推送"你的主图7天点击率数据"——点击率多少、相比之前提升多少、AI模型已更新。

**成本：** ¥0

#### S10 — 竞品差评→攻击点提取 ⭐⭐⭐⭐⭐

**整套管线的核武器。** 不是研究爆款长什么样，是研究用户为什么不买竞品。

竞品差评高频词（如"勒""闷热""掉色"）→ 转化成你的主图文案（"不勒｜透气｜不褪色"）。每条差评都是你的卖点。

**来源：** 淘宝评价 / 抖音评论区 / 拼多多评价
**成本：** ¥0.01/次

#### S11 — 季节/节日/节气自动适配

| 时间段 | 策略调整 |
|--------|---------|
| 6-8月 | 强调"夏季""透气""清凉" |
| 12-2月 | 强调"保暖""新年""礼物" |
| 618/双11前15天 | 强调"大促价""限时" |
| 开学季 | 强调"学生党""宿舍" |
| 情人节/母亲节前7天 | 强调"礼物""送妈妈/女友" |

**实现方式：** 日历API检测日期 → 匹配策略模板 → 注入生成prompt
**成本：** ¥0

#### S12 — 人群审美画像

同样的产品卖给不同人，主图风格天壤之别。

| 人群标签 | 视觉风格策略 |
|---------|------------|
| 18-25岁女性 | 活泼/高饱和/ins风/短视频感 |
| 25-35岁女性 | 简约/质感/莫兰迪色/场景化 |
| 35-45岁女性 | 品质/可信/对比效果/口碑感 |
| 高客单(¥300+) | 空间留白/高级灰/品牌感 |
| 低客单(¥0-49) | 促销感/价格突出/多卖点 |

**用户在注册时可选目标人群，系统自动调整生成风格。**
**成本：** ¥0（规则引擎）

#### S13 — 视觉注意力热力图预测

AI显著性预测模型（TranSalNet）→ 输出视线热力图 → 判断用户第一眼落在哪 → 如果落在背景而非产品，自动提示优化意见。

**成本：** ¥0.005/次（可本地跑小模型）

#### S14 — 自动A/B测试方案输出

不是出图就完事了。告诉用户：哪张图上哪个平台、测3天、3天后自动提醒看结果。

**成本：** ¥0

#### 四模式成本结构（含主图+详情页）

| 模式 | 核心步骤 | 单次成本 | 耗时 | 适用场景 |
|------|---------|---------|------|---------|
| **经济模式** | S1+S4(经济)+S6+详情页(经济) | **~¥2.52** | ~30-45s | 批量测试、预算敏感 |
| **基础模式** | 经济+详情页Pro+S7+S11+S12+S14 | **~¥3.01** | ~30-45s | MVP默认配置 |
| **标准模式 ⭐** | 基础+S2+S3+S5(含爬取) | **~¥3.62** | ~60-90s | 推荐默认 — 性价比最高 |
| **完整模式** | 标准+S8(变体)+S13(热力图) | **~¥5.63** | ~90-120s | 精品爆款需求 |

> **核心思想：** 标准模式仅比基础模式多¥0.61/次（+20%），但用户感知价值提升超过100%——竞品分析+差异化检测+差评攻击是竞品做不了的独家功能。
> 竞品做的是"生成好看的图"，你做的是"研究透市场再出图"，这是本质区别。

#### 编排策略（哪些步骤可以并行）

```
标准模式执行流程:
S1(产品分析) → S2(TOP100) → S3(差异化) 
  → S4(主图生成) + S5(文案) 并行
    → S6(CTR评分) 
      → S7(手机预览) + S14(A/B建议) 并行
```

- **串行依赖链**：S1→S2→S3→(S4∥S5)→S6→(S7∥S14)
- **可并行组**：S4+S5、S8+S10+S11+S12、S7+S14
- **S2不阻塞主流程**：TOP100分析首次命中时耗时~25s，但异步后台执行完后再注入S4

### 竞品TOP100分析策略

| 参数 | 推荐值 | 理由 |
|------|-------|------|
| 分析数量 | **Top 100** | 覆盖主流+潜力爆款，边际价值最高（Top 30不够，Top 200信息冗余） |
| 单次分析成本 | ~¥1.00（50次VLM调用×¥0.01-0.02/次） | 相对于主图生成¥5.50/次，增加18%成本换取范式质量 |
| 分析耗时 | ~25秒（异步后台） | 用户看到"正在分析同类目爆款..."，体验反而专业 |
| 缓存策略 | 每周每类目缓存一次 | 第一个用户触发¥1.00，后续同品类用户免费复用 |

```
评估维度矩阵：
┌─────────────────┬──────────────────────┬────────┐
│ 维度             │ 检测方式              │ 权重   │
├─────────────────┼──────────────────────┼────────┤
│ 产品突出度       │ YOLO + 边缘检测       │ 25%    │
│ 视觉注意力       │ 显著性模型(TranSalNet) │ 20%    │

│ 文案有效性       │ OCR + 文本区域分析      │ 15%    │
│ 清晰度/质感      │ 模糊检测+BRISQUE       │ 10%    │
│ 场景匹配度       │ CLIP embedding余弦相似度│ 10%    │
│ 竞品差异化       │ 与TOP100的视觉距离      │ 5%     │
└─────────────────┴──────────────────────┴────────┘
```

### 输入类型预处理策略

| 输入类型 | 处理管线 | 说明 |
|---------|---------|------|
| 手机自拍（烂图） | 裁剪矫正→去背景→智能调光→超分增强 | 最大价值——中小卖家手里只有这种图 |
| 模特上身图 | 路线A：人体分割→取产品；路线B：保留模特换背景 | 服装类目常用 |
| 已有设计图 | OCR检测→Inpainting去文字→提取核心产品 | 老图重做 |
| 白底图/高清图 | 跳过预处理，直接进入生成管线 | 最理想输入 |

## 产品设计四步法

### 第一步：竞品情报收集
- 直接竞品定位/定价/收入/用户量
- 竞品弱项分析（特别是没做什么）
- 结论前置：**不要做"又一个AI生图工具"，要做"CTR预测+数据飞轮"**

### 第二步：市场空间判断
- 市场规模 + 渗透率 + 增速（目前AI电商视觉渗透率~65%，但70%中小卖家未标准化）
- 全球对标参考（PhotoRoom 50人$50M ARR证明赛道小而美能赚钱）
- 竞争格局：大厂（美图/阿里/字节）vs 垂直工具（Flyelep/Sorftime）vs 全球化（PhotoRoom）

### 第三步：差异化定位
参考公式：
```
不是"AI帮你做主图"，是"AI帮你做能卖货的主图"
不是"生成好看的图"，是"生成前就知道点击率多高"
```

### 第四步：财务预算体系
必须包含（参考 project-validation-3agent skill）：
- 开发成本（域名¥75 + 微信认证¥300 = 实付¥375）
- 月运营成本（基础设施~¥171/月 + AI推理按日均量计算，API成本是大头）
- 定价（三档：¥39/¥99/¥299 + 免费引流）
- 盈亏平衡点（零预算下通常第6个月达平衡）
- 12个月财务预测（保守/中性/乐观三档）

## 已知陷阱

| 陷阱 | 表现 | 预防 |
|------|------|------|
| ⚠️ **一致性幻觉** | 详情页多张图之间产品颜色忽蓝忽红 | IP-Adapter + 统一Prompt后缀 + 色调后处理，仍不能100%保证 |
| ⚠️ **AI文字乱码** | 主图生成的文字模糊/错位 | 全程用Pillow后处理叠加文字，不靠模型生成文字 |
| ⚠️ **CTR评分≠真实CTR** | 模型预测的点击率与实际有差距 | 初期说"AI推荐排序"而非"预测点击率"，用数据飞轮逐步校准 |
| ⚠️ **API成本漏算** | 只算服务器不算API推理 | API费用通常是服务器费用的10-50倍，必须逐项列明 |
| ⚠️ **同质化陷阱** | 生成的图跟竞品太像，用户分不出来 | 使用S3差异化检测（CLIP向量距离），相似度>85%自动打回重生成 |
| ⚠️ **各Agent财务口径不一致** | 三个方案算出来的成本差几倍 | S1中的API成本以技术方案为准，营销方案和产品方案必须对齐 |
| ⚠️ **🔴 TOP100爬虫被封** | 抖音/淘宝反爬升级导致爬虫封IP/账号 | 代理IP池+限速2req/s+Playwright stealth指纹模拟+多账号轮换 |
| ⚠️ **🟡 差评爬取合规风险** | 爬取竞品评价可能违反平台用户协议 | 仅爬公开可见评价页，不做用户个人信息，内部分析不展示原文 |
| ⚠️ **🟡 CLIP差异化不敏感** | 白底数码产品类目CLIP差异度区分不明显 | 结合构图/配色规则评分 + 文案关键词维度 + 类目自适应阈值 |
