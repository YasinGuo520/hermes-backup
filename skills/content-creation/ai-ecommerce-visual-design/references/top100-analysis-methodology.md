# TOP100竞品视觉范式分析 — 实操指南

> 关联 skill: `ai-ecommerce-visual-design`
> 本文件记录从本会话（2026-07-13）中提炼的竞品TOP100视觉分析实操细节。

## 爬取策略

### 平台对应搜索接口

| 平台 | 公开数据获取方式 | 注意 |
|------|----------------|------|
| 淘宝/天猫 | 搜索页分页（每页100条），按销量排序 | 需处理反爬，可用Playwright模拟 |
| 抖音电商 | 商品卡搜索接口/抖音商城搜索 | 抖音商品卡流量占大，是重点 |
| 拼多多 | 搜索页分页，按销量排序 | 图片质量普遍较低，标准可适当放宽 |
| 小红书 | 商品搜索/笔记搜索结果 | 偏种草风格，视觉范式不同 |

### 缓存的两种模式

```
模式A：懒加载（推荐）
  用户选类目 → 查Redis缓存
    ├── 有且<=7天 → 直接返回范式参数（成本¥0）
    └── 无/超期 → 爬取+分析（成本¥1.00，耗时~25秒）
  
模式B：主动刷新（可选）
  定时任务每周日凌晨爬取所有热门类目
  首周一次性成本稍高，后续维护成本极低
```

## VLM分析Prompt模板

### 单张图片分析

```
你是一位电商视觉分析师。分析这张主图，提取以下结构化特征：

1. 色彩基调（暖色/冷色/中性/高对比/低对比）
2. 主色调（HEX色值）
3. 构图模式（中心构图/左文右图/满版/三分法/对角线）
4. 产品占比（%）
5. 产品展示角度（正面/侧面/45度/俯视/多角度组合）
6. 背景类型（纯色/渐变/场景/模特/生活化/纹理）
7. 背景颜色（HEX色值）
8. 文字是否存在（是/否）
9. 文字位置（顶部/中部/底部/左侧/右侧/分散）
10. 文字内容概要（提炼核心卖点词）
11. 光影氛围（自然光/棚拍/逆光/侧光/柔光）

输出格式：JSON
```

### TOP100聚合分析

```
基于以下100张主图的分析结果，归纳该类目的爆款视觉范式：

**统计维度：**
- 色彩：TOP3主色调组合及占比
- 构图：各构图模式出现频次 TOP3
- 产品展示：最常见的展示角度和占比区间
- 背景：最常见背景类型及占比
- 卖点词：出现频次 TOP10 的关键词
- 风格趋势：明显的新兴趋势（如果有）

**输出一个结构化的"范式参数"**，可直接用于AI生成prompt注入。
```

## 首次跑通验证的步骤（不写代码）

```
1. 手动打开你选定的平台+类目（如抖音→内衣）
2. 截图前100条商品主图
3. 用VLM一张张分析（可批量），提取特征
4. 手动聚类——总结出3个范式
5. 基于范式，用百炼生成3张候选主图
6. 上架你的抖音商品卡，分别测3天
7. 对比点击率 → 验证范式是否有效
8. 有效 → 值得自动化，无效 → 调整范式分类方式
```
