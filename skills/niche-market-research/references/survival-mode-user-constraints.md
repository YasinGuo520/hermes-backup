# 生存模式用户约束清单

## 通用约束模版（每次开生存模式前先盘）

| 约束题 | 为什么重要 |
|--------|----------|
| 有公司执照吗？ | 决定能不能注册开放平台/服务市场 |
| 有可用的社交圈子（微信好友/老客户）吗？ | 决定能不能走熟人信任路线 |
| 能做图片/视频吗？ | 平台对AI图片的态度在收紧 |
| 有现成的产品/服务吗？ | 决定是"卖现有东西"还是"从零造" |
| 能用什么AI能力（纯文字/图片/视频/代码）？ | 影响交付方式 |
| 月内需要多少钱？ | 决定是生存模式还是长期模式 |
| 英语水平？ | 决定能不能走海外接单路线 |

## 已验证的平台现状（2026年7月数据）

### 国内平台

| 平台 | 状态 | 备注 |
|------|------|------|
| **闲鱼AI代写** | ❌ 文书代写销量惨淡，大部分没单 | 用户实测结论，与部分文章鼓吹的相反 |
| **猪八戒AI代写** | ❌ 销量惨淡，很多可能是刷的 | 抽成高（5-20%），竞争激烈 |
| **BOSS直聘远程** | ⚠️ 有单但需要筛选 | 适合找长期兼职而非短期接单 |
| **小红书引流** | ⚠️ 需要内容积累 | 见效慢，不适合生存模式 |
| **百家号/头条号** | ❌ 流量分成见效太慢 | 3-6个月才能看到收入 |

### 海外平台

| 平台 | 状态 | 备注 |
|------|------|------|
| **Fiverr** | ✅ 华人月入8000-15000元有真实案例 | 需英语基础，个人注册即可 |
| **Upwork** | ✅ 客单价更高 | 需英语，竞标模式前期难 |

## 已试错过但不行的路径

| 路径 | 为什么不行 |
|------|----------|
| 帮人配AI客服代运营 | 没公司注册不了开放平台API，无法绑定客户账号 |
| AI商品图/模特图代做 | 平台在限制AI图片，闲鱼/小红书都会限流 |
| 电商文案代写 | 豆包免费能替代，用户付费意愿弱 |
| AI电商顾问/陪跑 | 没案例没背书，圈子又冷了5年，没人信 |
| 咸鱼文书代写 | 平台本身没销量，看起来是红海 |
| 猪八戒AI代写 | 同上，卷到没利润 |

## 生存模式下避开的坑

1. **不要先想再查** — 想到一个方向直接说是错误的。先搜索验证该方向在用户约束下是否可行。
2. **不要忽略"没公司"这个约束** — 它卡掉了所有需要注册开发者账号的路径（开放平台API、服务市场等）。
3. **不要忽略"圈子冷"** — 做代运营/咨询需要熟人信任背书，5年没联系的人不会突然找你买单。
4. **高单价愿景类产品直接淘汰** — 用户要的是30天内过万，不是"长期培养付费习惯"。
5. **平台型接单（闲鱼/猪八戒等）已被验证不靠谱** — 文案/代写类在2026年已严重内卷。海外平台是唯一还有空间的选项，但需要英语。
