# AI Agent 普及游戏设计案例

## 背景

用户 Yasin（电商创业者）提出：做一款微信小游戏，不是教成语古诗，而是让小孩/普通人通过游戏理解 AI Agent 是什么、怎么用，脱离游戏后能快速上手真实 Agent。

## 迭代过程

| 轮次 | 设计 | 用户反馈 | 问题 |
|------|------|---------|------|
| V1 | 7关闯关式教学（教LLM/Tool/Memory等概念） | "可玩性不够强，7关很难让人真正理解" | 像教程不像游戏 |
| V2 | RPG世界扮演Agent（5个世界，角色养成+任务） | "可玩性强了，但记不住术语" | 玩完就忘，概念没内化 |
| V3 | 节点编辑器拼管线（60+术语，每关解锁1-2个） | "可玩性不如V2" | 深度有了，但像工具不像游戏 |
| **最终** | **用户自己合成：V2的RPG框架 + V3的节点编辑操作 + 60+术语内容** | "用第二的游戏框架加上第三个的名词和操作内容" | ✅ |

## 最终设计：「Agent 情报局」

### 世界观
玩家是 AI 情报局实习探员，工位上有**情报处理器（节点编辑器）**。接到用户（NPC）委托后，拖拽 AI 模块组装管线，执行交付。

### 8 个世界 + 自由沙盒

| 世界 | 主题 | 委托类型 | 解锁术语数 |
|------|------|---------|-----------|
| 1.新兵营 | 基础通讯 | 问问题、讲故事 | 8个（LLM, Output, Token, 等） |
| 2.工具区 | 情报采集 | 查天气、搜资料 | 8个（Tool, Search, API, 等） |
| 3.记忆库 | 档案管理 | 多轮对话、记信息 | 8个（Memory, Context, Session, 等） |
| 4.指令学院 | 精准指挥 | 翻译、润色、格式转换 | 8个（Prompt, Temperature, System, 等） |
| 5.检索中心 | 知识溯源 | 研究报告、事实核查 | 8个（RAG, Embedding, Vector, 等） |
| 6.多模态室 | 跨界处理 | 识图、听写、编程 | 8个（Vision, Code, Speech, 等） |
| 7.协同作战 | 团队调度 | 多Agent协作、大项目 | 8个（Multi-Agent, MCP, Orchestrator, 等） |
| 8.总部特训 | 终极考核 | 综合大案，6+模块 | 6个（Guardrails, RLHF, 等） |
| 9.自由沙盒 | 真实世界 | 接真API，自己玩 | 无上限（毕业模式） |

### 核心玩法

```
玩家视角：

  左边：委托单（NPC发来的任务）
  中间：情报处理器（节点工作台）
  右边：工具箱（已解锁的AI模块）
  下面：RUN按钮

玩法：
  从工具箱拖AI模块到工作台
  用线连起来，形成"输入→处理→输出"管线
  点RUN → 动画演示光点流动 → 打分
```

### 示例关卡（第3世界第4关）

```
委托单
──────────────
委托人：王总
第一句："我的公司叫星辰科技"
第三句（隔了两个问题）："我的公司主营业务是什么？"
──────────────

正确答案：
  [输入] → [Memory]（存"星辰科技"）
  [输入] → [Memory]（检索前文）→ [LLM] → [输出]

执行动画：光点从输入→Memory→LLM→输出

得分：★★★

解锁术语：💾 Memory = 短期记忆，Agent用它记住上下文
```

### 术语内化机制

| 出现方式 | 效果 |
|---------|------|
| 工具模块名（拖[LLM]） | 动手操作即记忆 |
| 成功条提示（"Temperature调至0.8，创意满分！"） | 正面强化 |
| 失败条提示（"未配置Memory模块"） | 负面反馈强化 |
| 关尾百科（"你刚用的RAG → 现实中ChatGPT联网搜索也是RAG"） | 与现实连接 |
| 术语图鉴（玩家收集60+卡片） | 收集欲驱动 |

### 毕业能力

玩家通关后可以带走：
```
✅ 给AI下清晰的指令（Prompt Engineering）
✅ 知道AI什么时候会犯错（Hallucination）
✅ 会组合工具解决复杂问题（Agent Workflow）
✅ 知道Agent需要上下文（Memory/Context）
✅ 知道Agent可以看图片、听声音（Multi-modal）
✅ 能在真实Agent产品（ChatGPT/Kimi）上复用电这些技能
```

### 关键设计原则（从本次迭代提炼）

1. **第一版别想完美** — V1一定被否，V2可能也被否，V3用户帮你合成
2. **可玩性 > 教育性** — 用户先觉得好玩，才愿意学东西
3. **操作即理解** — 拖模块连接比看说明文字有效10倍
4. **背后是真的** — 毕业模式接真实LLM API，让玩家体验是真的Agent
5. **60+术语不用背** — 每个术语在游戏中自然出现3次以上，肌肉记忆
