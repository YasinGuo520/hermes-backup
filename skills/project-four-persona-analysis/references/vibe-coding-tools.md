## 核心方法论

### Vibe Coding五步（做微信小程序/网页时适用）

```
1. 写清楚需求 → 目标、输入、输出、约束
2. 反向搜索 → 让AI找已有成熟方案，不自研
3. 选最优解 → 为什么选这个方案
4. 设计接口 → 固定输入输出
5. AI写胶水代码 → 只写连接和配置，不重造轮子
```

### 关键原则

| 原则 | 说明 |
|-----|------|
| **能复用不重造** | 先让AI搜索成熟库/SDK，评估后再决定是否自研 |
| **能编排不发明** | 用胶水代码连接已有能力，自研只服务不可替代的业务差异 |
| **代码少bug就少** | 每多写一行代码就多一个出bug的机会 |
| **草图即原型** | 手绘草图拍照→AI直接转前端页面代码 |
