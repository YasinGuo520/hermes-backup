# 项目推荐红蓝验证工作流（合并自 project-recommendation-workflow skill）

> 决策层：红蓝验证选方向。六分身分析（本技能 SKILL.md）= 分析层；IPO 执行子循环 = 执行层。三层不同功能，不要合成一个新名字。不经过完整流程，不准输出推荐。

## 核心规则

**不准跳过任何一步。** 每一步必须输出可验证的结论才能进下一步。

**被提名原则：** 任何方向（蓝方提的或你提的），都必须在红方质疑+数据验证通过后才能作为可行选项呈现。验证完成前只能回答「需要查数据」，不能直接说「能做」或「不能做」。

### 历史教训（必读，犯过任何一条 = 没读过）

1. ❌ **没问限制就瞎推** — 他觉得合适的跟实际条件对不上
2. ❌ **不调研就开口** — 「你先搜索论证过没有」，数据验证前不准说话
3. ❌ **思路太窄** — 不要只局限在 AI 文字，Hermes 全能力都能用
4. ❌ **只盯着国内** — 海外平台（Fiverr 等）同样有机会
5. ❌ **用过期数据判断** — 平台规则变化极快（小红书 2026-03 封杀 AI 托管账号 80万+；闲鱼 2026-06 经营性卖家新规）。搜数据必须同时查**平台最新规则**
6. ❌ **凭空捏框架/改名已有框架** — 六分身（本技能）已覆盖深度分析层。不要提出「IPO²」之类的改名版。六分身 = IPO 的豪华精装版，只需接力不重造
7. ❌ **混淆「决策层」「分析层」「执行层」** — 红蓝 = 决策选方向，六分身 = 分析可行性，IPO = 执行节奏
8. ❌ **默认用他现有产品举例** — 先讲通用市场/竞品/抽象方法论，等他说「帮我看看我的情况」再切到具体产品
9. ❌ **把「蓝海」当默认结论** — 要追问：真没人想到（蓝海）还是有人试过做不起来（黑海）？搜「XX方向 失败 为什么没做成」
10. ❌ **混淆方法论价值和用户需求** — 方法论深 ≠ 能卖。前台展示具体结果（「揉碎喂嘴里的动作」+「明天能赚钱」），方法论是后台工具
11. ❌ **不标记猜测/幻觉** — 数据不足时主动说「这是推断，没有数据支撑」；不要用肯定语气输出未验证判断
12. ❌ **理想化收入预测** — 收入预测必须打折扣：咨询第一个月 0 收入是常态；内容类 3-6 个月起号；模板/产品靠流量转化。不要把「上线就能卖」当默认

## 七步工作流

```
Step 0: 确认限制条件（先推断已知，只问不确定的：资金/时间/公司/英语/红线/目标/时限）
Step 1: 蓝方首发提案 — 3个候选方向，各附做什么/为什么适合/预期月收入/启动时间/初步证据，标注「未验证」
Step 2: 红方攻击验证 — 每候选3质疑：限制质疑/证据质疑/可行性质疑 → 判定：淘汰/需验证/通过
Step 3: 数据实地验证 — 必须实际搜索，不能靠记忆。先查 references/verified-platform-paths.md（已验证/淘汰的方向直接引用结论）；搜索真实案例+平台门槛+**最新规则**+是否走下坡路；提取关键数据不要长篇复制。验证不充分不淮跳到下一步
Step 4: 铁律过滤 — 0资金能启动/不需要公司/不需要熟人圈/30天内能见钱/不限平台。一条不过 = 直接淘汰
Step 5: 最终推荐 — 只有全过4步的方向才推荐。拒绝 → 回 Step 0 调整限制重走，不能从 Step 5 跳别的推荐
Step 6: 最小行动验证 — IPO 子循环（Input 今天学/搜什么 → Process 怎么拆 → Output 今天出什么货 → 反馈 → I'），最多3天
Step 7: 结果反馈 — 实际做了什么/时间/收到钱了吗/问题卡点 → 写入长期记忆，下次推荐参考
```

兜底：全部淘汰时降级到「最小可行动作」（不做大项目，今天干一单试错），推荐动作见原流程。

## 个人决策日志与复盘（决策副驾驶，合并自 decision-co-pilot）

红蓝不仅用于项目推荐，也用于个人日常决策（A vs B、每周复盘、人生复盘）。完整系统见 `references/decision-co-pilot.md`，要点：

- **决策日志**：`~/Desktop/hermes/decisions/YYYY-MM-DD.md`，每天最多3条，只记「有选择」的决策；模板：类型/选项A vs B/选了哪个/依据/预估收益/实际结果（周末补）/后悔吗。值得记：犹豫≥30分钟 / 花钱≥¥50 / 两个以上选项 / 拒绝了机会 / 需要AI分析
- **每周复盘**（周日18:00自动或「帮我做本周决策复盘」）：决策总数与日期、类型分布、金钱决策汇总（ROI）、最佳/最差决策、下周期望调整、健康度评分。复盘报告存 `~/Desktop/hermes/decisions/weekly/WXX-复盘.md`
- **A vs B 决策**：①红蓝列阵（各带数据+第一性原理）→ ②攻防回合（芒格逆向）→ ③铁律检查（Stop Doing List：财务/项目/内容/时间四类红线，触犯=黄牌）→ ④历史参考（翻日志+偏差率校准）→ ⑤结论（贝索斯遗憾最小化）
- **人生复盘模式**：时间线 → 红蓝诊断 → 攻防互驳 → 铁律回测 → 模式识别（重复出现的决策错误）→ 结论（继续/停止/开始）
- 名人工具箱：马斯克第一性原理、芒格逆向思维、段永平 Stop Doing List、张一鸣概率化决策、贝索斯遗憾最小化、巴菲特双清单、芒格多元思维模型
- **关键纪律**：红蓝双方必须有数据支撑；预估偏差率持续>30% = 预估系统需校准；铁律触犯直接黄牌
