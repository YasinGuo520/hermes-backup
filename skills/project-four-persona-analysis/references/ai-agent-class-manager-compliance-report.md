## 一、核心法规原文摘要

### 1. 《生成式人工智能服务管理暂行办法》（2023年8月15日施行）

**适用范围（第2条）**：利用生成式人工智能技术向中华人民共和国境内公众提供生成文本、图片、音频、视频等内容的服务。

**关键条款**：

**第7条 — 训练数据处理**：
- 使用具有合法来源的数据和基础模型
- 涉及知识产权的不得侵害他人权益
- 涉及个人信息的应取得个人同意
- 提高训练数据质量

**第10条 — 未成年人保护**：
- 明确并公开适用人群、场合、用途
- 指导科学理性认识和使用
- 防范未成年人用户过度依赖或沉迷

**第11条 — 个人信息保护**：
- 不得收集非必要个人信息
- 不得非法留存能识别使用者身份的输入信息和使用记录
- 不得非法向他人提供使用者的输入信息和使用记录
- 依法处理查阅、复制、更正、补充、删除请求

**第12条 — 内容标识**：
- 对图片、视频等生成内容进行标识（《互联网信息服务深度合成管理规定》）

**第14条 — 违法内容处置**：
- 发现违法内容应及时采取停止生成、停止传输、消除等处置措施
- 采取模型优化训练等措施整改
- 向有关主管部门报告

**第15条 — 投诉举报机制**：
- 建立健全投诉、举报机制
- 设置便捷的投诉、举报入口
- 公布处理流程和反馈时限

**第17条（⚠️关键）** — **安全评估+算法备案触发条件**：
- "提供具有舆论属性或者社会动员能力的生成式人工智能服务的"
- 应开展安全评估
- 按《互联网信息服务算法推荐管理规定》履行算法备案

> **灰色地带判断**：班级管理工具不具有社会动员能力，但教育场景涉及内容传播。建议咨询网信办或专业律师。

### 2. 微信小程序教育服务类目资质要求（2025年版）

**非个人主体 — 教育服务类目（走此路需以下资质）：**

| 二级分类 | 资质要求 |
|---------|---------|
| **学历教育（培训机构）** | 《民办学校办学许可证》+《营业执照》/《事业单位法人证书》/《民办非企业登记证书》 |
| **学历教育（学校）** | （2选1）公立：教育行政部门审批设立证明 或 《事业单位法人证书》；私立：《民办学校办学许可证》 |
| **非学科类培训机构** | （5选1）《办学许可证》/《非学科类校外培训机构培训许可证》/《文化艺术类校外培训机构审核意见书》/《全国校外教育培训监管与服务综合平台备案》/人社部门职业培训备案或许可 |
| **课程销售** | 《增值电信业务经营许可证》（含"在线数据处理与交易处理业务"） |
| **教育平台** | （2选1）①《增值电信业务经营许可证》+ 与2家以上培训机构合作协议 + 培训机构《办学许可证》；② ICP证 + 平台经营证明材料 + 《小程序开发者承诺函》 |

**个人主体 — 教育服务类目：**

| 二级分类 | 说明 |
|---------|------|
| **教育信息展示** | 仅教育信息展示，不支持教育视频播放/直播、课程产品销售等服务 |

**海外主体 — 教育类目：**

| 二级分类 | 说明 |
|---------|------|
| **在线教育** | 适用于教育信息展示服务，不得涉及义务教育机构、军事、警察、政治和党校等特殊领域 |
| **教育装备** | 适用于教育教学活动所需的教具、学具、器材、设施、场所等 |
| **大学** | 学校主体展示信息、招生、学费缴纳 |

## 二、关键合规参数参考

### 隐私政策必须包含的AI条款
1. AI模型名称及备案号（如适用）
2. AI生成内容的范围和用途说明
3. 明确声明"AI模型不收集、不使用用户数据进行训练"
4. AI生成内容由用户（老师）确认后生效的人机协作机制
5. 用户对AI生成内容承担最终责任

### 学生数据保护最低标准
1. 数据最小化：仅收集学生姓名、家长联系方式（不收集身份证号、家庭住址）
2. 数据本地化：中国境内服务器（腾讯云/微信云开发）
3. 数据不用于训练：隐私政策+服务协议中明确
4. 数据删除：老师注销后自动清理关联学生数据
5. 数据保留期：建议设置学期结束可批量清理

### AI生成内容标识方案
- 文本内容旁添加"🅰 AI辅助生成"标识
- 标识位置：纪律记录/通知/评语内容的开头或结尾
- 颜色/样式：建议灰色小字，不影响阅读但明确标注

## 五、类目选择决策路径（AI教育工具）

```
产品有真人授课/培训吗？
├─ 是 → 走「教育服务」类目（需要办学许可证/ICP证）
├─ 否 → 产品是管理工具还是信息展示？
│   ├─ 管理工具（班级管理/作业编排/通知生成）→ ✅ 「工具」类目
│   │   ├─ 资质：营业执照+微信认证（¥300/年）
│   │   └─ 优点：无教育类目高门槛，合规成本最低
│   └─ 信息展示（学校介绍/课程目录/公告栏）
│       ├─ 无变现 → 「教育服务-教育信息展示」（个人也可）
│       └─ 有变现 → 「工具」类目+微信支付（企业主体）
```

**核心原则**：当产品定位模糊时，从最轻量级的类目开始。审核不通过再升级——审核反馈就是最好的合规顾问。
