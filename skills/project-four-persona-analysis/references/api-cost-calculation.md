# API 成本精确计算方法

> 用于项目财务分析中的AI API成本核算。**不可按「每次调用x元」估算，必须按token算。**

## 计算步骤

### 第一步：问用户实际单价

```
问法：你1亿token实际要多少钱？
用户回答就是基准值，官网价不可用
```

不同模型/渠道/签约价差异巨大。用户的实际价格可能远低于官网标价。

### 第二步：估算每次调用的token消耗

| 场景 | 输入tokens | 输出tokens | 合计 | 缓存命中率 |
|-----|-----------|-----------|------|-----------|
| 简单记录/分类 | 10-20 | 50-100 | ~90 | >90% |
| 结构化输出 | 20-50 | 80-150 | ~150 | 85% |
| 生成文本通知 | 100-200 | 200-500 | ~500 | 70% |
| 复杂推理/分析 | 200-500 | 300-800 | ~1,000 | 50% |
| 对话（多轮） | 500-2,000 | 200-500 | ~1,000 | 60% |

### 第三步：计算月token消耗

```
月tokens = 日均调用次数 × 每次平均tokens × 30天
月成本 = 月tokens / 100,000,000 × 用户1亿token价格
```

### 第四步：考虑峰谷时段

如果产品用户主要在工作日9-18点使用（如教师工具/办公工具），大部分调用落在高峰时段。
- 简单估算：按 70%高峰 + 30%低谷 加权
- 批量任务（数据导出/报表生成）可调度到低谷
- 非实时任务异步处理在低谷

### 第五步：实际案例

```
案例：AI班级管家，中度老师每天14次调用
  日均tokens = 10次×90 + 2次×150 + 1次×500 + 1次×300 ≈ 2,000
  月tokens = 2,000 × 30 = 60,000
  月成本 = 60,000 / 100,000,000 × ¥5 = ¥0.003/月
  年成本 = ¥0.036
  全班45学生：45 × ¥0.00225 = ¥0.101/月
  全班合计：¥0.104/月
  买断制¥19.9：3年成本¥0.312，利润+¥19.59 ✅
```

### 交叉验证规则

所有涉及API成本的估算，**必须让产品经理和财务总监两组人分别独立计算**：
- 如果两组结果差<20% → 通过
- 如果差>20% → 有人拍脑袋了，重新算

## DeepSeek V4 Flash 官方参考价（2026年7月）

### 峰谷定价（2026年7月中旬起实行）

**高峰时段：** 每日 09:00-12:00 和 14:00-18:00（翻倍价）
**低谷时段：** 12:00-14:00 + 18:00后 + 周末全天（基础价）

| 项目 | 低谷 | 高峰 |
|-----|:---:|:---:|
| 缓存命中输入 | ¥0.02/百万 | ¥0.04/百万 |
| 缓存未命中输入 | ¥1/百万 | ¥2/百万 |
| 输出 | ¥2/百万 | ¥4/百万 |

**注意：** 官网标价只是参考。**用户实际价格以签约价为准。** 必须问用户真实价格。

### 高峰期策略

- 缓存system prompt可大幅降低成本（命中价仅为未命中的1/50）
- 批量任务调度到低谷时段
- 非实时任务异步处理

## 常见错误

| 错误 | 后果 |
|-----|------|
| 按"每次调用¥0.01"估算 | 高估10-1000倍 |
| 不算缓存命中 | 高估50倍 |
| 按官网标价不算用户签约价 | 可能高估数倍 |
| 把所有调用当复杂推理 | 实际80%是简单记录 |
| 不算峰谷时段差异 | 老师工具产品可能高估2倍成本 |
