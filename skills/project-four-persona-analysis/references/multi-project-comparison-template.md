# 多项目对比决策框架

当有多个候选项目时，用此框架对比后决策。

---

## 对比维度

| 维度 | 项目A | 项目B |
|------|-------|-------|
| 类型 | 微信小游戏/小程序/SaaS/工具 | |
| 目标用户 | | |
| 核心价值 | 一句话 | |
| 开发周期 | | |
| 开发成本 | | |
| 变现模式 | 买断/IAA/IAP/B端/混合 | |
| 回本周期 | 第X月 | |
| 最大资金缺口 | ¥X | |
| 竞品数量 | | |
| 合规难度 | 高/中/低 | |
| 风险等级 | 高/中/低 | |
| 团队需求 | X人 | |

---

## 经济对比表

```
项目A                         项目B
├ 开发周期 X周                ├ 开发周期 X天
├ 成本 ¥XX万                  ├ 成本 ¥X千
├ 回本 X个月                  ├ 回本 X个月
├ 年利润 ¥XX万                ├ 年利润 ¥XX万
└ 风险 高/中/低               └ 风险 高/中/低
```

---

## 决策原则

1. **先赚快钱再搞大项目**：优先开发成本低、周期短、变现已验证的项目
2. **并行不冲突**：短期项目可以给长期项目做流量入口
3. **资源约束**：一人团队只启动一个项目，不并行
4. **弃投原则**：当成熟项目的确定性收益 > 新项目的预期收益时，优先深耕现有项目
