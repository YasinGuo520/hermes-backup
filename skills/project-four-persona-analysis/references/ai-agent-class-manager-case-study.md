# AI Agent 班级管家 — 产品案例

> 项目类型：微信小程序（非游戏）
> 目标用户：小学班主任（买单方）+ 小学生（使用方）
> 定价：免费版 + ¥9.9/月订阅 + 学校版¥499/校/年

## 产品结构

### 老师端：AI自动化班级管理

| Agent | 功能 | 老师操作 |
|-------|------|---------|
| 纪律Agent | 语音输入课堂表现，自动记录评分 | "张三举手5次"→自动+5分 |
| 作业Agent | 布置/催收/统计作业 | "今晚数学P10"→群发通知 |
| 通知Agent | 一键生成家长通知 | "明天秋游"→生成通知模板 |
| 数据Agent | 自动生成班级周报/学期报告 | 每周五自动出报表 |

### 学生端：AI机器人搭档（核心驱动力）

每个学生拥有专属AI机器人，**男生可选装甲型，女生可选灵动型**。

**装备系统（取代宠物喂食）：**

| 部位 | 基础（白） | 稀有（蓝） | 史诗（紫） | 传说（金） |
|------|----------|----------|----------|----------|
| 武器 | 机械拳 | 激光剑 | 雷霆锤 | 等离子炮 |
| 头盔 | 基础头盔 | 战术面罩 | 全息面罩 | 暗影头盔 |
| 装甲 | 铁甲 | 钛合金甲 | 能量甲 | 暗影装甲 |
| 推进器 | 小喷气 | 双翼推进 | 粒子喷射 | 光子引擎 |
| 特效 | ✗ | 蓝光 | 闪电环绕 | 火焰光环 |

装备获取：表现积分兑换 / 连续签到 / 学期奖励 / ¥1-3微付费

**真AI对话：** 学生可直接跟机器人聊天（跑DeepSeek），自然学会跟AI交互。

## 竞品差异

| 维度 | 班级宠物园 | AI Agent 班级管家 |
|-----|-----------|-----------------|
| 老师端 | 手动记录积分 | AI自动记录+生成通知+报表 |
| 学生端 | 宠物只能看状态 | 能对话的AI机器人，真AI |
| 学生动力 | 怕宠物饿死（被动） | 想要更帅装备（主动） |
| 定价 | ¥9.9一次性 | 免费+¥9.9/月订阅 |
| AI概念 | 无 | 天然嵌入 |

## 迭代过程

1. 初始概念：塔防游戏普及AI Agent → 发现开发周期长（8-10周）
2. 受「班级宠物园」启发：改成老师工具+学生宠物 → 发现学生端动力不足
3. 最终方案：老师省时间工具 + 学生打装备机器人 + 真AI对话

## 核心教训

- 买单方和用方不同时，**必须让用方有内在动力**
- 学生端的动力：「怕失去」<「想要更帅」（主动追求 > 被动防守）
- API成本必须按token算，用真实价格，不能拍脑袋
