## 一、教师痛点定量数据

| 数据点 | 数值 | 来源 |
|--------|------|------|
| 中小学教师平均周工作时长 | **52.54小时/周** | 孔凡琴等《中小学教师工作时间及对工作负荷感的影响研究》(华南师大学报,2023), N=48,874 |
| 教学占工作时长比例 | **~1/3** | 王富伟等《小学教师典型一天的制度分析》(全球教育展望,2018), 社科院项目 |
| 76.4%教师每周读书时间 | **<1小时** | 同上学报引用, 2300位教师调查 |
| 班主任每天花在记录/统计/沟通的时间 | **~2.2小时** | 基于典型一天描述估算（考勤/饭费/作业催缴/通知/纠纷处理） |
| 教师使用AI的核心动机：提升效率 | **60.7%** | 《2025年中小学教师人群应用人工智能情况调研报告》 |
| 教师使用AI的核心动机：减轻负担 | **56.7%** | 同上报告 |

### 典型一天时间线（来自社科院调研还原）

```
7:20 到校
7:32 考勤登记 + 改午餐人数 + 收饭费（1:1联系忘带家长）
8:00-9:30 上课
9:35 写记事 + 叮嘱喝水穿外套
9:45-10:15 上操
10:00-11:00 批改42本周记
11:35 午餐 + 检查记事
12:00 赶交教师笔记和中队日志
12:00-13:00 处理学生纠纷（批评+说教+引导约15分钟）
13:00-13:20 阳光体育
14:00-15:30 继续批改 + 临时会议通知
15:30-16:30 上课 + 放学（校队+与家长沟通）
16:30 社团交接 + 去南校开会
17:00 回家（通勤1.5h）
19:00 到家吃饭
19:30-20:00 家长电话25分钟
20:00-22:00 备课+准备公开课
```

**关键结论**: 教师每分钟都被"高频低价值事务"占用。纪律记录、作业催缴、通知触达三大痛点构成了每天~2.2小时的重复性劳动，是AI Agent的最佳替代场景。

## 二、竞品数据库

### 2.1 主要竞品对比

| 竞品 | 公司 | 类型 | 核心功能 | 商业模式 | 宣称用户量 | AI能力 |
|------|------|------|---------|---------|-----------|--------|
| **班级优化大师** | 希沃(视源股份) | App+PC+硬件 | 行为评价/家校通知/自动评语/班级报表 | 免费(Seewo生态) | 150万+教师/200万+班级 | AI评语+潜力模型(小五人格) |
| **班宠乐园** | 创业团队 | 网页+App | 宠物养成+积分管理+20+课堂工具 | 免费+增值 | 未披露 | 无 |
| **班级宠物园/学萌岛** | 长沙智辉宇创 | App(iOS/Android) | 宠物养成+积分+小卖部+证书导出 | ¥38买断 | 4.5分/245评(≈7K-12K下载) | 接入AI评语(版本2.4.3) |
| **九章爱学老师版** | 好未来(TAL/NYSE) | App | AI备课/出题/批改/家校沟通/170+智能体 | 免费+内购 | 快速增长中 | 170+智能体(含AI交互课件) |
| **班级小管家** | 创业团队 | 微信小程序 | 作业/打卡/通知/统计 | 免费 | 大量 | 无 |

### 2.2 竞品定位矩阵

```
         轻量级工具     ← →    重量级平台
          ┌──────────────────────────────┐
 纯工具    │ 班级小管家                   │ 班级优化大师
          │               AI Agent 管家   │
          │               （目标空白位）   │
          ├──────────────────────────────┤
 AI原生    │ (空白区 - 机会)               │ 九章爱学老师版(偏备课)
          │ 学萌岛/班宠乐园               │
 游戏化    └──────────────────────────────┘
```

**关键发现**: 右上角——**AI原生 × 班级日常管理**——目前是市场空白。

### 2.3 竞品核心差异分析

| 维度 | 现有竞品 | AI Agent 管家 |
|------|---------|--------------|
| 解决的问题 | 点激励/记录(积分+宠物) | 替代每日2.2h高频低价值事务 |
| 核心价值主张 | 让孩子更积极 | 让老师省时间 |
| AI能力 | 仅评语生成/潜力分析 | Agent/Tool/Memory/Prompt完整四层 |
| 用户使用方式 | 手动打分+点击 | 自然语言对话+AI自动执行 |
| 付费模式 | ¥38买断(学萌岛) / 免费(优化大师) | ¥19.9买断+IAA+增值 |
| 迁移成本 | 低(学生数据可导出) | 需用行为数据绑定(护城河) |

## 三、行业趋势数据

### 3.1 AI教育工具赛道数据

| 维度 | 数据 |
|------|------|
| 中国在线教育市场规模(2026E) | 突破万亿(含K12素质/职业/成人) |
| 教师AI工具使用意愿 | 60.7%为提升效率，56.7%为减轻负担 |
| 市场痛点TOP3 | 1. 缺乏一站式平台 2. AI生成偏差需修正 3. Prompt交互门槛高 |
| 教育类eCPM(微信小程序) | 激励视频¥18-45，插屏¥12-25(教育类比塔防/休闲略低) |
| 买断定价参考 | 学萌岛¥38 → 表明教师愿意为管理工具付费 |

### 3.2 微信教育小程序生态

- 教育类小程序受微信官方鼓励（符合"数字教育"政策方向）
- AI相关小程序需注意：使用已备案大模型（阿里百炼/百度文心/腾讯混元）
- 教师用户群体在微信生态内传播效率极高（教师微信群裂变）
- 模板消息/服务通知可用于催缴作业/通知推送
