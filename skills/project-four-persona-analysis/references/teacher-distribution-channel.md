# 教师群体作为分销渠道

教师群体是一个被低估的高效分销渠道，尤其适合低价工具类产品。

---

## 为什么教师群体适合

| 特征 | 说明 |
|------|------|
| 决策链极短 | ¥9.9-19.9不需要学校审批，自己掏钱 |
| 多群身份 | 一个老师平均5-10个教师群，裂变效率高 |
| 高频刚需 | 每天2.2小时花在非教学记录上 |
| 自发传播 | 好用就会在教师群分享，不需要激励 |
| 寒暑假空窗 | 需提前储备用户/现金流应对假期流失 |

## 已验证的模型（班级宠物园模式）

```
产品：帮老师省时间的工具（不是教育课程）
定价：¥9.9-19.9买断（低于个人决策阈值）
传播：教师群口口相传 + 小红书教育KOL
增长：社交裂变为主，不买量
转化：看到→扫码→试用→付费→分享
```

## 反面教训

- **不要走学校采购**：周期长（3-6个月）、决策链复杂、回款慢
- **不要做高价**：¥19.9是最优价位，老师不需要审批
- **不要纯免费**：付费筛选出真正有需求的用户
- **不要套教育类目**：走「工具」类目规避资质门槛
